**Phase 3: Fix Symlink Resolution in `on` Method**

**Root Cause Analysis:**
- `on` method stored whatever version name was passed (e.g., "latest")
- `upgrade` method used stored version directly
- Version increments failed: `incrementBuild("latest")` → `NaN.undefined.undefined.NaN`

**Fix Applied to Web4TSComponent:**
```typescript
// Before:
(this.model as any).contextVersion = version;  // Could be "latest"

// After:
// Resolve actual version if symlink was provided
let actualVersion = version;
if (lstatSync(componentPath).isSymbolicLink()) {
  const linkTarget = readlinkSync(componentPath);
  const versionMatch = linkTarget.match(/(\d+\.\d+\.\d+\.\d+)/);
  if (versionMatch) {
    actualVersion = versionMatch[1];
  }
} else {
  const pathMatch = componentPath.match(/(\d+\.\d+\.\d+\.\d+)$/);
  if (pathMatch) {
    actualVersion = pathMatch[1];
  }
}
(this.model as any).contextVersion = actualVersion;  // Always real version
```

**Imports Added:**
```typescript
import { lstatSync, readlinkSync } from 'fs';
```

**Build Result:**
- ❌ Initial: `error TS2304: Cannot find name 'readlinkSync'`
- ✅ Fixed: Added `readlinkSync` to existing import statement
