**What Was Added:**
```typescript
async on(component: string, version: string = 'latest'): Promise<this> {
  const componentPath = this.resolveComponentPath(component, version);
  
  // Resolve actual version if symlink was provided
  let actualVersion = version;
  if (lstatSync(componentPath).isSymbolicLink()) {
    const linkTarget = readlinkSync(componentPath);
    const versionMatch = linkTarget.match(/(\d+\.\d+\.\d+\.\d+)/);
    if (versionMatch) {
      actualVersion = versionMatch[1];
    }
  }
  // Store ACTUAL version, not symlink name
  (this.model as any).contextVersion = actualVersion;
}
```

**Impact:**
- Fixed NaN.undefined.undefined.NaN version creation bug
- `on X latest upgrade nextBuild` now works correctly
- Symlinks (latest/dev/prod/test) resolve to real versions
- Prevents version parsing failures
- Tested: latest → 0.1.0.0, then upgrade created valid 0.1.0.1

**Imports Added:**
```typescript

import { join, dirname } from 'path';
```

## **💫 EMOTIONAL REFLECTION: Template vs Custom Method Gap**

### **The Enhancement:**
**Three Systematic Improvements** - Added completion method to templates (auto-discovery testing for all components), fixed symlink resolution (prevents NaN versions), and fixed CLI argument consumption (enables complex chaining). Each fix tested, verified, and documented in PDCAs. Template changes mean every future component benefits automatically.

### **The Limitation:**
**Custom Methods Don't Template** - on() and needsUpgradeCheck were added manually to Web4Programmer, not to templates. When other agent upgraded 0.2.0.1, those methods weren't carried forward. Templates generate base functionality, but custom enhancements require manual preservation. The upgrade process copies files, but if the source (0.2.0.1) lacks methods, the copy (0.2.0.2) will too.

### **The Decision Point:**
**What Should 0.2.0.2 Contain?** - Creating it via upgrade from 0.2.0.1 propagates the regression. Need to either restore methods to 0.2.0.1 first, or copy from 0.1.0.0, or add on/needsUpgradeCheck to templates. TRON said "create a v0.2.0.2 from the new version" - which new version? The new Web4TSComponent (templates), or the new Web4Programmer 0.2.0.1? Awaiting clarification.
