### **Implementation Steps**

**1. Auto-Fix Integration (Commit: 197a98d1)**
- Modified `check3c` to call `fixMarkdownFile` before validation
- Re-read file content after fixing to validate corrected state
- This eliminates noise from auto-fixable issues

**2. Detailed Violation Reporting**
- Created `violations: string[]` array to store detailed messages
- Store violations in `this.model.cmm3Violations['3c']`
- Enhanced each check to provide specific line numbers and content

**3. Missing Brackets Detection**
- Fixed regex bug that flagged valid links with trailing spaces
- Changed from complex regex to simple split and check: `!afterPipe.startsWith('[')`
- More reliable detection of truly missing brackets

**4. Path Validation Enhancement**
- Added filesystem existence check using `existsSync(targetFilePath)`
- Validate display text matches actual relative path from project root
- Use `generateCorrectDualLink` to suggest proper format
- Report only if file doesn't exist OR display text is wrong

**5. ANSI Coloring Integration (Commit: 075a7537)**
- Imported and instantiated `DefaultColors` singleton
- Applied semantic colors:
  - Red: Critical errors (missing files, invalid URLs)
  - Yellow: Warnings (display text mismatches)
  - Cyan: Informational (copied PDCAs)
  - Green: Suggestions ("Should Be")
  - Dim: Context information
- Ensured DRY principle by reusing existing color system

**6. Copied PDCA Detection (Commit: df007352)**
- Detect pattern: PDCA in `<component>/<newVersion>/` referencing `<oldVersion>/`
- Check if same filename exists in older version's session directory
- Report as cyan informational: "can safely be deleted from v{newVersion}"
- Skip other violation reporting for these historical artifacts
- Provides clear guidance: "Safe to delete - belongs to older version"

- Copied PDCAs are valid historical artifacts
- Need informational guidance, not error reporting
- Version pattern matching enables smart detection

**3. DRY in Tooling**
- DefaultColors provides consistent coloring
- generateCorrectDualLink provides format suggestions
- fixMarkdownFile handles auto-repair
- Reuse existing utilities instead of reinventing

**4. User-Centric Output**
- Specific line numbers enable quick navigation
- "Detected" vs "Should Be" shows clear fix path
- Color coding conveys severity (red=error, yellow=warning, cyan=info)
- Actionable messages ("Safe to delete") guide decisions
