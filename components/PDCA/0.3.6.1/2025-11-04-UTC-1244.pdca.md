**Objective:** Redesign completion API to eliminate fake context injection, add diagnostic output showing completion methods used, and display signature with parameter highlighting

**Requirements Traceability:** User feedback 2025-11-04-UTC-1244

**Implementation Strategy:**
- **New Entry Point:** Create `completeCliCommand(cword, ...words)` as clean, natural API
