## **🔧 DO**

**Bug Analysis and Fix Implementation - Pending Execution**

### **Bug Description:**
When `rewritePDCA` with Option B (smart preservation) was tested on real demo PDCA (1103), it produced severely corrupted output:
- Template placeholders mixed with preserved content
- Sections duplicated
- Content bleeding across section boundaries
- Subsections (###) confused the regex pattern

### **Root Cause:**
The `mergeSections()` method uses regex pattern: `(## \\*\\*${sectionName}\\*\\*[^\\n]*\\n\\n)([\\s\\S]*?)(\\n\\n---|$)`

**Problems:**
1. `[\\s\\S]*?` (non-greedy) doesn't properly stop at next section if there's complex content
2. Doesn't handle subsections (### headers) within main sections
3. `\\n\\n---` boundary detection fails when sections end differently
4. Regex replacement with `$1${cleanContent}$3` doesn't cleanly isolate boundaries

### **Proposed Fix:**
Rewrite `mergeSections()` to use **line-by-line parsing** instead of regex:

```typescript
private mergeSections(template: string, extractedSections: Record<string, string>): string {
  const templateLines = template.split('\n');
  const result: string[] = [];
  let i = 0;
  
  while (i < templateLines.length) {
    const line = templateLines[i];
    
    // Check if this is a section header: ## **SectionName**
    const sectionMatch = line.match(/^## \*\*(.+?)\*\*$/);
    
    if (sectionMatch) {
      const sectionName = sectionMatch[1];
      
      // If we have extracted content for this section, use it
      if (extractedSections[sectionName]) {
        result.push(line); // Keep the header
        result.push(''); // Blank line after header
        result.push(extractedSections[sectionName]); // Insert extracted content
        
        // Skip template content until next ## ** or ---
        i++;
        while (i < templateLines.length) {
          if (templateLines[i].match(/^## \*\*/) || templateLines[i].trim() === '---') {
            break;
          }
          i++;
        }
        continue; // Don't increment i again
      }
    }
    
    result.push(line);
    i++;
  }
  
  return result.join('\n');
}
```

**Key Improvements:**
1. **Precise Boundaries**: Finds exact line where section starts/ends
2. **Handles Subsections**: Extracted content includes all ### headers
3. **No Regex Fragility**: Simple line-by-line logic, no complex patterns
4. **Clean Replacement**: Skips template lines, inserts extracted content once
