```quote
What about other information that is already in it? Say a corrupted PDCA was created, but then that information should just be put in right places in the rewritten PDCA, or?
```

### **My Answer**
Creating design PDCA for "Smart Content Preservation" feature for `rewritePDCA`. The user identified a valuable UX improvement: current `rewritePDCA` creates a fresh template (preserving only timestamp, title, objective) but **loses all existing DO/CHECK/ACT content**. 

User's insight: If a corrupted PDCA has some valid content, `rewritePDCA` should be smart enough to:
1. Detect which sections exist and are salvageable
2. Extract valid content from those sections
3. Preserve that content in the correct sections of the rewritten PDCA
4. Only reset sections that are truly missing or corrupted

This transforms `rewritePDCA` from a "nuclear option" (lose everything) to a "smart recovery" (save what's valid, fix what's broken).

**Learning Applied:** User feedback reveals UX gap - current behavior prioritizes simplicity over preserving user's work. Smart content preservation would be more valuable for real-world use cases.

## **📋 PLAN**

**Objective:** Enhance rewritePDCA to salvage and preserve existing content from corrupted PDCAs

**Requirements Traceability:** User feedback → UX improvement → Smart content preservation

### **Problem Analysis**

**Current Behavior (Nuclear Option):**
- `rewritePDCA` preserves: timestamp, title (extracted), objective (extracted)
- `rewritePDCA` resets: ALL content sections (PLAN, DO, CHECK, ACT, EMOTIONAL, PROCESS)
- Result: Clean template with metadata, but **user loses all their work**

**User Expectation:**
- If corrupted PDCA has valid DO section content → preserve it
- If CHECK section is missing → create fresh (OK to reset)
- If ACT has good content → keep it
- Only reset what's truly corrupted/missing

**Gap:**
- Current: "Throw away everything, start fresh"
- Desired: "Save what's valid, fix what's broken"

### **Design Options**

**Option A: Add `--preserve-content` Flag (Recommended)**

**Syntax:**
```bash
# Nuclear option (current behavior - default)
pdca rewritePDCA <file>

# Smart preservation (new behavior - opt-in)
pdca rewritePDCA <file> --preserve-content
```

**Pros:**
- Backward compatible (default behavior unchanged)
- Users choose based on use case
- Simple flag, clear intent

**Cons:**
- Two code paths to maintain
- Users must know which flag to use

**Implementation:**
1. Add `preserveContent?: boolean` parameter to `rewritePDCA` method
2. If `false` (default): Current nuclear behavior
3. If `true`: Parse corrupted file, extract salvageable content, merge with template

**Option B: Always Use Smart Preservation (Breaking Change)**

**Behavior:** `rewritePDCA` always tries to preserve content

**Pros:**
- One code path, simpler
- Better UX (never loses work)

**Cons:**
- Breaking change (changes existing behavior)
- May preserve corrupted content users wanted to discard
- No "clean slate" option

**Option C: Separate Command (`preservePDCA`)**

**Syntax:**
```bash
pdca rewritePDCA <file>        # Nuclear (current)
pdca preservePDCA <file>       # Smart preservation (new)
```

**Pros:**
- Clear separation of concerns
- No breaking changes
- Explicit intent

**Cons:**
- Two commands for similar operations
- More complex CLI

```typescript
// In DefaultPDCA.ts

async rewritePDCA(filePath: string, preserveContent: boolean = false, dryRun?: string): Promise<this> {
  // Step 1: Extract timestamp, title, objective (existing behavior)
  const timestamp = this.extractTimestampFromFilename(filePath);
  const corruptedContent = await fs.readFile(filePath, 'utf-8');
  const title = this.extractTitleFromContent(corruptedContent);
  const objective = this.extractObjectiveFromContent(corruptedContent);
  
  // Step 2: Read fresh template
  const templatePath = join(this.model.workspace, 'scrum.pmo/roles/_shared/PDCA/template.md');
  let templateContent = await fs.readFile(templatePath, 'utf-8');
  
  // Step 3: Auto-populate metadata (existing behavior)
  templateContent = this.populateBoilerplateInternal(templateContent, title, objective, timestamp, this.model.branch);
  
  // Step 4: NEW - Content preservation logic (if flag enabled)
  if (preserveContent) {
    const extractedSections = this.extractSections(corruptedContent);
    templateContent = this.mergeSections(templateContent, extractedSections);
  }
  
  // Step 5: Write to same filename (existing behavior)
  await fs.writeFile(filePath, templateContent, 'utf-8');
  return this;
}

// NEW: Extract sections from corrupted PDCA
private extractSections(content: string): SectionMap {
  const sections: SectionMap = {};
  const sectionRegex = /^## \*\*(.+?)\*\*$/gm;
  
  // Parse sections
  const matches = [...content.matchAll(sectionRegex)];
  for (let i = 0; i < matches.length; i++) {
    const sectionName = matches[i][1];
    const startIndex = matches[i].index! + matches[i][0].length;
    const endIndex = i < matches.length - 1 ? matches[i + 1].index : content.length;
    const sectionContent = content.substring(startIndex, endIndex).trim();
    
    if (this.isValidContent(sectionContent)) {
      sections[sectionName] = sectionContent;
    }
  }
  
  return sections;
}

// NEW: Validate if content is salvageable
private isValidContent(content: string): boolean {
  if (!content || content.length < 50) return false;  // Too short
  if (content.match(/\{\{.*?\}\}/g)?.length > 5) return false;  // Too many placeholders
  if (content.startsWith('CORRUPTED') || content.startsWith('MISSING')) return false;  // Explicitly broken
  return true;
}

// NEW: Merge extracted sections into template
private mergeSections(template: string, extracted: SectionMap): string {
  for (const [sectionName, sectionContent] of Object.entries(extracted)) {
    // Find section in template and replace placeholder with extracted content
    const sectionRegex = new RegExp(`(## \\*\\*${sectionName}\\*\\*.*?)(---|\$)`, 's');
    template = template.replace(sectionRegex, (match, header, divider) => {
      return `${header}\n\n${sectionContent}\n\n${divider}`;
    });
  }
  return template;
}
```
