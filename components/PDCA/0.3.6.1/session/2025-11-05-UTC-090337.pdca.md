## **📊 SUMMARY**

### **Problem Statement**
The `rename` command currently loses timestamp precision when applying case transformations (`now`, `creationDate`, `strip`, `feature`). Files with 6-digit timestamps (HHMMSS format) are converted to 4-digit timestamps (HHMM format), breaking the chain and losing temporal precision.

**Current Behavior:**
- File: `2025-11-05-UTC-083559.pdca.md` (with seconds)
- After `rename now`: `2025-11-05-UTC-0836.pdca.md` (seconds lost)
- After `rename creationDate`: `2025-11-05-UTC-0835.pdca.md` (seconds lost)

**Expected Behavior:**
- File: `2025-11-05-UTC-083559.pdca.md` (with seconds)
- After `rename now`: `2025-11-05-UTC-083612.pdca.md` (seconds preserved)
- After `rename creationDate`: `2025-11-05-UTC-083559.pdca.md` (seconds preserved)

### **Root Cause Analysis**
1. **Timestamp Extraction (Line 5067):** Regex `^(\d{4}-\d{2}-\d{2}-UTC-\d{4})` only matches 4-digit timestamps (HHMM)
2. **Timestamp Generation (Lines 5084, 5111):** `now` and `creationDate` cases hardcode 4-digit format (HHMM)
3. **Format Detection Missing:** No logic to detect original format and preserve it

```typescript
// File: components/PDCA/0.3.6.1/src/ts/layer2/DefaultPDCA.ts
// Line 5067: Update timestamp regex to support both formats

// OLD:
const timestampMatch = nameWithoutFeature.match(/^(\d{4}-\d{2}-\d{2}-UTC-\d{4})/);

// NEW:
const timestampMatch = nameWithoutFeature.match(/^(\d{4}-\d{2}-\d{2}-UTC-(\d{4}|\d{6}))/);
const timestamp = timestampMatch ? timestampMatch[1] : null;
const timestampDigits = timestampMatch ? timestampMatch[2] : null; // Capture format
const hasSeconds = timestampDigits?.length === 6;
```

```typescript
// Lines 5076-5090: Update 'now' case to preserve format

case 'now': {
  const now = new Date();
  const year = now.getUTCFullYear();
  const month = String(now.getUTCMonth() + 1).padStart(2, '0');
  const day = String(now.getUTCDate()).padStart(2, '0');
  const hour = String(now.getUTCHours()).padStart(2, '0');
  const minute = String(now.getUTCMinutes()).padStart(2, '0');
  
  // NEW: Add seconds if original format had them
  const second = hasSeconds ? String(now.getUTCSeconds()).padStart(2, '0') : '';
  const newTimestamp = hasSeconds 
    ? `${year}-${month}-${day}-UTC-${hour}${minute}${second}`
    : `${year}-${month}-${day}-UTC-${hour}${minute}`;
  
  newName = hasFeature 
    ? `${newTimestamp}.feature${baseExt}`
    : `${newTimestamp}${baseExt}`;
  break;
}
```

```typescript
// Lines 5093-5119: Update 'creationDate' case to preserve format

case 'creationDate': {
  try {
    const gitLog = execSync(
      `git log --follow --diff-filter=A --format=%aI -- "${normalized}"`,
      { cwd: projectRoot, encoding: 'utf-8' }
    ).trim();
    
    if (!gitLog) {
      throw new Error(`File has no git history: ${normalized}`);
    }
    
    const creationDate = new Date(gitLog.split('\n')[0]);
    const year = creationDate.getUTCFullYear();
    const month = String(creationDate.getUTCMonth() + 1).padStart(2, '0');
    const day = String(creationDate.getUTCDate()).padStart(2, '0');
    const hour = String(creationDate.getUTCHours()).padStart(2, '0');
    const minute = String(creationDate.getUTCMinutes()).padStart(2, '0');
    
    // NEW: Add seconds if original format had them
    const second = hasSeconds ? String(creationDate.getUTCSeconds()).padStart(2, '0') : '';
    const newTimestamp = hasSeconds
      ? `${year}-${month}-${day}-UTC-${hour}${minute}${second}`
      : `${year}-${month}-${day}-UTC-${hour}${minute}`;
    
    newName = hasFeature
      ? `${newTimestamp}.feature${baseExt}`
      : `${newTimestamp}${baseExt}`;
  } catch (error: any) {
    throw new Error(`Failed to get git creation date: ${error.message}`);
  }
  break;
}
```
