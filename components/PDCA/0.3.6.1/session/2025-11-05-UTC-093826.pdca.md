**1. createPDCA - Create New PDCA from Template**
```bash
# Natural language (chat)
Create a new PDCA in Web4TSComponent 0.3.17.1 session directory with title "Demo" and objective "Tools in PDCA"

# CLI syntax

# Features:
# - Auto-populates metadata (timestamp, previous commit, dual links)
# - Establishes bidirectional chain with previous PDCA
# - Supports cross-component creation via sessionDirectory parameter
# - AI must populate all content sections per AI Content Population Mandate
```

**2. rename with now - Update Timestamp to Current Time**
```bash
# Natural language (chat)
Use rename with now on the PDCA file @2025-11-05-UTC-093826.pdca.md

# CLI syntax
pdca rename now /path/to/2025-11-05-UTC-093826.pdca.md

# Features:
# - Preserves original timestamp format (HHMM or HHMMSS)
# - Updates bidirectional chain links automatically
# - Atomic git commit and push
```

**3. rename with creationDate - Set Timestamp to Git Creation Date**
```bash
# Natural language (chat)
Use rename with creationDate on the PDCA file @2025-11-05-UTC-093826.pdca.md

# CLI syntax
pdca rename creationDate /path/to/file.pdca.md

# Features:
# - Queries git log for file creation date
# - Preserves timestamp format (HHMM or HHMMSS)
# - Useful for retroactive timestamp correction
```

**4. rename with strip - Remove Description from Filename**
```bash
# Natural language (chat)
Use rename with strip on the PDCA file @2025-10-28-UTC-1822.phase1-2-completion.pdca.md

# CLI syntax

# Result: 2025-10-28-UTC-1822.pdca.md
# Features:
# - Removes descriptive text, keeps only timestamp
# - Preserves .feature suffix if present
# - Updates chain links automatically
```

**5. rename with feature - Add Feature Marker**
```bash
# Natural language (chat)
Use rename with feature on the PDCA file @2025-11-04-UTC-1015.pdca.md

# Result: 2025-11-04-UTC-1015.feature.pdca.md
# Features:
# - Marks PDCA as feature-related work
# - Can be combined with strip to remove later
```

**6. chain - Display Bidirectional Links**
```bash
# Natural language (chat)
Show the chain for this PDCA

# CLI syntax
pdca chain /path/to/file.pdca.md

# Features:
# - Shows previous and next PDCA links
# - Validates bidirectional chain integrity
```

**7. rewritePDCA - Rebuild Corrupted PDCA**
```bash
# Natural language (chat)
Use rewritePDCA on the corrupted PDCA file at @2025-11-04-UTC-1011.pdca.md

# CLI syntax

# Features:
# - Preserves original timestamp (in-place rewrite)
# - Smart content preservation (salvages existing content)
# - Auto-populates all metadata and content sections
# - Deletes corrupted file, creates fresh PDCA
```
