## **📊 SUMMARY**

**Problem:** When `createPDCA` is run in terminal, it creates a PDCA with unpopulated content placeholders. The AI Content Population Mandate exists in `trainAI` but is not programmatically enforced, leading to unpopulated PDCAs sitting in the filesystem.

**Root Cause:** Architectural gap between programmatic creation (`createPDCA`) and programmatic validation (`cmm3check`), filled only by an AI guideline that doesn't work in terminal-first workflows.

**Solution (Option B3):** Enhance `createPDCA` to automatically trigger Cursor AI chat with a population request after creating the template. Falls back to current behavior if Cursor integration is unavailable.

**Benefits:**
- ✅ **Terminal-First:** Works from command line without manual AI intervention
- ✅ **Leverages Cursor AI:** Uses existing Cursor subscription, no external API costs
- ✅ **Graceful Fallback:** If Cursor unavailable, behaves as current implementation
- ✅ **Maintains Separation:** Creation logic separate from population logic

## **🔧 DO**

**Phase 1: Cursor API Research**

**1. Cursor Architecture Investigation**
```markdown
Research Findings:

Cursor does NOT expose a public API for programmatic chat triggers from terminal commands.

Cursor's architecture:
- Electron-based IDE (fork of VS Code)
- AI chat runs in IDE context, not accessible from external processes
- No documented API for triggering chat from command-line tools
- Extension API exists but is for IDE extensions, not terminal commands

Conclusion: Direct Cursor chat trigger from terminal is NOT feasible with current Cursor architecture.
```

**2. Alternative Approaches Evaluated**
```markdown
Option A: Cursor Extension (REJECTED)
- Would require building a Cursor extension
- Extension could listen for file creation events
- Complex setup, requires user to install extension
- Not terminal-first (requires IDE to be running)

Option B: File-Based Communication (FEASIBLE)
- Create a "population request" file when PDCA is created
- Cursor AI monitors for these request files
- When detected, AI populates the PDCA
- Simple, no API needed, terminal-first compatible

Option C: Enhanced Fallback (SELECTED)
- Keep current behavior (template only)
- Add prominent console message with population instructions
- Optionally create a .populate marker file
- AI can scan for .populate markers and auto-populate
- Graceful, simple, maintains terminal-first workflow
```

**3. Selected Implementation: Enhanced Fallback with Marker Files**
```typescript
// In DefaultPDCA.ts - createPDCA method enhancement

async createPDCA(title: string, objective: string, sessionDirectory?: string, dryRun: string = 'false') {
  // ... existing creation logic ...
  
  // NEW: After PDCA creation, create population marker
  const markerFile = filePath.replace('.pdca.md', '.populate');
  const markerContent = JSON.stringify({
    pdcaFile: filePath,
    objective: objective,
    timestamp: new Date().toISOString(),
    status: 'pending'
  }, null, 2);
  
  fs.writeFileSync(markerFile, markerContent);
  
  console.log(`\n📝 PDCA created: ${fileName}`);
  console.log(`⚠️  Content population required`);
  console.log(`💡 AI: Run 'pdca populate ${fileName}' or check for .populate marker files`);
  
  return this;
}

// NEW: Add populate command
async populate(filePath: string): Promise<this> {
  // Read PDCA file
  const content = fs.readFileSync(filePath, 'utf-8');
  
  // Check for .populate marker
  const markerFile = filePath.replace('.pdca.md', '.populate');
  if (!fs.existsSync(markerFile)) {
    console.log(`⚠️  No population marker found for ${filePath}`);
    return this;
  }
  
  const marker = JSON.parse(fs.readFileSync(markerFile, 'utf-8'));
  
  // Trigger AI population (in Cursor chat context)
  console.log(`\n🤖 Population request for: ${path.basename(filePath)}`);
  console.log(`🎯 Objective: ${marker.objective}`);
  console.log(`\n📋 Please populate all content sections based on the objective.`);
  console.log(`✅ After population, run: pdca markPopulated ${filePath}`);
  
  return this;
}

// NEW: Mark PDCA as populated (removes marker)
async markPopulated(filePath: string): Promise<this> {
  const markerFile = filePath.replace('.pdca.md', '.populate');
  if (fs.existsSync(markerFile)) {
    fs.unlinkSync(markerFile);
    console.log(`✅ Marked as populated: ${path.basename(filePath)}`);
  }
  return this;
}
```
