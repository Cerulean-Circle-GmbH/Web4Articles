Currently, the `rename` command accepts a `renameCase` parameter with four possible values: `now`, `creationDate`, `strip`, and `feature`. However, there is NO tab completion for this parameter, forcing users to:

This degrades developer experience compared to other commands that have intelligent tab completion.

```typescript
/**
 * Parameter completion for rename command's renameCase parameter
 * Returns the four valid case transformation options
 * Used by: rename
 * @cliHide
 */
async renameCaseParameterCompletion(currentArgs: string[]): Promise<string[]> {
  return ['now', 'creationDate', 'strip', 'feature'];
}
```

**Why This Works**:
1. **Naming Convention**: TSCompletion auto-discovers methods ending in `ParameterCompletion`
2. **Parameter Matching**: `renameCase` → `renameCaseParameterCompletion` 
3. **Auto-Registration**: No manual configuration needed - bash completion finds it automatically
4. **Zero Config**: The `source.env` completion handler calls TSCompletion which introspects the method
