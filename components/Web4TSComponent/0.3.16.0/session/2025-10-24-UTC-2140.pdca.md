## **🔧 DO**

**Issue 1 - PS1 Prompt Fixed:**

**Root Cause Found:**
- Template had shell variables: `${COMP_NAME:-Component}/${COMP_VERSION:-Version}`
- v0315xHack condition `!modifiedContent.includes('[ISOLATED web4')` prevented replacement
- Shell variables defaulted to "Component/Version" when COMP_NAME/COMP_VERSION unset

**Solution Applied:**
```typescript
// OLD: Conditional replacement only if no ISOLATED text
if (!modifiedContent.includes('[ISOLATED web4')) {
  // PS1 replacement logic
}

// NEW: Always replace to convert shell variables to hardcoded values  
{
  // PS1 replacement logic - always runs
  if (modifiedContent.includes('export PS1=')) {
    modifiedContent = modifiedContent.replace(
      /export PS1=".*?"/,
      `export PS1="\\[\\033[1;36m\\][ISOLATED web4 ${componentName}/${componentVersion}]\\[\\033[0m\\] \\[\\033[1;33m\\]\\w\\[\\033[0m\\] > "`
    );
  }
}
```

**Issue 2 - test itCase Fixed:**

**Root Cause Found:**
- 0.3.13.2 had complete directory: `Web4TSComponent/0.3.13.2/test/`
- 0.3.15.1 only had: `Web4TSComponent/0.3.14.4 -> ../../../..`
