## **📋 PLAN**

### **Problem Analysis**

**Initial Design (Symlink Approach):**
```typescript
// ❌ DANGEROUS: Creates recursive loops
const versionLink = path.join(componentMirrorDir, componentVersion);
await fs.symlink(componentPath, versionLink, 'dir');
```

**Why It Failed:**
1. `test/data/components/Web4TSComponent/0.3.13.2` → symlink to real component
2. Real component CONTAINS `test/data` directory
3. Result: `test/data → component → test/data → component → ...` (infinite loop!)
4. Node.js error: "cannot copy to subdirectory of self"
5. PATH resolution created doubled paths: `.../test/data/components/.../test/data/...`

**Additional Issue:**
Old component's `web4tscomponent` file might be a wrapper from previous `initProject`, not the actual CLI!

### **Solution Design**

**Copy Strategy with Exclusions:**
```typescript
// ✅ SAFE: Copy files with explicit exclusions
const entries = await fs.readdir(componentPath, { withFileTypes: true });
for (const entry of entries) {
  if (entry.name === 'test') {
    await fs.mkdir(destPath, { recursive: true });
    continue; // Skip test/ (avoid recursion)
  }
  if (entry.name === 'node_modules') {
    continue; // Skip node_modules (is a symlink)
  }
  // Copy everything else
  await fs.cp(srcPath, destPath, { recursive: true });
}
```

**Direct Node Wrapper:**
```typescript
// ✅ SAFE: Generate fresh wrapper that calls node directly
const cliWrapperContent = `#!/bin/bash
exec node "${cliJsPath}" "$@"
`;
await fs.writeFile(cliScriptPath, cliWrapperContent, { mode: 0o755 });
```

- 📚 Documentation is thorough and will prevent future regression

**What Was Challenging:**
- 🔄 Multiple iterations to discover all failure modes (symlink loops, wrapper recursion, hardcoded versions)
- 🐛 Each fix revealed a new issue (classic debugging cascade)
- ⚠️ Symlinks are seductive (elegant, fast) but dangerous (subtle failures)

**Key Learning:**
> **"Symlinks in test isolation = recursive path hell"**
> 
> When copying A into A/test/data, symlinks create infinite loops.
> Solution: Copy with exclusions, not symlink.
> Trade-off: Speed vs Safety → **Safety always wins for test isolation!**

**CMM4 Insight:**
This PDCA demonstrates feedback loop mastery:
1. Built feature (retroactive isolation)
2. Found critical flaw (symlink loops)
3. Analyzed root cause (recursion)
