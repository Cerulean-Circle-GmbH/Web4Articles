**What's wrong?**

- All necessary data should be IN the model BEFORE method runs

## **🎯 TRUE RADICAL OOP SOLUTION**

### **Core Principle**

**Model = Pure Serializable Data** (NO logic, NO getters, NO `_` private properties!)

**Component & CLI = Smart** (They work ON the model, calculate paths, update model)

**Pattern**:
```typescript
// ❌ WRONG (calculate in every method):
const target = this.model.context || this;
const componentPath = path.join(cli.model.componentsDirectory, target.model.component, ...);

// ✅ RIGHT (paths already IN model):
const componentPath = this.model.componentPath;  // Already set by init/on/setContext!
```

---

### **Where Intelligence Lives**

**Smart Methods** (calculate and UPDATE model):
1. `init()` - Initial setup, calculate paths for `this` component
2. `on()` - Load context component, calculate paths for context
3. `updateModelPaths()` - Helper to recalculate when context changes

**Dumb Model** (just data):
```typescript
export interface Web4TSComponentModel {
  component: string;
  version: SemanticVersion;
  
  // Infrastructure paths (from CLI, set ONCE in init):
  projectRoot: string;          // §/Web4Articles
  componentsDirectory: string;   // §/Web4Articles/components
  componentRoot: string;         // THIS component's root (§/components/Web4TSComponent/0.3.18.3)
  
  // Calculated paths for TARGET component (this OR context - set by updateModelPaths()):
  targetComponentRoot?: string;   // Target component root (§/components/IdealMinimalComponent/0.3.18.2)
  targetTestDirectory?: string;   // Target test dir (§/components/IdealMinimalComponent/0.3.18.2/test)
  targetSrcDirectory?: string;    // Target src dir (§/components/IdealMinimalComponent/0.3.18.2/src)
  
  context?: any;  // Loaded context component
}
```

**CRITICAL SEMANTIC DIFFERENCE**:
- `componentRoot` = **THIS** component's root (Web4TSComponent) - NEVER changes!
- `targetComponentRoot` = **TARGET** component's root (this OR context) - changes with `on()`!

**Why This Matters**:
```typescript
// When: web4tscomponent test
// componentRoot = §/components/Web4TSComponent/0.3.18.3 (THIS)
// targetComponentRoot = §/components/Web4TSComponent/0.3.18.3 (same - no context)

// When: web4tscomponent on IdealMinimalComponent 0.3.18.2 test
// componentRoot = §/components/Web4TSComponent/0.3.18.3 (THIS - unchanged!)
// targetComponentRoot = §/components/IdealMinimalComponent/0.3.18.2 (context!)
```

**Methods MUST use**:
- `this.model.componentRoot` → When operating on THIS component (Web4TSComponent itself)
- `this.model.targetComponentRoot` → When operating on target (this OR context)

### **The Solution**

**Step 1: Add helper method to UPDATE model**

```typescript
/**
 * Update model with calculated paths for target component (this or context)
 * Called after init() or when context changes (on/removeComponent)
 * Radical OOP: Intelligence in methods, pure data in model
 * @pdca 2025-11-07-UTC-0000.eliminate-path-duplication-all-cases.pdca.md
 */
private updateModelPaths(): void {
  const target = this.model.context || this;
  const cli = this.getCLI();
  
  // ✅ Calculate TARGET component paths (changes with context):
  this.model.targetComponentRoot = path.join(
    cli.model.componentsDirectory,
    target.model.component,
    target.model.version.toString()
  );
  this.model.targetTestDirectory = path.join(this.model.targetComponentRoot, 'test');
  this.model.targetSrcDirectory = path.join(this.model.targetComponentRoot, 'src');
}
```

**Step 2: Call it where context changes**

```typescript
// In init():
async init(scenario: Web4TSComponentScenario): Promise<this> {
  // ... existing init code ...
  this.updateModelPaths();  // ✅ Calculate paths for THIS component
  return this;
}

// In on() (DefaultCLI):
async on(component: string, version: string): Promise<this> {
  // ... load context component ...
  (this.component!.model as any).context = targetComponent;
  if (this.component && typeof (this.component as any).updateModelPaths === 'function') {
    (this.component as any).updateModelPaths();  // ✅ Recalculate for CONTEXT
  }
  return this;
}

// In removeComponent():
this.model.context = undefined;
this.updateModelPaths();  // ✅ Recalculate back to THIS component
```

**Step 3: Methods just READ from model**

```typescript
// ✅ NO calculations, still need target for NAME/VERSION, use targetComponentRoot for PATH:

  const target = this.model.context || this;  // For component NAME/VERSION only
  const componentPath = this.model.targetComponentRoot!;  // For PATH
  // ... business logic only
}
```
