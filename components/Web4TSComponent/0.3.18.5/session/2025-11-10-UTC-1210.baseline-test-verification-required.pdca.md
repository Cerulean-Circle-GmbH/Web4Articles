## Lessons Learned

**Lesson 1**: **"Manual testing is CMM2"**
- ❌ Manual: `web4tscomponent create ...` in shell
- ✅ CMM3: `web4tscomponent test file idealminimalcomponent-creation-isolation.test.ts`

**Lesson 2**: **"Tests must verify NEW patterns, not just OLD"**
- Template changed to add path fields
- Test must assert those fields exist
- Otherwise test passes with old templates!

**Lesson 3**: **"Evidence-based testing enables manual verification"**
- Test creates components in test/data
- Evidence persists after test (no afterAll cleanup)
- Can manually inspect and test the generated component
- Best of both worlds: automated + inspectable

**Lesson 4**: **"Existing tests are the baseline"**
- Before implementing manually, search for existing tests
- `idealminimalcomponent-creation-isolation.test.ts` already does what I did manually
- Just needed to run it and verify it still passes
