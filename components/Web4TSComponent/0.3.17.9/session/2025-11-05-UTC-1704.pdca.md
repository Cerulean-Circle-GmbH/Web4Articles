**8. Root Cause Analysis**

**Timeline:**
1. **Nov 4, 2025 21:38 UTC:** 0.3.17.7 created with improved shell scripts
2. **Nov 5, 2025 13:18 UTC:** 0.3.17.9 created using `web4tscomponent upgrade` command
3. **Problem:** Upgrade command used templates that predated Nov 4 improvements
4. **Result:** 0.3.17.9 generated with OLDER shell scripts despite being NEWER version

**Why this happened:**
- Templates in dist/ directory not rebuilt before upgrade
- OR templates in source not updated to match 0.3.17.7 improvements
- OR 0.3.17.7 improvements not yet propagated to template source

**Where templates come from:**
```
Web4TSComponent source (layer 2-5)
  ↓ (build)
Web4TSComponent dist/
  ↓ (create command)  
Web4TSComponent templates/
  ↓ (upgrade command)
New component version source
```

**The break:** 0.3.17.7 sh scripts improved DIRECTLY in src/sh, NOT propagated back to templates
