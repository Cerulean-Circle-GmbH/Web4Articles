## **📋 PLAN**

### **Context**

TRON confirmed: Web4TSComponent should have lazy-initialized User reference, similar to how generated components have lazy web4tscomponent reference. This enables proper delegation for owner data generation instead of manually creating JSON.stringify objects.

**Current Problem (Manual Owner Creation):**
```typescript
// ❌ Manual JSON creation - NOT Web4 pattern!
owner: JSON.stringify({
  user: process.env.USER || 'system',
  hostname: process.env.HOSTNAME || 'localhost',
  uuid: this.model.uuid,
  timestamp: new Date().toISOString(),
  component: componentName,
  version: componentVersion
})
```

**Web4 Pattern (Delegation to User):**
```typescript
// ✅ Delegate to User service
const user = await this.getUser();
const ownerData = await user.generateOwnerData(
  process.env.USER || 'system',
  process.env.HOSTNAME || 'localhost',
  this.model.uuid
);
```

### **Critical Fix: Web4 Type Safety**

**Violation:** `private user?: any` (any is strictly forbidden in Web4)

**Correction:** 
- `private user?: User` with proper interface typing
- Copy User interface to prevent build dependency:
  ```typescript
  interface User {
    init(scenario: Scenario): this;
    generateOwnerData(params: OwnerParams): Promise<string>;
    toScenario(): Promise<Scenario>;
  }
  
  interface OwnerParams {
    user: string;
    hostname: string;
    uuid?: string;
  }
  ```
- Source: `components/User/0.3.0.4/src/ts/layer3/User.interface.ts`
