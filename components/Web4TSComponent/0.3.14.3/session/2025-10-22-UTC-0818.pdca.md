## **🔧 DO**

**1. TypeScript Output Format (DefaultCLI.ts lines 1400, 1411)**
```typescript
lines.push(`WORD: ${word}`);
//          ^^^^^ 
// Breakdown: "WORD" + ":" + " " (ONE space) + word
```

**Example Output:**
```
WORD: method
WORD: parameter
```

**2. Bash Processing Pipeline (source.env line 92)**
```bash
words=$(echo "$result" | grep "^WORD: " | cut -d' ' -f2- | xargs)
#                             ^^^^^^^      ^^^^^^^        ^^^^^^
#                             Match ONE    Split on       Join lines,
#                             space        ONE space,     trim whitespace
#                                          take field 2+
```

**3. Pipeline Step-by-Step Analysis**
```bash
# Step 1: grep "^WORD: "
# Input:  "WORD: method\nWORD: parameter"
# Output: "WORD: method\nWORD: parameter"
# Role:   Filter lines starting with "WORD: " (one space)

# Step 2: cut -d' ' -f2-
# Input:  "WORD: method\nWORD: parameter"
# Output: "method\nparameter"
# Role:   Remove "WORD: " prefix by splitting on space and taking field 2+

# Step 3: xargs
# Input:  "method\nparameter"
# Output: "method parameter"
# Role:   Join newline-separated lines with spaces AND trim trailing whitespace
```

**4. Test Verification**
```bash
# Test 1: Normal words
result="WORD: method\nWORD: parameter"
words=$(echo "$result" | grep "^WORD: " | cut -d' ' -f2- | xargs)
echo "'$words'"  # Output: 'method parameter' (no trailing space)

# Test 2: Callback
result="WORD: __CALLBACK__:whatParameterCompletion"
words=$(echo "$result" | grep "^WORD: " | cut -d' ' -f2- | xargs)
callback="${words#__CALLBACK__:}"
echo "'$callback'"  # Output: 'whatParameterCompletion' (no trailing space)
```

**5. Why tr Was Wrong**
```bash
# OLD: tr '\n' ' ' 
# Input:  "method\nparameter\n"
# Output: "method parameter "  ← Trailing space from final newline!

# NEW: xargs
# Input:  "method\nparameter\n"
# Output: "method parameter"  ← No trailing space, naturally trimmed
```
