## 🎯 SUMMARY

**CRITICAL ISSUE DISCOVERED**: Component `.component.json` files are stored directly in component directories instead of the centralized scenario database. This violates MDA principles AND nearly caused catastrophic data loss.

**INCIDENT**: On 2025-11-11 23:06:25, commit `3781ceb81` DELETED the entire `scenarios/` folder (374 files, 12,295 lines, MONTHS of MDA work) because the AI misunderstood it as "test contamination". Only git history allowed restoration.

**ROOT CAUSE**: 
1. `.component.json` files stored in component dirs looked like test artifacts
2. No clear documentation that `scenarios/` is a PRODUCTION DATABASE
3. AI misunderstood scenario architecture during implementation

**CORRECT ARCHITECTURE**:
```
# Production
scenarios/{Component}/{Version}/{uuid}.scenario.json  ← Real scenario file
components/{Component}/{Version}/{Component}.component.json → symlink to scenarios/...

# Test Isolation  
test/data/scenarios/{Component}/{Version}/{uuid}.scenario.json  ← Real scenario file
test/data/components/{Component}/{Version}/{Component}.component.json → symlink to test/data/scenarios/...
```

#### **Phase 2: Fix create() Method**

**Changes to `DefaultWeb4TSComponent.create()`**:

1. **Generate UUID** for the scenario
2. **Calculate scenario path** in `scenarios/{GeneratingComponent}/{Version}/`
3. **Write scenario** to centralized storage
4. **Create symlink** from component dir to scenario
5. **Test isolation**: Use `test/data/scenarios/` instead of `scenarios/`

**Code Structure**:
```typescript
async create(component: string, version: string, options: string): Promise<void> {
  // ... existing component creation ...
  
  // Generate scenario UUID
  const scenarioUuid = crypto.randomUUID();
  
  // Determine scenarios directory (test isolation aware)
  const isTestIsolation = this.model.projectRoot.includes('/test/data');
  const scenariosRoot = isTestIsolation 
    ? path.join(this.model.projectRoot, 'scenarios')
    : path.join(this.model.projectRoot, '../../..', 'scenarios');
  
  // Calculate scenario path: scenarios/{GeneratingComponent}/{Version}/{uuid}.scenario.json
  const scenarioDir = path.join(scenariosRoot, this.model.component, this.model.version.toString());
  await fs.mkdir(scenarioDir, { recursive: true });
  
  // Write scenario to centralized storage
  const scenarioPath = path.join(scenarioDir, `${scenarioUuid}.scenario.json`);
  const scenario = await this.toScenario();
  await fs.writeFile(scenarioPath, JSON.stringify(scenario, null, 2));
  
  // Create symlink from component directory
  const symlinkPath = path.join(componentRoot, `${component}.component.json`);
  const relativePath = path.relative(componentRoot, scenarioPath);
  await fs.symlink(relativePath, symlinkPath);
  
  console.log(`   📊 Scenario: ${scenarioUuid}`);
  console.log(`   🔗 Symlink: ${component}.component.json → scenarios/${this.model.component}/${this.model.version}/`);
}
```

## 🚨 APPENDIX: Disaster Recovery Procedure

### If scenarios/ is Accidentally Deleted

**IMMEDIATE ACTIONS**:

```bash
# 1. STOP - Don't commit, don't push
git status

# 2. Check if scenarios/ is staged for deletion
git diff --cached --name-only | grep scenarios

# 3. If staged, unstage immediately
git restore --staged scenarios/

# 4. If deleted from working directory, restore from git
git checkout HEAD -- scenarios/

# 5. Verify restoration
ls -la scenarios/ | wc -l  # Should show 374+ files

# 6. If committed, revert the commit
git revert <commit-hash>

# 7. If pushed, create emergency recovery branch
git checkout -b emergency/restore-scenarios
git revert <commit-hash>
git push origin emergency/restore-scenarios
```

**RECOVERY FROM HISTORY**:

```bash
# Find the last good commit
git log --all --full-history --oneline -- scenarios/ | head -20

# Restore from specific commit
git checkout <commit-before-deletion>^ -- scenarios/

# Commit restoration
git add scenarios/
git commit -m "🚨 RESTORE: scenarios/ folder from commit <hash>"
git push
```

**PREVENTION**:

```bash
# Add git hook to prevent scenarios/ deletion
cat > .git/hooks/pre-commit << 'EOF'
#!/bin/bash
if git diff --cached --name-only | grep -q '^scenarios/'; then
  echo "🚨 WARNING: You are about to modify scenarios/ folder!"
  echo "This is a PRODUCTION DATABASE. Are you ABSOLUTELY sure?"
  read -p "Type 'I UNDERSTAND THE RISK' to continue: " confirmation
  if [ "$confirmation" != "I UNDERSTAND THE RISK" ]; then
    echo "❌ Commit aborted."
    exit 1
  fi
fi
EOF
chmod +x .git/hooks/pre-commit
```
