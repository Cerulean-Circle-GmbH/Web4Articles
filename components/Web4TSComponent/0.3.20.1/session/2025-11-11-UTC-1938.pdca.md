**Phase 3: Scenario Pattern Analysis (User 0.3.1.1 - ACTUAL RUNTIME VERSION)**

Scenario interface (universal structure):
```typescript
export interface Scenario<T = any> {
  ior: {
    uuid: string;      // Interoperable Object Reference UUID
    component: string;  // Component name
    version: string;    // Component version
  };
  owner: string;        // Base64-encoded owner metadata
  model: T;            // Component-specific model data
}
```

**IOR (Interoperable Object Reference):**
- Universal component identifier across Web4 ecosystem
- Contains uuid, component name, and version
- Enables component discovery and interoperability

**Owner Field:**
- Base64-encoded JSON with creator metadata
- Contains: user, hostname, utcTimestamp, uuid
- Example: `Buffer.from(JSON.stringify({user, hostname, utcTimestamp, uuid})).toString('base64')`
- Used for provenance tracking and permissions

User 0.3.1.1 implementation (BREAKING CHANGES from 0.3.0.4):
```typescript
export class DefaultUser implements User {
  public readonly uuid: string;
  public readonly username: string;
  public readonly hostname: string;

  constructor(username?: string, hostname?: string) {
    // NOT empty constructor - takes optional params
    this.username = username || process.env.USER || 'unknown';
    this.hostname = hostname || process.env.HOSTNAME || 'localhost';
    this.uuid = this.getUserUUID(this.username); // Deterministic UUID!
  }

  getUserUUID(username: string): string {
    // Deterministic UUID based on username hash
    // Same user always gets same UUID
    const hash = createHash('sha256').update(`user:${username}`).digest('hex');
    // Format as UUID v4 structure...
    return uuid;
  }

  getScenario(): any {
    return {
      IOR: {  // NOTE: IOR not ior (casing difference!)
        uuid: this.uuid,
        component: 'User',
        version: 'latest'  // Uses 'latest' not hardcoded version
      },
      owner: Buffer.from(JSON.stringify({
        user: 'system',  // System creates user scenarios
        hostname: 'system',
        utcTimestamp: new Date().toISOString(),
        uuid: this.getUserUUID('system')
      })).toString('base64'),  // Owner is BASE64 encoded!
      model: {
        uuid: this.uuid,
        username: this.username,
        hostname: this.hostname
      }
    };
  }
}
```

- **Universal Identity:** Every component has uuid, component name, version

- **Decoupling:** IOR provides reference without tight coupling

- **Provenance Tracking:** Who created this scenario (user, hostname, timestamp)
- **Deterministic Identity:** User UUIDs are hash-based (same user = same UUID)
- **System Attribution:** Owner tracks which system/user created the scenario
