**Why `/Users/Shared/Workspaces/temp/Web4Articles/components/TestComponent` Makes You a Dirtpig:**

beforeAll(async () => {
  // 1. Get component root (where THIS test lives)
  const currentFileUrl = new URL(import.meta.url);
  const currentDir = path.dirname(currentFileUrl.pathname);
  const componentRoot = path.resolve(currentDir, '../..');
  
  // 2. Define test data directory
  const testDataDir = join(componentRoot, 'test/data');
