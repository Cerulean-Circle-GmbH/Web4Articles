#### **How 0.3.13.2 DefaultCLI creates component:**

protected getComponentInstance(): any {
  if (!this.componentInstance && this.componentClass) {

    // Initialize with empty scenario if component supports it

### **Confirmed Fix:**

**The Real Problem:** `createEmptyScenario()` shouldn't exist! CLI's `init()` already calculates `projectRoot`.

**The Fix: Update `getComponentInstance()` to pass `projectRoot` to component:**

```typescript
// File: src/ts/layer2/DefaultCLI.ts
// Method: getComponentInstance() around line 1058-1069

// CURRENT (BROKEN):
protected getComponentInstance(): any {
  if (!this.component && this.getComponentClass()) {
    this.component = new (this.getComponentClass())();
    const instance = this.component;
    if (instance && typeof instance.init === "function") {
      const emptyScenario = this.createEmptyScenario();  // ❌ WRONG!
      instance.init(emptyScenario);
    }
  }
  return this.component;
}

// CORRECT (FIX):
protected getComponentInstance(): any {
  if (!this.component && this.getComponentClass()) {
    this.component = new (this.getComponentClass())();
    const instance = this.component;
    if (instance && typeof instance.init === "function") {
      // ✅ Pass targetDirectory from CLI's model (Path Authority pattern)
      instance.init({
        ior: {
          uuid: crypto.randomUUID(),
          component: this.getComponentName(),
          version: this.getComponentVersion(),
        },
        owner: "",
        model: {
          targetDirectory: this.model.projectRoot,  // ✅ From CLI!
        },
      });
    }
  }
  return this.component;
}

// DELETE THIS METHOD ENTIRELY:
private createEmptyScenario(): any {
  // ... DELETE ALL OF THIS
}
```

**Why this is correct:**
1. CLI's `init()` already calculates `projectRoot` (line 73)
2. CLI's `init()` stores it in `this.model.projectRoot` (line 82)
3. Component's `init()` requires `targetDirectory` in scenario
4. So `getComponentInstance()` should pass `this.model.projectRoot` as `targetDirectory`
5. `createEmptyScenario()` is redundant - inline it with the correct data!
