## Lessons Learned (CMM1 → CMM3)

### What Went Wrong (CMM1 Chaos)
1. ❌ **No build verification before commit** - Agent made 4 commits without running full build
2. ❌ **Tests not part of build** - `tsconfig.json` doesn't include test files
3. ❌ **Vitest bypassed TypeScript** - Running single tests with `npx vitest` doesn't compile ALL files
4. ❌ **No pre-commit hooks** - Nothing stops broken code from being committed
5. ❌ **No CI/CD pipeline** - No automated quality gates

### What Should Happen (CMM3)
1. ✅ **Test-first ALWAYS** - Run existing tests BEFORE making changes
2. ✅ **Build-first ALWAYS** - Full build must pass BEFORE committing
3. ✅ **Atomic commits** - Each commit must build + test successfully
4. ✅ **Pre-commit hooks** - Automated gates that BLOCK bad commits
5. ✅ **CI/CD pipeline** - GitHub Actions runs build + tests on every push

### CMM3 Git Protocol (CORRECTED)
```bash
# 1. BEFORE making changes
./src/sh/build.sh || { echo "❌ Build broken BEFORE changes!"; exit 1; }
npm test || { echo "❌ Tests broken BEFORE changes!"; exit 1; }

# 2. Make changes
# ... edit files ...

# 3. AFTER changes, BEFORE commit
./src/sh/build.sh || { echo "❌ YOU BROKE THE BUILD!"; exit 1; }
npm test || { echo "❌ YOU BROKE THE TESTS!"; exit 1; }

# 4. Only if both pass
git add -A
git commit -m "..."
git push
```
