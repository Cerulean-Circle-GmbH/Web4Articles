## Check

### Root Cause Hypothesis

The prompt line is being generated correctly by the CLI but is being **OVERWRITTEN** by bash's command-line redraw.

**Why**:
1. CLI outputs prompt line with `printf "%b"` (no newline)
2. Cursor stays on same line
3. Bash redraws its command line on the same line
4. Bash's redraw overwrites most of the prompt
5. Only last 3 characters `nks` (from "links") remain visible

### Verification Questions

1. **Is the blank `DISPLAY:` line causing an extra newline?**
   - Debug log shows: `DISPLAY: ` (blank line) before prompt
   - This might push prompt to a line that gets overwritten

2. **Has the order of DISPLAY lines changed?**
   - Need to compare 0.3.17.1 vs 0.3.17.3 output order

3. **Is there a missing newline after the prompt?**
   - Prompt needs NO newline (for bash to append completion)
   - But maybe the WORD line needs a newline before it?

4. **Why does 0.3.17.1 work but 0.3.17.3 doesn't with same source.env?**
   - Need to compare actual completion output format
   - Maybe 0.3.17.1 had different DISPLAY line ordering
