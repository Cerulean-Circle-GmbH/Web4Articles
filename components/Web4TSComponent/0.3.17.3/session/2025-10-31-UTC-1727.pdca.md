### **SECTION 1: Radical OOP vs Functional Programming**

#### **What is Radical OOP?**

**Radical OOP Principles (Web4):**
1. **Empty Constructor** - No parameters, zero initialization logic
2. **init(scenario)** - ALL configuration via scenario
3. **Model Storage** - State lives in `this.model`, not scattered fields
4. **Direct Access Internally** - Access model directly: `this.model.projectRoot`
5. **Getters ONLY for Public Interfaces** - Inter-component access only, NOT internal
6. **Type Safety** - NEVER use `any` type, always use proper interfaces
7. **NO Ternary Logic in Models** - `version: isVersionDir ? x : y` is FORBIDDEN functional shit
8. **Proper Types Only** - `version` is of type `Version`, not string with logic
9. **Values, Not Calculations** - Model fields are values, never calculated expressions
10. **Interface/Implementation Pattern** - `Version` is interface, use concrete implementation `SemanticVersion`
11. **Default Initialization** - `new SemanticVersion().init()` (default: "0.1.0.0"), NOT `new Version('0.0.0.0')`
12. **Single Source of Truth** - Each responsibility has ONE authoritative location
13. **Path Authority** - CLI calculates ALL paths ONCE in `init()`, component receives them
14. **Component Identity via toScenario()** - Components provide their own IOR, owner, version via `toScenario()`
15. **NO Hardcoded Scenarios** - NEVER hardcode `ior`, `owner`, or `version` - use `component.toScenario()` + modify
16. **User Service Integration** - `owner` field uses `User.toScenario()` (base64 encoded), NOT empty string
17. **targetDirectory Defaults** - Default is `projectRoot`, test isolation uses `testDataDir` (component version + `test/data`)
18. **NO Required Fields in init()** - Component provides sensible defaults, scenario enhances them (NEVER throw on missing fields)
19. **Direct Model Enhancement** - After init(), CLI sets paths via direct model assignment (NO re-init!): `component.model.projectRoot = ...`

**Example - Radical OOP:**
```typescript
// ✅ CORRECT: Radical OOP with Reference<T>
import { Reference } from '../layer3/Reference.interface.js';

class DefaultCLI {
  protected model: CLIModel = null as any;
  protected component: Reference<DefaultWeb4TSComponent> = null;
  protected context: Reference<DefaultWeb4TSComponent> = null;
  
  constructor() {
    // Empty - no logic!
  }
  
  init(scenario?) {
    // Calculate paths ONCE
    const projectRoot = this.calculateProjectRootInternal();
    
    this.model = {
      uuid: crypto.randomUUID(),
      projectRoot: projectRoot,              // ✅ Stored ONCE
      componentsDir: join(projectRoot, 'components'),
      scriptsDir: join(projectRoot, 'scripts'),
      // ... all paths calculated and stored
    };
    
    if (scenario?.model) {
      this.model = { ...this.model, ...scenario.model };
    }
    
    return this;
  }
  
  // ✅ INTERNAL: Direct access to model (no getters!)
  someMethod() {
    const root = this.model.projectRoot;  // Direct access!
    const comps = this.model.componentsDir;  // Direct access!
    
    // ✅ Type-safe null checking with Reference<T>
    if (this.component) {
      const version = this.component.model.version;  // Type-safe!
    }
  }
  
  // ✅ PUBLIC: Getter for inter-component access ONLY
  public getProjectRoot(): string {
    return this.model.projectRoot;
  }
}
```

**Functional Programming Anti-Pattern:**
```typescript

  private componentVersion: string;

    if (!this.component) {
      throw new Error('Component not loaded');  // State checking

      if (instance && typeof instance.init === "function") {
```

**Key Differences:**

| Aspect | Radical OOP ✅ | Functional ❌ |
|--------|---------------|---------------|
| **State Storage** | `this.model` (single object) | Scattered fields (`componentClass`, `componentName`, etc.) |
| **Initialization** | `init()` creates complete model | Multiple methods create scenarios ad-hoc |
| **Path Calculation** | ONCE in `init()`, stored in model | Recalculated on demand |
| **Internal Access** | Direct: `this.model.projectRoot` | Functional getters: `getProjectRoot()` |
| **Inter-Component Access** | Public getter: `public getProjectRoot()` | N/A |
| **Type Safety** | `Reference<DefaultWeb4TSComponent>` | `any` ❌ |
| **Version Type** | `version: Version` (interface)<br/>`new SemanticVersion().init()` (impl) | `version: isVersionDir ? x : '0.0.0'` ❌<br/>`new Version('0.0.0.0')` ❌ |
| **Model Values** | Values only, no logic | Ternary conditionals in assignments ❌ |
| **One Type Per File** | `Reference.interface.ts` | Types mixed in files |
| **Scenario Creation** | Component provides via `toScenario()`,<br/>CLI modifies with paths | Hardcoded IOR/owner/version ❌ |
| **Owner Field** | `User.toScenario()` (base64 encoded) | Empty string `""` ❌ |
| **Component Identity** | `component.toScenario()` + modify | Hardcoded in CLI ❌ |

```typescript
  if (!this.methodSignatures.has(command)) {

  }

  const signature = this.methodSignatures.get(command)!;

  // Priority: CLI method > Context method > Component method
  if (typeof (this as any)[command] === 'function') {

    const method = (this as any)[command];
    if (signature.isAsync) {

    } else {
      method.apply(this, args);
    }
  } else if (this.context && typeof this.context[command] === 'function') {

    if (signature.isAsync) {
```
