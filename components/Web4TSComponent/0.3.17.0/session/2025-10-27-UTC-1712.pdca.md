**7. Implementation Options Analysis**

**Option A: nvm-based Installation**
- **Pros:** Standard Node.js version management, widely used
- **Cons:** Requires curl/wget, bash (not sh), git for some operations
- **Complexity:** High (many dependencies)

**Option B: Official Node.js Binary Download**
- **Pros:** Direct download, fewer dependencies, platform-specific binaries available
- **Cons:** Need to detect OS/architecture, manual PATH management
- **Complexity:** Medium

**Option C: System Package Manager**
- **Pros:** Standard installation method
- **Cons:** Requires sudo/root access, varies by OS (apt, brew, yum), violates "zero preconditions"
- **Complexity:** Low per-platform but high overall

**Option D: Bundled Node.js**
- **Pros:** No installation needed, truly zero preconditions
- **Cons:** Large repository size, platform-specific binaries, licensing concerns
- **Complexity:** Low runtime, high distribution

**8. Recommended Approach (Hybrid)**

```bash
# bootstrap.sh - Intelligent detection and installation

#!/bin/sh

# Try to find npm in standard locations
for path in /usr/local/bin /usr/bin /opt/homebrew/bin ~/.nvm/versions/node/*/bin; do
    if [ -x "$path/npm" ]; then
        export PATH="$path:$PATH"
        echo "✅ Found npm at $path"
        exec ./src/sh/start.sh
    fi
done

# If not found, attempt download and local install
echo "🚀 Black start mode: Installing Node.js locally..."

# Detect OS and architecture
OS=$(uname -s | tr '[:upper:]' '[:lower:]')
ARCH=$(uname -m)

case "$ARCH" in
    x86_64) ARCH="x64" ;;
    aarch64|arm64) ARCH="arm64" ;;
    *) echo "❌ Unsupported architecture: $ARCH"; exit 1 ;;
esac

# Download Node.js binary (latest LTS)
NODE_VERSION="v20.10.0"  # Hardcode stable LTS version
NODE_URL="https://nodejs.org/dist/${NODE_VERSION}/node-${NODE_VERSION}-${OS}-${ARCH}.tar.gz"

# Create local installation directory
LOCAL_NODE="./node_local"
mkdir -p "$LOCAL_NODE"

# Download (requires curl or wget)
if command -v curl >/dev/null 2>&1; then
    curl -fsSL "$NODE_URL" | tar -xz -C "$LOCAL_NODE" --strip-components=1
elif command -v wget >/dev/null 2>&1; then
    wget -qO- "$NODE_URL" | tar -xz -C "$LOCAL_NODE" --strip-components=1
else
    echo "❌ Neither curl nor wget found - cannot download Node.js"
    echo "💡 Please install curl or wget, or install Node.js manually"
    exit 1
fi

# Verify installation
if [ -x "$LOCAL_NODE/bin/npm" ]; then
    export PATH="$LOCAL_NODE/bin:$PATH"
    echo "✅ Node.js installed locally at $LOCAL_NODE"
    exec ./src/sh/start.sh
else
    echo "❌ Node.js installation failed"
    exit 1
fi
```
