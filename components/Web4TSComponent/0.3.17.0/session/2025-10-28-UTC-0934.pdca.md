### **Path Calculation Separation Plan** 🎯 **NEW - CRITICAL**

> **User Feedback (2025-10-28):**
> "@DefaultCLI.ts should be aware of all path calculations and responsible for all path calculations and can be used by the web4tscomponent that should NOT try to repeat any path calculations. it should only be aware of the component and the component context, its files, folders and tests and symlinks and templates. so DefaultCLI knows projectRoot, the component dir, the scripts dir, the scripts version dir the componentes test dir.... the component knows its componentName/version directory and everything relative to that. review the pdca for this radical separation of responsibilities, that will help you while implementation. add testcases to make sure there is no further repetition of this kind of code."

**Critical Architectural Principle (Responsibility Separation):**

| Responsibility | DefaultCLI (Path Authority) | DefaultWeb4TSComponent (Component Authority) |
|---------------|----------------------------|---------------------------------------------|
| **Absolute Paths** | ✅ `projectRoot`, `components/`, `scripts/`, `test/data/` | ❌ Never calculates absolute paths |
| **Path Calculation** | ✅ Single source of truth for ALL absolute paths | ❌ Uses CLI services for absolute paths |
| **Project Structure** | ✅ Knows project-level directories | ❌ Doesn't know project structure |
| **Component Structure** | ❌ Doesn't know component internals | ✅ Knows `src/`, `dist/`, `test/`, `session/` |
| **Relative Paths** | ❌ Doesn't work with relative paths | ✅ All paths relative to component root |

**2. DefaultCLI - Path Authority (Absolute Paths Only)**
```typescript
export class DefaultCLI {
  init(scenario?: Scenario<CLIModel>): this {
    if (!this.model) {
      const projectRoot = this.calculateProjectRoot();  // ✅ SINGLE SOURCE OF TRUTH
      
      this.model = {
        uuid: randomUUID(),
        projectRoot: projectRoot,
        componentsDir: join(projectRoot, 'components'),
        scriptsDir: join(projectRoot, 'scripts'),
        scriptsVersionDir: join(projectRoot, 'scripts', 'versions'),
        testDataDir: join(projectRoot, 'test', 'data'),
      };
    }
    return this;
  }
  
  /**
   * Calculate project root - SINGLE SOURCE OF TRUTH
   * @cliHide
   */
  private calculateProjectRoot(): string {
    // 1. Try WEB4_PROJECT_ROOT
    if (process.env.WEB4_PROJECT_ROOT) {
      return process.env.WEB4_PROJECT_ROOT;
    }
    
    // 2. Try git root
    try {
      const gitRoot = execSync('git rev-parse --show-toplevel', { encoding: 'utf8' }).trim();
      if (existsSync(gitRoot)) return gitRoot;
    } catch {}
    
    // 3. Traverse up for .git + package.json
    let current = process.cwd();
    while (current !== '/') {
      if (existsSync(join(current, '.git')) && existsSync(join(current, 'package.json'))) {
        return current;
      }
      current = join(current, '..');
    }
    
    // 4. Fallback
    return process.cwd();
  }
  
  /**
   * Get component directory (absolute) - PATH SERVICE
   * @cliHide
   */
  getComponentDir(componentName: string, version: string): string {
    return join(this.model.componentsDir, componentName, version);
  }
  
  /**
   * Get component test directory (absolute) - PATH SERVICE
   * @cliHide
   */
  getComponentTestDir(componentName: string, version: string): string {
    return join(this.getComponentDir(componentName, version), 'test');
  }
}
```

### **Init() Pattern Refactoring Plan**

> **User Feedback (2025-10-28):**
> "in DefaultCLI createEmptyModel does the job that normally is to be done by init. The default Web4 instantiation pattern is `let component = new DefaultComponent().init();` perfect would be even `let component = DefaultComponent.new.init();` for ALL Web4 components. IF the init has the optional parameter, it initializes the model from the scenario instead."

**Current Problem:**
- `createEmptyModel()` is called in `constructor()` - violates Web4 pattern
- `init()` only merges scenario data, doesn't create empty model
- Can't do `new DefaultComponent()` without initialization

**Target Pattern:**
```typescript
// Empty initialization
let component = new DefaultComponent().init();

// Future: Static factory
let component = DefaultComponent.new.init();

// With scenario
let component = new DefaultComponent().init(scenario);
```

**Refactoring Strategy:**

1. **Update Component Interface**
```typescript
export interface Component<TModel extends Model = Model> {
  init(scenario?: Scenario<TModel>): this;  // Make scenario optional
  toScenario(name?: string): Promise<Scenario<TModel>>;
}
```

```typescript
import { VersionModel } from '../layer3/VersionModel.interface.js';

import { randomUUID } from 'crypto';

export class SemanticVersion implements Version {
  private model!: VersionModel;
  
  /**
   * Empty constructor - Web4 radical OOP pattern
   */
  constructor() {
    // Empty - all initialization in init()
  }
  
  /**
   * Initialize with scenario
   */
  init(scenario?: Scenario<VersionModel>): this {
    if (!this.model) {
      this.model = {
        uuid: randomUUID(),
        name: 'version',
        origin: 'system',
        definition: 'SemanticVersion component',
        major: 0,
        minor: 0,
        patch: 0,
        revision: 0,
        versionString: '0.0.0.0'
      };
    }
    
    if (scenario?.model) {
      this.model = { ...this.model, ...scenario.model };
    }
    
    return this;

    return new SemanticVersion().init().parse(version);
  }
  
  /**
   * Parse version string and update model
   */
  parse(version: string): this {
    const pattern = /^(\d+)\.(\d+)\.(\d+)\.(\d+)$/;
    const match = version.match(pattern);
    
    if (!match) {
      throw new Error(`Invalid version format: ${version}. Expected X.Y.Z.W`);
    }
    
    const [, major, minor, patch, revision] = match.map(Number);
    
    this.model.major = major;
    this.model.minor = minor;
    this.model.patch = patch;
    this.model.revision = revision;
    this.model.versionString = version;
    
    return this;
  }

   * Immutable: Returns NEW component instance

    const newVersion = new SemanticVersion().init();
    newVersion.model.major = this.model.major + 1;
    newVersion.model.minor = 0;
    newVersion.model.patch = 0;
    newVersion.model.revision = 0;
    newVersion.model.versionString = `${newVersion.model.major}.0.0.0`;
    return newVersion;
  }

    return this.model.versionString;
  }

    const otherModel = (other as SemanticVersion).model;
    
    if (this.model.major !== otherModel.major) return this.model.major - otherModel.major;
    if (this.model.minor !== otherModel.minor) return this.model.minor - otherModel.minor;
    if (this.model.patch !== otherModel.patch) return this.model.patch - otherModel.patch;
    return this.model.revision - otherModel.revision;
```

```typescript
export class DefaultWeb4TSComponent implements Web4TSComponent {
  private model!: Web4TSComponentModel;
  
  constructor() {
    // Empty constructor
  }
  
  init(scenario?: Scenario<Web4TSComponentModel>): this {
    if (!this.model) {
      // Discover version from directory
      const currentFileUrl = new URL(import.meta.url);
      const currentVersionDir = path.resolve(path.dirname(currentFileUrl.pathname), '..', '..', '..');
      const componentDirName = path.basename(currentVersionDir);
      
      // ✅ Create version INSTANCE
      const versionComponent = SemanticVersion.fromString(componentDirName);
      
      this.model = {
        uuid: randomUUID(),
        component: 'Web4TSComponent',
        version: versionComponent,  // ✅ INSTANCE, not versionComponent.model!
      };
    }
    
    if (scenario?.model) {
      this.model = { ...this.model, ...scenario.model };
      // ✅ If scenario has version data, reconstruct instance
      if (scenario.model.version && !(scenario.model.version instanceof SemanticVersion)) {
        this.model.version = new SemanticVersion().init({ 
          model: scenario.model.version as any 
        });
      }
    }
    
    return this;
  }
  
  /**
   * Upgrade component to next revision (default)
   * ✅ RADICAL OOP: Direct instance operation (no reconstruction!)
   */
  async upgrade(type: 'major' | 'minor' | 'patch' | 'revision' = 'revision'): Promise<this> {
    // ✅ Direct instance operation!
    switch (type) {
      case 'major':
        this.model.version = await this.model.version.promoteMajor() as SemanticVersion;
        break;
      case 'minor':
        this.model.version = await this.model.version.promoteMinor() as SemanticVersion;
        break;
      case 'patch':
        this.model.version = await this.model.version.promotePatch() as SemanticVersion;
        break;
      case 'revision':
        this.model.version = await this.model.version.promoteRevision() as SemanticVersion;
        break;
    }
    
    // ✅ No reconstruction, no model sync - instance persists!
    return this;
  }
```

```typescript
/**
 * ScenarioStore - Universal persistence service for ALL Web4 components
 * Single source of truth for serialization/deserialization
 * Zero duplication across entire Web4 ecosystem
 */
export class ScenarioStore implements Component<ScenarioStoreModel> {
  private model!: ScenarioStoreModel;
  
  constructor() {}
  
  init(scenario?: Scenario<ScenarioStoreModel>): this {
    if (!this.model) {
      this.model = {
        uuid: randomUUID(),
        storageDir: './scenarios',  // Configurable via scenario
        encryption: false,          // Future: encrypt owner data
      };
    }
    if (scenario?.model) {
      this.model = { ...this.model, ...scenario.model };
    }
    return this;
  }
  
  /**
   * Save ANY component to scenario (universal serialization)
   * Handles INSTANCE → data extraction automatically
   */
  async save<T extends Model>(component: Component<T>, name?: string): Promise<Scenario<T>> {
    const scenario: Scenario<T> = {
      ior: this.extractIOR(component),
      owner: await this.extractOwner(component),
      model: this.extractModel(component.model)  // ✅ RECURSIVE extraction!
    };
    
    // Write to file if name provided
    if (name) {
      const filePath = join(this.model.storageDir, `${name}.scenario.json`);
      await writeFile(filePath, JSON.stringify(scenario, null, 2));
    }
    
    return scenario;
  }
  
  /**
   * Load scenario and reconstruct component (universal deserialization)
   */
  async load<T extends Model>(
    scenarioPath: string, 
    ComponentClass: new () => Component<T>
  ): Promise<Component<T>> {
    const scenarioJson = await readFile(scenarioPath, 'utf8');
    const scenario = JSON.parse(scenarioJson) as Scenario<T>;
    
    // ✅ Component's init() reconstructs instances from scenario data
    const component = new ComponentClass().init(scenario);
    return component;
  }
  
  /**
   * Recursively extract data from model (handles nested instances)
   * @private
   */
  private extractModel(model: any): any {
    const result: any = {};
    
    for (const [key, value] of Object.entries(model)) {
      if (this.isComponent(value)) {
        // ✅ Found component instance - recursively extract its model
        result[key] = this.extractModel((value as any).model);
      } else if (Array.isArray(value)) {
        // ✅ Array - check each element
        result[key] = value.map(v => 
          this.isComponent(v) ? this.extractModel((v as any).model) : v
        );
      } else if (value && typeof value === 'object' && value.constructor === Object) {
        // ✅ Plain object - recurse
        result[key] = this.extractModel(value);
      } else {
        // ✅ Primitive value
        result[key] = value;
      }
    }
    
    return result;
  }
  
  /**
   * Check if value is a Web4 component instance
   * @private
   */
  private isComponent(value: any): boolean {
    return value && 
           typeof value === 'object' && 
           typeof value.init === 'function' &&
           value.model !== undefined;
  }
  
  /**
   * Extract IOR from component
   * @private
   */
  private extractIOR(component: any): IOR {
    // Extract from model or generate
    return {
      uuid: component.model.uuid,
      component: component.model.component || component.constructor.name,
      version: component.model.version?.toString?.() || '0.0.0.0'
    };
  }
  
  /**
   * Extract owner data (uses User service if available)
   * @private
   */
  private async extractOwner(component: any): Promise<string> {
    // Check if component has User service reference
    if (component.model.user && typeof component.model.user.generateOwnerData === 'function') {
      const ownerJson = await component.model.user.generateOwnerData({
        uuid: component.model.uuid,
        component: component.model.component,
        version: component.model.version?.toString?.()
      });
      
      // Base64 encode (mock-up for encryption)
      return Buffer.from(ownerJson).toString('base64');
    }
    
    // Fallback: simple owner data
    return JSON.stringify({
      user: process.env.USER || 'system',
      hostname: process.env.HOSTNAME || 'localhost',
      uuid: component.model.uuid,
      timestamp: new Date().toISOString()
    });
  }
}
```
