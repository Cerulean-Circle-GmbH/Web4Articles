## Summary

### Problem Statement

**CRITICAL DRY VIOLATIONS IN CLIModel:**

```typescript:32:50:components/Web4TSComponent/0.3.17.1/src/ts/layer3/CLIModel.interface.ts
  /**
   * Web4TSComponent instance (not componentClass reference!)
   * @pdca 2025-10-28-UTC-0934.pdca.md:1153 - Stores INSTANCE
   */
  component?: DefaultWeb4TSComponent;
  
  /**
   * User service instance
   * @pdca 2025-10-28-UTC-0934.pdca.md:1153 - Stores INSTANCE
   */
  user?: User;
  
  /**
   * UNIFIED CONTEXT: Single source of truth for delegation
   * Replaces Web4TSComponentModel.context - context belongs to CLI, not component!
   * Target component loaded via on() for cross-component operations
   * @pdca 2025-10-30-UTC-1011.pdca.md - Moved from Web4TSComponentModel to CLIModel
   */
  context?: DefaultWeb4TSComponent;
```

**Problem:** These are **INSTANCE VARIABLES**, not model data!
- ❌ `component` - DefaultCLI's own component instance
- ❌ `context` - DefaultCLI's loaded context for `on()` delegation
- ❌ `user` - DefaultCLI's user service instance

**Model Purpose (Web4 Architecture):**
- ✅ Model = **DATA** (strings, numbers, booleans, arrays)
- ✅ Model = **SERIALIZABLE** (toScenario() / fromScenario())
- ❌ Model ≠ **INSTANCES** (components, services, references)

**Evidence of Confusion:**

Generated component CLI duplicates this pattern:
```typescript:13:29:test/data/components/TestIsolatedComponent/0.1.0.0/src/ts/layer5/TestIsolatedComponentCLI.ts
export class TestIsolatedComponentCLI extends DefaultCLI {
  private component: DefaultTestIsolatedComponent | null;  // ✅ CORRECT - instance variable
  
  constructor() {
    super();
    this.component = null;  // ✅ Initialize instance variable
    
    this.init();
    
    // ❌ WRONG - Also stores in model!
    const tempComponent = new DefaultTestIsolatedComponent().init();
    this.model.component = tempComponent as any;  // ❌ DRY VIOLATION
    
    this.discoverMethods();
  }
```

**Result:** Component stored in TWO places:
1. `this.component` (correct - instance variable)
2. `this.model.component` (wrong - pollutes model)
