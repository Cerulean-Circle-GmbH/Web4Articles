## Summary

### Problem Statement

**🔴 CRITICAL BUG: Wrong Template Used + Wrong Versions Hardcoded**

**File Created:** `/test/data/package.json`

**Created By:** `DefaultWeb4TSComponent.initProject()` method (line 969)

**Wrong Template Used:**
```typescript
// Line 969: Uses WRONG template
const packageJsonContent = await this.loadTemplate('config/root-package.json.template', {});
```

**Should Use:**
- ❌ NOT `config/root-package.json.template` (this is for PROJECT ROOT)
- ✅ NEVER - test/data IS the project root in test isolation!

**The REAL Problem:**

`test/data/package.json` is created by `initProject()` which is designed for **PROJECT ROOT initialization**, NOT component creation!

The template `root-package.json.template` contains:
```json
{
  "name": "web4-project",           // ❌ Generic project name
  "version": "1.0.0",               // ❌ Generic version
  "type": "module",
  "description": "Web4 Component Architecture Project",
  "private": true,
  "devDependencies": {
    "@types/node": "^24.1.0",       // ❌ WRONG VERSION (doesn't exist!)
    "typescript": "^5.9.3",         // ❌ WRONG VERSION (doesn't exist!)
    "vitest": "^3.2.4"
  }
}
```

**What SHOULD happen:**

When a component creates `test/data/` as its isolated project root:
1. `test/data/package.json` should be project root config (CORRECT - what it is now)
2. BUT it should use CORRECT versions from master Web4TSComponent package.json
3. Components created INSIDE test/data should use `package.json.template` for their own package.json

### Phase 2: Create Version Sync Test

**New Test:** `test/vitest/template-version-sync.test.ts`

```typescript
describe('Template Version Synchronization', () => {
  it('should have matching versions across all templates and scripts', async () => {
    // Read master package.json (source of truth)
    const masterPkg = JSON.parse(
      await readFile('package.json', 'utf-8')
    );
    
    // Read all templates
    const rootPkgTemplate = await readFile(
      'templates/config/root-package.json.template', 'utf-8'
    );
    const componentPkgTemplate = await readFile(
      'templates/config/package.json.template', 'utf-8'
    );
    const installDeps = await readFile(
      'src/sh/install-deps.sh', 'utf-8'
    );
    
    // Extract versions from templates
    const rootVersions = JSON.parse(rootPkgTemplate.replace(/\{\{.*?\}\}/g, '""'));
    const componentVersions = JSON.parse(componentPkgTemplate.replace(/\{\{.*?\}\}/g, '""'));
    
    // Verify all match master
    expect(rootVersions.devDependencies['@types/node'])
      .toBe(masterPkg.devDependencies['@types/node']);
    expect(rootVersions.devDependencies.typescript)
      .toBe(masterPkg.devDependencies.typescript);
    
    // Verify shell script matches
    expect(installDeps).toContain(masterPkg.devDependencies['@types/node']);
    expect(installDeps).toContain(masterPkg.devDependencies.typescript);
  });
});
```

**Purpose:** Automatically detect when templates drift from master package.json

### Phase 3: Long-Term Solution - Dynamic Version Reading

**Option A: Template Placeholders**

Update templates to use placeholders:
```json
{
  "devDependencies": {
    "@types/node": "{{TYPES_NODE_VERSION}}",
    "typescript": "{{TYPESCRIPT_VERSION}}",
    "vitest": "{{VITEST_VERSION}}"
  }
}
```

Update `loadTemplate()` to read master package.json and replace:
```typescript
private async loadTemplate(templatePath: string, replacements: Record<string, string>): Promise<string> {
  // Read master package.json
  const masterPkgPath = path.join(currentDir, '../../../package.json');
  const masterPkg = JSON.parse(await readFile(masterPkgPath, 'utf-8'));
  
  // Add version replacements
  replacements.TYPES_NODE_VERSION = masterPkg.devDependencies['@types/node'];
  replacements.TYPESCRIPT_VERSION = masterPkg.devDependencies['typescript'];
  replacements.VITEST_VERSION = masterPkg.devDependencies['vitest'];
  replacements.GLOB_VERSION = masterPkg.dependencies['glob'];
  replacements.MINIMATCH_VERSION = masterPkg.dependencies['minimatch'];
  
  // ... rest of loadTemplate logic
}
```

**Option B: Direct JSON Read During initProject()**

```typescript
// In initProject() line 969:
const masterPkgPath = path.join(currentDir, '../../../package.json');
const masterPkg = JSON.parse(await readFile(masterPkgPath, 'utf-8'));

// Read template
let packageJsonContent = await this.loadTemplate('config/root-package.json.template', {});

// Replace versions dynamically
const pkg = JSON.parse(packageJsonContent);
pkg.devDependencies = masterPkg.devDependencies;
pkg.dependencies = masterPkg.dependencies;
packageJsonContent = JSON.stringify(pkg, null, 2);

await fs.writeFile(packageJsonPath, packageJsonContent);
```
