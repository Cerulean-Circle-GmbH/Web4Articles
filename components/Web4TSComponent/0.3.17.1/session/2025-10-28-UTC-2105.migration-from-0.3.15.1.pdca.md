### **🎯 CRITICAL: Path Resolution Bug Fix**

**Status:** ❌ **MISSING** in 0.3.17.1  
**Impact:** **BREAKING** - CLI commands fail, test discovery broken  

**Root Issue Fixed in 0.3.15.1:**
- `findProjectRoot()` was using `process.cwd()` instead of `targetDirectory`
- Components with nested `components/` directories stopped search at wrong level
- Result: Path duplication, 1 test found instead of 25+

**Fix Pattern (0.3.15.1):**
```typescript
// FIXED in 0.3.15.1 - components/Web4TSComponent/0.3.15.1/src/ts/layer2/DefaultWeb4TSComponent.ts:33
const discoveredRoot = this.findProjectRootFrom(path.dirname(path.dirname(currentVersionDir)));

// FIXED in 0.3.15.1 - components/Web4TSComponent/0.3.15.1/src/ts/layer2/DefaultWeb4TSComponent.ts:215-217
private findProjectRoot(): string {
  return this.model.targetDirectory;
}
```
