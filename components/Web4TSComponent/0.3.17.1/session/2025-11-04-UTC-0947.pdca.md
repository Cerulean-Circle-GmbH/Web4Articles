**4. CMM3 Compliance Check (cmm3check)**
```bash
# Validate PDCA compliance
pdca cmm3check <file>

- 1l: Missing DoR/DoD sections (new mandatory requirement)
- 3a-3c, 4a-4d, 5a/5c, 6a, 7a/7b: Link format, timestamps, etc.

# Auto-fix available for some violations (dry-run supported)
```
