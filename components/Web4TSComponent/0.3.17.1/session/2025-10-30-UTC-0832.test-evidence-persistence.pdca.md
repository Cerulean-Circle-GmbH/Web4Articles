## Summary

### Problem Statement

User feedback: "see the folders in test/data, but the component artifacts are gone. the ruel is to clean before the next test run and let the test results - the evidence - in test/data without deleting it. test/data becomes a testable alternate isolated project root."

**Current Violation:**

```typescript
// ❌ WRONG: test/vitest/component-creation-isolation.test.ts:33-40
afterAll(async () => {
  // Cleanup: Remove created test component
  const testComponentsDir = path.join(testDataDir, 'components', testComponentName);
  if (existsSync(testComponentsDir)) {
    await rm(testComponentsDir, { recursive: true, force: true });  // ❌ DELETES EVIDENCE!
    console.log(`   🧹 Cleaned up: ${testComponentName}`);
  }
});
```

**Correct Pattern:**
- ✅ **beforeAll:** Clean test/data (remove old evidence)
- ✅ **Test runs:** Create components in test/data
- ✅ **afterAll:** DO NOTHING - keep evidence for inspection
- ✅ **Next run:** beforeAll cleans again (fresh start)

**Key Principle:**
> test/data becomes a **testable alternate isolated project root** - it should contain EVIDENCE of what the tests created, allowing manual inspection and validation.

## Plan

### Root Cause Analysis

**Why this exists:**
- Traditional test pattern: "clean up after yourself"
- But for **evidence-based testing**, we want artifacts to persist
- test/data is NOT production - it's a sandbox for inspection
- Each test run should start fresh but LEAVE evidence

**Impact:**
- ❌ Cannot inspect test results manually
- ❌ Cannot verify generated file structure
- ❌ Cannot debug test failures (evidence deleted)
- ✅ But: Test isolation DOES work (just removes evidence)

**Correct Pattern (Evidence-Based Testing):**

1. **beforeAll:** Clean slate (remove old evidence)
2. **Tests run:** Create components, verify structure
3. **Tests pass/fail:** Results visible in test/data
4. **afterAll:** DO NOTHING (keep evidence)
5. **Developer:** Can cd to test/data and inspect/run commands
6. **Next run:** beforeAll cleans old evidence, creates new

### Goals

1. ✅ **Change cleanup timing:**
   - Move cleanup from afterAll to beforeAll
   - Remove afterAll hook entirely

2. ✅ **Add .gitignore for test/data:**
   - Ignore components/ subdirectory
   - Ignore scripts/ subdirectory
   - Keep .gitignore itself in git

3. ✅ **Document the pattern:**
   - Add comment explaining evidence persistence
   - Reference this PDCA in test file

4. ✅ **Verify evidence persists:**
   - Run tests
   - Verify test/data/components/TestIsolatedComponent exists
   - Verify can cd into it and inspect

### Process Improvements

**Key Learnings:**

1. ✅ **Evidence-Based Testing Pattern:**
   - Clean BEFORE tests (fresh start)
   - Let tests run and create artifacts
   - Keep evidence AFTER tests (inspection)
   - Next run cleans old evidence automatically
   - Pattern: `beforeAll: clean → tests: create → afterAll: NONE`

2. ✅ **test/data as Alternate Project Root:**
   - Not just temporary files - real components
   - Can cd into and test manually
   - Complete with package.json, CLI, build system
   - Serves as working example for inspection
   - Demonstrates "what the tests actually create"

3. ✅ **Git Strategy for Test Evidence:**
   - test/data structure tracked (directories)
   - test/data contents ignored (.gitignore)
   - Evidence is local and reproducible
   - Each developer gets their own evidence
   - No pollution of git history with test artifacts

4. ✅ **Developer Experience Benefits:**
   - Visual confirmation of test output
   - Can inspect generated code quality
   - Can debug test failures by examining artifacts
   - Can manually verify delegation pattern
   - Can run commands on generated components

**Anti-Pattern Avoided:**

❌ **Traditional "Clean Up After Yourself":**
```typescript
afterAll(() => {
  rm(testArtifacts);  // ❌ Removes evidence!
});
```

✅ **Evidence-Based "Clean Before Next Run":**
```typescript
beforeAll(() => {
  rm(oldEvidence);    // ✅ Fresh start
});
// NO afterAll - keep evidence for inspection!
```

**Template for Future Tests:**

```typescript
/**
 * Evidence-Based Testing Pattern:
 * - beforeAll: Clean OLD evidence (fresh start)
 * - Tests run: Create artifacts in test/data

 */

// ✅ NO afterAll - evidence persists
```
