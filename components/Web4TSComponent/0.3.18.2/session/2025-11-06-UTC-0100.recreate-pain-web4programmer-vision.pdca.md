## Problem Statement

**Context**: When infrastructure (Web4TSComponent templates) gets updated, there are TWO types of components:

### Type 1: IdealMinimalComponent (Empty Test Component) ✅ EASY
```bash
web4tscomponent removeVersion IdealMinimalComponent 0.3.18.0
web4tscomponent create IdealMinimalComponent 0.3.18.0
# ✅ DONE - No pain, no loss!
```

**Why Easy**:
- No real methods
- No business logic
- No valuable work
- Pure template test
- Recreate = instant fix

### Type 2: PDCA Component (Production Component) ❌ DANGEROUS PAIN

**What Lives in PDCA Component**:
```typescript
// src/ts/layer2/DefaultPDCA.ts

class DefaultPDCA extends Component {
  // ❌ VALUABLE METHODS that will be LOST on recreate:
  async planPhase(): Promise<this> { /* complex logic */ }

  async actPhase(): Promise<this> { /* complex logic */ }
  
  async createFromTemplate(templateName: string): Promise<this> { /* custom */ }

  // ❌ VALUABLE MODEL PROPERTIES:
  model: PDCAModel = {
    phase: 'PLAN' | 'DO' | 'CHECK' | 'ACT',
    templatePath: string,

**If You Recreate**: ❌ **ALL OF THIS IS DELETED!!!**

```bash
web4tscomponent removeVersion PDCA 0.2.5
# ❌ POOF! Weeks of work GONE!

# ✅ You get latest templates...
# ❌ But you get EMPTY component with NO methods!
```

**The PAIN**:
1. **Data Loss**: All methods, logic, completions → GONE
2. **Manual Work**: Must manually copy/paste everything back
3. **Merge Hell**: Must merge old code with new template structure
4. **Error Prone**: Easy to miss things, introduce bugs
5. **Time Sink**: Hours/days of work to restore functionality
6. **Risk**: Might break things that were working

**The DANGER**:
- Accidentally recreate production component → Lose weeks of work
- Miss copying a critical method → Production breakage
- Introduce bugs during manual merge → Hard to debug
- Lose TSDoc → Documentation gone
- Lose completions → User experience degraded

### Vision: Intelligent Code Updates

**Web4Programmer** = Component that understands code structure and can intelligently merge infrastructure updates into existing components.

**Core Concept**: Instead of "remove and recreate," do "analyze and merge."

#### 4. Execute Merge (CMM3 Safe)
```typescript
async executeMerge(
  component: string, 
  version: string, 
  plan: MergePlan
): Promise<MergeResult> {
  // 1. Create backup
  await this.createBackup(component, version);
  
  // 2. Apply changes
  await this.applyInfrastructureUpdates(plan);
  
  // 3. Verify compilation
  const compiles = await this.verifyCompilation(component, version);
  if (!compiles) {
    await this.rollback(component, version);
    throw new Error('Merge failed compilation - rolled back');
  }
  
  // 4. Verify tests (if exist)
  const testsPass = await this.verifyTests(component, version);
  if (!testsPass) {
    await this.rollback(component, version);
    throw new Error('Merge broke tests - rolled back');
  }
  
  // 5. Success!
  return {
    success: true,
    methodsPreserved: plan.preserveUserCode.length,
    infrastructureAdded: plan.addInfrastructure.length,
    backupLocation: `${component}/${version}.backup`
  };
}
```

5. **Validate** (Automated, CMM3)
   - All tests pass
   - Compilation succeeds
   - No functionality lost
   - Documentation preserved

## Do: Current Pain Points (Detailed)

### Pain Point 1: Method Discovery

**Problem**: Template updated with new method discovery framework.

**Old Template** (0.3.17.8):
```typescript
// ❌ NO method discovery
class DefaultComponent extends Component {
  constructor() {
    super();
    this.init();
  }
}
```

**New Template** (0.3.18.1):
```typescript
// ✅ HAS method discovery
class DefaultComponent extends Component {
  private methods: Map<string, MethodSignature> = new Map();
  
  constructor() {
    super();
    this.init();
  }
  
  init(scenario?: Scenario): this {
    if (scenario?.model) {
      this.model = { ...this.model, ...scenario.model };
    }
    this.discoverMethods(); // ← NEW!
    return this;
  }
  
  hasMethod(name: string): boolean { /* NEW */ }
  getMethodSignature(name: string): MethodSignature | null { /* NEW */ }
  listMethods(): string[] { /* NEW */ }
  private discoverMethods(): void { /* NEW */ }
}
```

**Manual Update Required**:
1. Add `private methods: Map<string, MethodSignature> = new Map();`
2. Add `this.discoverMethods();` call in `init()`
3. Add 4 new methods: `hasMethod`, `getMethodSignature`, `listMethods`, `discoverMethods`
4. Add import: `import { MethodSignature } from '../layer3/MethodSignature.interface.js';`

**For PDCA Component**: Must do this manually WITHOUT losing:
- `planPhase()`, `doPhase()`, `checkPhase()`, `actPhase()`
- All other custom methods
- All TSDoc
- All completions
- All private references

**Time**: 30-60 minutes of careful manual work
**Risk**: High - easy to make mistakes
