Read `DefaultWeb4TSComponent.ts:tree()` method (line 1449):
```typescript
async tree(depth: string = '4', showHidden: string = 'false'): Promise<this> {
  // Print quick header
  this.printQuickHeader();
  
  // ✅ RADICAL OOP: Work with component INSTANCE
  const target = this.model.context || this;
  
  const maxDepth = parseInt(depth, 10) || 4;
  const includeHidden = showHidden.toLowerCase() === 'true';
  
  // Target has ALL data in ITS model
  const componentPath = path.join(
    target.model.componentsDirectory,  // ← Path Authority
    target.model.component,
    target.model.version.toString()
  );
  
  await this.displayTreeStructure(componentPath, '', maxDepth, 0, includeHidden);
  return this;
}
```

**Root Cause Analysis**:
- `path.join()` is Node.js `path` module
- Error: "path argument must be of type string. Received undefined"
- **Hypothesis**: One of the arguments to `path.join()` is `undefined`
- **Most Likely**: `target.model.componentsDirectory` is undefined in target component

**3. Fix the Bug**

The issue is that target components (like IdealMinimalComponent) may not have `componentsDirectory` in their model.

**Fix Strategy**: Use Path Authority principle - get path from CLI's model, not target's model:

```typescript
async tree(depth: string = '4', showHidden: string = 'false'): Promise<this> {
  this.printQuickHeader();
  
  // ✅ RADICAL OOP: Work with component INSTANCE
  const target = this.model.context || this;
  
  const maxDepth = parseInt(depth, 10) || 4;
  const includeHidden = showHidden.toLowerCase() === 'true';
  
  // ✅ FIX: Use this.model (CLI) for path infrastructure, target.model for component data
  // @pdca 2025-11-06-UTC-0120.tree-command-fix.pdca.md
  const componentPath = path.join(
    this.model.componentsDirectory,  // ← Use CLI's componentsDirectory (always defined)
    target.model.component,          // ← Use target's component name
    target.model.version.toString()  // ← Use target's version
  );
  
  console.log(`${this.colors.cyan}${this.colors.bold}📁 Tree structure for ${target.model.component} ${target.model.version.toString()}:${this.colors.reset}`);
  console.log(`${this.colors.dim}${componentPath}${this.colors.reset}`);
  await this.displayTreeStructure(componentPath, '', maxDepth, 0, includeHidden);
  
  return this;
}
```
