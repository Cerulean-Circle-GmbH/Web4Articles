**Test Selection Hierarchy** (From code line 1671):

**Valid `references` parameter values:** `'file'`, `'describe'`, `'itCase'`

**Hierarchical Tab Completion:**
- `web4tscomponent test <Tab>` → shows `file describe itCase`
- `web4tscomponent test describe <Tab>` → shows hierarchical list of all describe blocks (same as `web4tscomponent test describe`)
- `web4tscomponent test describe 1<Tab>` → filters to describes starting with `1`
- `web4tscomponent test describe 1a<Tab>` → narrows to specific describe block

**Implementation:**
- `scopeParameterCompletion()` provides first parameter options (`file`, `describe`, `itCase`)
- `referencesParameterCompletion()` provides hierarchical completion for subsequent parameters
- When scope=`'describe'`, calls `getTestDescribeReferences()` which outputs full hierarchical list
- Tab completion shows the SAME output as running the command without numbers

```bash
# Level 1: List all test files
web4tscomponent test file
# Output: numbered list of test files
# Tab: web4tscomponent test file <Tab> shows same list

# Level 2: Run specific file by number
web4tscomponent test file 19
# Runs file #19 (fast!)

# Level 3: List describe blocks in all files
web4tscomponent test describe
# Shows hierarchical structure with file+describe numbering
# Tab: web4tscomponent test describe <Tab> shows same list

# Level 4: Run specific describe block
web4tscomponent test describe 2 1
# Runs describe block 1 in file 2
# Tab: web4tscomponent test describe 2<Tab> filters to file 2's describes

# Level 5: List individual test cases
web4tscomponent test itCase 2 1
# Shows all tests in describe block 1 of file 2
# Tab: web4tscomponent test itCase <Tab> shows all test cases

# Level 6: Run single test case (surgical!)
web4tscomponent test itCase 2 1 3
# Runs test case 3 in describe 1 of file 2 (~350ms!)
```

**Performance Benefits** (From README line 1886-1891):
- Full test suite: `web4tscomponent test` → 214 seconds
- Single file: `web4tscomponent test file 2` → <1 second ⚡ (200x faster)
- Single test: `web4tscomponent test itCase 2 1 3` → <500ms ⚡⚡⚡ (400x faster)
