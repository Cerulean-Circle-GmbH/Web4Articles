## **📋 PLAN**

**Objective:** Refactor all *ParameterCompletion methods from functional `async method(currentArgs: string[])` to Radical OOP `async method(): Promise<string[]>`

**Architectural Violation:**

**Current (WRONG - Functional):**
```typescript
async scopeParameterCompletion(currentArgs: string[]): Promise<string[]> {
  if (currentArgs.length >= 1 && currentArgs[0] === "test") {
    // Uses passed parameter
  }
  return scopes;
}
```

**Correct (Radical OOP - Model-Driven):**
```typescript
async scopeParameterCompletion(): Promise<string[]> {
  // Use model state calculated in shCompletion
  if (this.model.completionCommand === "test") {
    // Uses model state
  }
  return scopes;
}
```

1. **Identify all *ParameterCompletion methods** that accept `currentArgs` parameter

3. **Refactor each method** to use `this.model.completionCompWords` instead of `currentArgs`
4. **Update callers** (shCompletion, completeParameter) to call parameterless methods
5. **Verify tests pass** and completion still works
