## 🔨 Do

### Step 1: Locate the topic list output code

The output happens in the `trainAI` method when topic is unknown or empty:

```typescript
if (!training) {
  console.error(`❌ Unknown training topic: ${topic}`);
  console.log(`\n📚 Available topics:`);
  Object.keys(trainingTopics).forEach(key => {
    console.log(`   - ${key}: ${trainingTopics[key].title}`);
  });
  return this;
}
```

### Step 2: Change format to numbered

**Current**:
```typescript
Object.keys(trainingTopics).forEach(key => {
  console.log(`   - ${key}: ${trainingTopics[key].title}`);
});
```

**New** (with numbering):
```typescript
Object.keys(trainingTopics).forEach((key, index) => {
  console.log(`   ${index + 1}:${key}: ${trainingTopics[key].title}`);
});
```

This matches the format: `1:topic-name: Title`

### Step 3: Implement the change

**Changed code** in `DefaultPDCA.ts`:
```typescript
Object.keys(trainingTopics).forEach((key, index) => {
  console.log(`   ${index + 1}:${key}: ${trainingTopics[key].title}`);
});
```
