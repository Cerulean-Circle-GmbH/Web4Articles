## 📋 PLAN

### Task

Update trainAI documentation to reflect correct Web4 CLI syntax patterns learned from research.

### Findings from UTC-1625 Research

**Key insight:** Web4 uses positional parameters, NOT flags!

**Correct syntax:**
```bash
pdca queryTrainAI <query> <?topic>
```

**NOT:**
```bash
pdca queryTrainAI <query> --topic <topic>  # ❌ Wrong
```
