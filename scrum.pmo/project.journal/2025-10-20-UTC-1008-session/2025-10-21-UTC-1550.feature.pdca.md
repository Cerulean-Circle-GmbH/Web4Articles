### TRON Challenge 2: Naming Convention

**User challenge:** "When a user (or agent!) will use autocompletion with zero knowledge and sees pdca getDualLink - then he will never search for something that is called calculateRelativePath. what name is better?"

**Analysis:** ✅ CORRECT! Naming fails zero-knowledge discoverability!

**Autocomplete experience:**
```bash
pdca get<TAB>
  getDualLink         # User sees this
  calculateRelative... # User WON'T find this!
```

**Better naming:**
- ❌ `calculateRelativePath` - Not discoverable near getDualLink
- ✅ `getDualLinkRelativePath` - Groups with getDualLink
- ✅ `getRelativePathForDualLink` - Explicit but verbose
- ✅ `getDualLinkLocalPath` - Focuses on local part
- ✅ `getLocalLinkPath` - Shorter variant

**Decision: `getDualLinkRelativePath`**

**Why:**
1. ✅ Zero-knowledge discoverable: Users typing `pdca getDual<TAB>` will see both methods
2. ✅ Clear purpose: Name explains it's for dual link relative paths
3. ✅ Semantic grouping: Related methods appear together in autocomplete
4. ✅ Self-documenting: No need to explain what it's for

**UX principle:** Method names should guide zero-knowledge users through autocomplete discovery!

```typescript
/**
 * Calculate relative path from one file to another for dual link local part
 * Groups with getDualLink for zero-knowledge discoverability
 * 
 * @param fromFile Source file path (absolute or project-root-relative)
 * @param toFile Target file path (absolute or project-root-relative)
 * @returns Relative path from fromFile to toFile
 * @cliSyntax fromFile toFile
 */
async getDualLinkRelativePath(fromFile: string, toFile: string): Promise<this> {
  const path = await import('path');
  const projectRoot = await this.getProjectRoot();
  
  // Normalize paths to full paths
  let fromFullPath: string;
  let toFullPath: string;
  
  if (path.isAbsolute(fromFile)) {
    fromFullPath = fromFile;
  } else if (fromFile.startsWith('§/')) {
    fromFullPath = path.join(projectRoot, fromFile.substring(2));
  } else {
    fromFullPath = path.join(projectRoot, fromFile);
  }
  
  if (path.isAbsolute(toFile)) {
    toFullPath = toFile;
  } else if (toFile.startsWith('§/')) {
    toFullPath = path.join(projectRoot, toFile.substring(2));
  } else {
    toFullPath = path.join(projectRoot, toFile);
  }
  
  // Calculate relative path
  const fromDir = path.dirname(fromFullPath);
  const relativePath = path.relative(fromDir, toFullPath);
  
  console.log(`\n🧭 Relative Path Calculation\n`);
  console.log(`📁 From: ${path.relative(projectRoot, fromFullPath)}`);
  console.log(`📁 To:   ${path.relative(projectRoot, toFullPath)}`);
  console.log(`\n✨ Relative Path: ${relativePath}\n`);
  
  return this;
}
```

```typescript
import { describe, it, expect, beforeAll } from 'vitest';
import { PDCACLI } from '../src/ts/layer5/PDCACLI';

describe('PDCA getDualLinkRelativePath', () => {
  let pdca: any;
  let projectRoot: string;

  beforeAll(async () => {
    pdca = new PDCACLI();
    // Find project root (where components/ and scripts/ exist)
    let currentDir = __dirname;
    while (!require('fs').existsSync(path.join(currentDir, 'components')) ||

      const parentDir = path.dirname(currentDir);

        throw new Error('Could not find project root');
      }
      currentDir = parentDir;
    }
    projectRoot = currentDir;

  describe('TC50: Same directory', () => {

    });
  });

  // Helper to capture console output
  async function captureConsoleOutput(fn: () => Promise<any>): Promise<string> {
    const originalLog = console.log;
    let output = '';
    
    console.log = (...args: any[]) => {
      output += args.join(' ') + '\n';
    };
    
    try {
      await fn();
      return output;
    } finally {
      console.log = originalLog;
    }
  }
```
