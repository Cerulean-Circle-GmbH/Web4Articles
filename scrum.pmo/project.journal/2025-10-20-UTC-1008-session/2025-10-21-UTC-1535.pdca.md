### The trainAI as RAG Insight

**What trainAI currently is:**
- Repository of CMM3/CMM4 knowledge
- Training topics for specific patterns
- Accessible via `pdca trainAI <topic>`
- Contains key lessons, verification checklists

**What trainAI COULD be:**
- Real-time RAG system in the feedback loop
- Automatic violation detection → topic suggestion
- Pre-flight checklist enforcement
- Self-awareness metrics

### The Architecture

**Current State (Manual FOR TWO):**
```
1. Agent violates rule
2. TRON catches violation  
3. TRON says "read trainAI how-to-X"
4. Agent reads and re-learns
5. Agent applies learning
6. Loop continues
```

**Enhanced State (RAG-Powered FOR TWO):**
```
1. Agent about to violate rule
2. trainAI RAG catches pattern
3. trainAI injects relevant lesson
4. Agent sees "⚠️ trainAI: Check how-to-dual-links lesson #10"
5. Agent self-corrects BEFORE violation
6. TRON verifies, loop continues
```

### The Core Design

**trainAI as RAG system needs:**

1. **Pattern Detection:**
   - Detect "about to create dual link manually" → inject `how-to-dual-links`
   - Detect "about to report completion" → inject "run git status first"
   - Detect "about to commit" → inject "verify filename matches content"

2. **Pre-Flight Integration:**
   - Before git operations → query trainAI for relevant protocol
   - Before file creation → query trainAI for naming convention
   - Before reporting ✅ → query trainAI for completion checklist

3. **Self-Awareness Metrics:**
   - Track which lessons I've violated
   - Display "You've violated how-to-test-workflow lesson #13 twice today"
   - Suggest review when pattern repeats

4. **TRON Enhancement:**
   - TRON can query: "What violations has agent committed?"
   - TRON can enforce: "Read trainAI topic X before proceeding"
   - TRON sees metrics: "Agent compliance rate: 73%"

```typescript
// Hook into agent workflow
beforeToolCall(toolName: string, args: any): void {
  if (toolName === 'write' && args.file_path.endsWith('.pdca.md')) {
    const lesson = this.queryTrainingByKeyword('dual link');
    this.injectWarning(lesson);
  }
  
  if (toolName === 'run_terminal_cmd' && args.command.includes('git commit')) {
    const lesson = this.getTrainingLesson('how-to-test-workflow', 13);
    this.injectWarning('Run git status first!');
  }
}
```
