### The Bug in LicenseTool

**What Happened:**

1. Original bash files had:
   ```bash
   #!/bin/bash
   # SPDX-License-Identifier...
   # PDCA CLI Tool...
   ```

2. Our shebang detection fix (0.1.0.0) detects shebang ✅
3. Returns `'hash'` style ✅
4. **BUT**: The `insertHeaderInternal` method adds header AFTER existing content!
5. LicenseTool saw file "has no header" (didn't recognize `#` comments as header)
6. Added BOTH `/**` block (from initial detection) AND `#` style (from shebang detection)
7. **Stripped the shebang entirely!**

### Why Our Fix Didn't Work

**From `DefaultLicenseTool.ts` line 453-486:**
- ✅ Detects shebang correctly
- ✅ Returns `'hash'` style
- ❌ **But somewhere in the apply logic, it:**
  - Removes the shebang
  - Adds `/**` block
  - Then adds `#` header
  - Never puts shebang back!

# Find all bash files starting with /**
find components -type f \( -name "pdca" -o -name "licensetool" -o -name "*.sh" \) ! -path "*/node_modules/*" | while read f; do

      const fs = require('fs');
      const content = fs.readFileSync('$f', 'utf-8');
      
      // Remove /** block
      let fixed = content.replace(/^\/\*\*[\s\S]*?\*\/\n+/, '');
      
      // If has # header but no shebang, add it
      if (fixed.startsWith('# SPDX-License') && !fixed.includes('#!/bin/bash')) {

    "
  fi
done

## 📊 Meta-Learning

### Critical Lessons

**1. Shebang Detection ≠ Shebang Preservation:**
- We fixed detection (getCommentStyleInternal) ✅
- **We forgot preservation (insertHeaderInternal)** ❌
- Detecting format is only half the solution!

**2. Test Coverage Gap:**
- TC1 tests detection (getCommentStyleInternal) ✅
- **No test for preservation during apply!** ❌
- Test: "Apply header to file WITH shebang, verify shebang stays first"

**3. Double Header Bug:**
- File detected as "no header" (doesn't recognize `#` comments)
- Added `/**` block (default for extensionless)
- Then added `#` header (shebang detected)
- **hasValidHeaderInternal doesn't recognize `#` headers!**

**4. System-Breaking Change:**
- Applying headers broke the tool itself
- Created circular dependency: Can't fix without the tool
- **Need emergency bypass: Node.js scripts**

**5. Test the Tool ON the Tool:**
- LicenseTool should be tested on itself
- If it breaks itself → bug caught immediately
- **Self-referential testing catches system-breaking bugs**
