### Current State Analysis

**How trainAI works now:**
```bash
pdca trainAI how-to-dual-links
# Output: Entire topic with all lessons, checklist, required reading
# Agent must read through everything, grep for specific info
```

**Problems:**
1. **Information Overload:** Agent gets entire topic, not specific answer
2. **Manual Search Required:** Need to grep or visually scan for relevant info
3. **No Context Awareness:** Can't ask follow-up questions
4. **No Cross-Topic Search:** Can't search across all trainAI knowledge
5. **Not Conversational:** Can't ask "How do I test a new feature?"

**What a traditional RAG provides:**
- Query function: Ask questions in natural language
- Context retrieval: Finds relevant chunks from knowledge base
- Semantic search: Matches meaning, not just keywords
- Answer generation: Synthesizes answer from retrieved context

### Design Considerations

**1. Query vs Topic Display**

Current: `pdca trainAI <topic>` shows full topic
New: `pdca trainAI query <question>` searches and answers

**Keep both!**
- Full topic display: Learning, comprehensive understanding
- Query: Quick answers, specific questions

**2. Search Scope**

**Option A: Topic-level search**
- Search within specific topic only
- Fast, focused
- Requires knowing which topic

**Option B: Cross-topic search**
- Search all trainAI knowledge
- Comprehensive, discovers connections
- Slower, but more useful

**Decision: Implement both**
- `pdca trainAI query <question>` - searches all topics
- `pdca trainAI query <question> --topic <topic>` - scoped search

**3. Search Algorithm**

**Simple (CMM3 start):**
- Keyword matching in lessons/checklist
- Return matching lessons with topic context

**Future (CMM4 evolution):**
- Semantic search with embeddings
- Vector database
- Answer synthesis

**Start simple, iterate!**

**4. Output Format**

### Implementation Design

**Method signature:**
```typescript
async queryTrainAI(query: string, options?: { topic?: string }): Promise<this>
```

**CLI:**
```bash
pdca trainAI query "question here"
pdca trainAI query "question here" --topic how-to-dual-links
```

**Search strategy:**

1. Parse query into keywords
2. Search in each topic:
   - Title
   - Description
   - Key lessons
   - Verification checklist
3. Score matches (count keywords)
4. Return top results with context
5. Suggest related topics

**Example implementation:**
```typescript
async queryTrainAI(query: string, topic?: string): Promise<this> {
  const allTopics = this.getAllTrainingTopics();
  const searchScope = topic ? [topic] : Object.keys(allTopics);
  
  const results: SearchResult[] = [];
  
  for (const topicKey of searchScope) {
    const topicData = allTopics[topicKey];
    const matches = this.searchInTopic(query, topicKey, topicData);
    results.push(...matches);
  }
  
  // Sort by relevance
  results.sort((a, b) => b.score - a.score);
  
  // Display results
  this.displayQueryResults(query, results);
  
  return this;
}
```

### Implementation Sketch

```typescript
/**
 * Query trainAI knowledge base with natural language questions
 * Searches across all topics or within specific topic
 * 
 * @param query Natural language question
 * @param topic Optional: limit search to specific topic
 * @cliSyntax query topic
 * @cliDefault topic ""
 */
async queryTrainAI(query: string, topic?: string): Promise<this> {
  console.log(`\n🔍 trainAI Query Results\n`);
  console.log(`Query: "${query}"\n`);
  
  const trainingTopics = this.getTrainingTopics(); // Get all topics
  const searchScope = topic ? [topic] : Object.keys(trainingTopics);
  
  if (topic && !trainingTopics[topic]) {
    console.log(`❌ Topic "${topic}" not found\n`);
    console.log(`💡 Available topics:`);
    Object.keys(trainingTopics).forEach((key, i) => {
      console.log(`   ${i + 1}:${key}`);
    });
    return this;
  }
  
  // Search for matches
  const results = this.searchTrainAI(query, searchScope, trainingTopics);
  
  if (results.length === 0) {
    console.log(`❌ No results found for "${query}"\n`);
    console.log(`💡 Available topics:`);
    Object.keys(trainingTopics).forEach((key, i) => {
      console.log(`   ${i + 1}:${key} - ${trainingTopics[key].title}`);
    });
    return this;
  }
  
  // Display results grouped by topic
  const groupedResults = this.groupByTopic(results);
  
  for (const [topicKey, matches] of Object.entries(groupedResults)) {
    const topicTitle = trainingTopics[topicKey].title;
    console.log(`📚 Found in: ${topicKey}`);
    console.log(`   ${topicTitle}`);
    console.log(`${'─'.repeat(80)}`);
    
    matches.forEach(match => {
      console.log(`${match}\n`);
    });
  }
  
  // Suggest related topics
  console.log(`💡 Related topics:`);
  const relatedTopics = Object.keys(groupedResults);
  relatedTopics.forEach(key => {
    console.log(`   - pdca trainAI ${key} (full guide)`);
  });
  console.log();
  
  return this;
}

private searchTrainAI(
  query: string,
  scope: string[],
  topics: Record<string, TrainingTopic>
): SearchResult[] {
  const results: SearchResult[] = [];
  const queryLower = query.toLowerCase();
  const keywords = queryLower.split(/\s+/);
  
  for (const topicKey of scope) {
    const topic = topics[topicKey];
    
    // Search in key lessons
    topic.keyLessons?.forEach((lesson: string) => {
      const lessonLower = lesson.toLowerCase();
      const matchCount = keywords.filter(kw => lessonLower.includes(kw)).length;
      
      if (matchCount > 0) {
        results.push({
          topic: topicKey,
          content: lesson,
          score: matchCount,
          type: 'lesson'
        });
      }
    });
    
    // Search in verification checklist
    topic.verificationChecklist?.forEach((item: string) => {
      const itemLower = item.toLowerCase();
      const matchCount = keywords.filter(kw => itemLower.includes(kw)).length;
      
      if (matchCount > 0) {
        results.push({
          topic: topicKey,
          content: item,
          score: matchCount,
          type: 'checklist'
        });
      }
    });
  }
  
  // Sort by score
  results.sort((a, b) => b.score - a.score);
  
  return results;
}
```
