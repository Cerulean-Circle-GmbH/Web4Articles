### Option C: Committed Test Fixtures

**What This Means:**
- Pre-commit test data files to repository
- Tests operate on real committed files in git
- Tests use real `git mv` commands
- Test data lives permanently in `components/PDCA/latest/test/data/movefile-tests/`

**Current State:**
- 9 tests SKIPPED (TC30-TC38)

- Reason for skip: Tests would pollute git history with dynamic commits

**Goal:**
Enable all 9 skipped tests by creating permanent test fixtures

### Test Fixture Design

**Test Data Location:**
`components/PDCA/latest/test/data/movefile-tests/`

**Baseline Structure:**
```
test/data/movefile-tests/
├── source/
│   ├── test-file-a.md          # File to be moved
│   ├── test-file-b.md          # File with link to test-file-a
│   └── test-file-c.md          # File with link to test-file-a
├── target/
│   └── subdir/                 # Target directory for moves
└── README.md                   # Explains test fixture purpose
```

**File Content Design:**

**test-file-a.md:**
```markdown
# Test File A

This is a test file for moveFile functionality.

Links to other files:
- [Test File B](test-file-b.md)
- [Test File C](test-file-c.md)
```

**test-file-b.md:**
```markdown
# Test File B

Links to Test File A:
- [Test File A](test-file-a.md)
```

**test-file-c.md:**
```markdown
# Test File C

Links to Test File A:
- [Test File A](test-file-a.md)
```

### Test Strategy

**Challenge:** Tests modify files, but we need reproducibility

**Solution: Copy fixtures before each test** ✅
- Before each test: Copy files from `test/data/movefile-tests/` to temp location
- Run test on copies
- Assert on copied files
- Clean up temp files after test
- Original fixtures remain unchanged
