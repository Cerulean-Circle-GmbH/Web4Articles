**Key Lessons:**
1. ✅ CMM3 RULE: Automated tests are authority, manual verification is CMM2 (subjective)
2. ✅ WORKFLOW: Create/update test → Run test → Observe → STOP → Wait for user direction
3. ✅ ALWAYS run test immediately after creating it to verify it works
4. ✅ Test output is the source of truth - trust it
5. ⚠️ ANTI-PATTERN: Create test but don't run it
6. ⚠️ ANTI-PATTERN: Run manual verification instead of test
7. ⚠️ ANTI-PATTERN: Create test AND manual verify in parallel
8. ❌ NEVER bypass tests with manual steps when automated test exists
9. 💡 Automation Hierarchy: 1) Automated test exists → Run it (HIGHEST), 2) No test → Create test first, 3) Can't automate → Document manual (LAST RESORT)
10. 💡 If test output unclear, improve the test - don't bypass it

**Verification Checklist:**
- [ ] Can identify when automated test exists
- [ ] Runs test immediately after creation
- [ ] Observes and reports test output before proceeding
- [ ] Waits for user direction after showing results
- [ ] Avoids manual verification when test exists
- [ ] Trusts test output as CMM3 authority
