### **Reading Depth 3 Protocol - Complete Definition**

**From CMM3 Checklist Section 7c (lines 87-89):**

> **Reading depth requirement:** Read ALL relevant documents to depth 3 (document → referenced docs → their references). **Applies to:** startup instructions, user-provided links, protocol references, ANY input requiring understanding. **Depth 3 ensures:** Level 0 (entry), Level 1 (direct refs), Level 2 (secondary refs), Level 3 (deep context). Validate all links at each depth.

### **The Four Depth Levels**

**Level 0: Entry Document**
- The initial document provided or required
- Example: `cmm3.compliance.checklist.md` when starting session
- Action: Read completely and understand

**Level 1: Direct References**
- All documents linked FROM level 0
- Example from checklist: `start-command.md`, `template.md`, `howto.PDCA.md`, `PDCA.howto.decide.md`
- Action: Identify ALL, read ALL completely

**Level 2: Secondary References**
- All documents linked FROM level 1 documents
- Example from violation PDCA: `PDCA.understanding.CMMI.md`, `forty-two-revelation.md`, `howto.cmm.md`, `cmm-levels-summary.md`
- Action: Identify ALL from level 1 docs, read ALL completely

**Level 3: Deep Context**
- All documents linked FROM level 2 documents  
- Example: `dory-symptoms-story.md`, `definition-destruction-analysis-pdca`, Web4 requirement docs
- Action: Identify ALL from level 2 docs, read relevant ones for complete context

### **Prevention Strategies Documented**

**From violation PDCA lines 293-327:**

**1. MANDATORY Directive Recognition Protocol**
When encountering language like "Read ALL", "MUST DO", "MANDATORY", "CRITICAL", "Required":

**STOP and ask:**
- a) Is this CMM3 objective definition or CMM2 template suggestion?
- b) What would 100% compliance look like concretely?
- c) Can I create checklist/tracking for complete execution?
- d) Should I ask for clarification before interpreting?

**2. Depth 3 Reading Checklist (Created in violation PDCA)**
```markdown
[ ] Level 0: Entry document read and understood
[ ] Level 1: ALL direct references identified
[ ] Level 1: ALL direct references read completely
[ ] Level 2: ALL secondary references identified from Level 1 docs
[ ] Level 2: ALL secondary references read completely
[ ] Level 3: ALL tertiary references identified from Level 2 docs
[ ] Level 3: ALL tertiary references read completely
[ ] Validation: No unread references remain at any level
```

**3. todo_write Integration**
- Create specific document list for each depth level
- Individual todos for each document
- Validation todo after each depth level
- No proceeding until all reading todos complete

**4. Verification Before Claiming**
**Pattern:** Execute → Verify → Then Claim (not Claim → Execute Later)

Never write "depth 3 in progress" or "depth 2 validated" without ACTUAL completion.
