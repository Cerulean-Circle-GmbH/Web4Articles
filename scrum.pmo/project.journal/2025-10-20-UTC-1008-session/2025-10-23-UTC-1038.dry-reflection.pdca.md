### 🚨 CRITICAL LEARNING: Web4 Naming Convention

**TRON Feedback:** "All names with `_` are not allowed, also like `--help` as you already know."

**Web4 Naming Rules:**

1. ❌ **NO underscores** in method names (neither public nor private)
   - Wrong: `_calculateRelativePath`, `_internal`, `_helper`
   - Correct: `calculateRelativePathInternal`, `internal`, `helper`

2. ❌ **NO double-dash flags** in CLI
   - Wrong: `--help`, `--version`, `--dry-run`
   - Correct: Positional parameters only

3. ✅ **camelCase for ALL methods** (public and private)
   - Public: `getDualLink`, `trainAI`, `queryTrainAI`
   - Private: `calculateRelativePathInternal`, `normalizeFilePath`

4. ✅ **Positional parameters only** for CLI
   - Syntax: `pdca getDualLink <filePath>`
   - NOT: `pdca getDualLink --file=<filePath>`

**Anti-Pattern Found in PDCA Component:**
```typescript
// ❌ WRONG: Uses underscore prefix (legacy pattern)
private _calculateRelativePathInternal(docPath, targetPath, path) {
  return path.relative(path.dirname(docPath), targetPath);
}
```

**LicenseTool MUST use correct naming:**
```typescript
// ✅ CORRECT: camelCase, no underscore
private calculateRelativePathInternal(docPath: string, targetPath: string): string {
  const path = require('path');
  return path.relative(path.dirname(docPath), targetPath);
}
```

**Title:** 🏷️ How to Web4 Naming: Component, Method, and CLI Conventions

**Key Lessons:**
1. ❌ NEVER use underscores in method names (public or private)
2. ❌ NEVER use `--flags` in CLI (positional parameters only)
3. ✅ ALWAYS use camelCase for all identifiers
4. ✅ Private methods: suffix with `Internal` (e.g., `calculateRelativePathInternal`)
5. ✅ CLI commands: verb-noun pattern (e.g., `getDualLink`, `trainAI`)
6. ✅ Annotate internal methods with `@cliHide`
7. ✅ Use `@cliSyntax` for parameter order
8. ✅ Use `@cliValues` for auto-completion
9. 📚 Naming is part of Web4 Auto-Discovery CLI pattern
10. 🔍 Method names must be discoverable via tab completion

**Anti-Patterns to Avoid:**
```typescript
// ❌ WRONG: Underscore prefix
private _calculatePath() {}
private _internal() {}
private __private() {}

// ❌ WRONG: Flags in CLI
@cliSyntax filePath --dry-run --verbose

// ✅ CORRECT: camelCase suffix
private calculatePathInternal() {}
private normalizeFilePathInternal() {}

// ✅ CORRECT: Positional parameters
@cliSyntax filePath dryRun
```
