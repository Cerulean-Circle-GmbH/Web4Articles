### Problem Analysis

**RAG Query Results:**
```
🔧 Web4 Naming: methodNameInternal() for private helpers (NO underscores!)
❌ NEVER use _methodName() or _methodNameInternal() (underscore violation)
```

**Violation Found:**
- Used `__dirname` (Node.js global with double underscores) in test files
- 14 occurrences in `/components/PDCA/0.3.0.3/test/pdca.movefile.test.ts`
- 1 occurrence in `/components/PDCA/0.3.0.3/test/pdca.test.ts`
- Also propagated to `0.3.1.1` version

**Web4-Compliant Pattern (from Web4TSComponent):**
```typescript
// ❌ WRONG: Node.js CommonJS pattern
const currentDir = __dirname;

// ✅ CORRECT: ES Modules + Web4 compliant
const currentFileUrl = new URL(import.meta.url);
const currentDir = path.dirname(currentFileUrl.pathname);
```

**Why This Matters:**
1. **Web4 Principle**: No underscores in naming
2. **ES Modules**: `__dirname` is CommonJS, we use ES modules
3. **Consistency**: All Web4 components use `import.meta.url`
4. **Best Practice**: Modern JavaScript/TypeScript pattern
