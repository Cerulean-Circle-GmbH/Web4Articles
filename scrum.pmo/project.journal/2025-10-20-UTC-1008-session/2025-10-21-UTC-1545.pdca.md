### Investigation Results

**Found:** `calculateRelativePath` method at line 616 of DefaultPDCA.ts:
```typescript
private calculateRelativePath(docPath: string, targetPath: string, path: typeof import('path')): string {
  const docDir = path.dirname(docPath);
  return path.relative(docDir, targetPath);
}
```

**Used internally by:**
- `fixMarkdownFile` method
- `updateLinksToFile` method

**trainAI status:**

### The Actual Truth

**getDualLink behavior:**
- Returns project-root-relative paths: `(articles/file.md)`
- This is CORRECT for the § notation display part
- But local link part needs relative path from source file!

**Example from my error:**
```
From: scrum.pmo/project.journal/SESSION/file.md
To: articles/cursor-cto.md

getDualLink output:
[§/articles/cursor-cto.md](articles/cursor-cto.md)

Problem: (articles/cursor-cto.md) is project-root-relative
Need: (../../../articles/cursor-cto.md) - relative from source

Manual fix: Count 3 levels up, then articles/cursor-cto.md
```

**Why calculateRelativePath exists:**
- Internal methods need this functionality
- They use it to fix links in markdown files
- But it's NOT exposed via CLI for getDualLink!
