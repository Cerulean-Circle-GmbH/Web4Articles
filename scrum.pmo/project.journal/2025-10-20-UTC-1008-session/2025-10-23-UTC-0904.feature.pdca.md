**Header Template Structure (ALL Files):**
```
SPDX-License-Identifier: AGPL-3.0-only WITH AI-GPL-Addendum
SPDX-FileComment: See <relative-path>/AI-GPL.md for AI-specific terms.
Copyright (c) <dynamic-year> Cerulean Circle GmbH
Copyleft: See AGPLv3 (<relative-path>/LICENSE) and AI-GPL Addendum (<relative-path>/AI-GPL.md)
Backlinks: /LICENSE, /AI-GPL.md
```

**Key Design Decisions:**

1. **SPDX Identifier:** `AGPL-3.0-only WITH AI-GPL-Addendum`
   - Uses SPDX `WITH` operator for addendums (official spec)
   - Machine-readable by SPDX tools

2. **SPDX-FileComment:** Quick reference pointer
   - Reduces context switching for developers/AI
   - SPDX-compliant way to add file-specific notes
   - Relative path calculated from file location

3. **Dynamic Year:** `new Date().getFullYear()`
   - Automatically correct when applied
   - Files show their creation/modification year

4. **Relative Paths:** Calculated per file
   - Root files: `./AI-GPL.md`
   - Nested files: `../../AI-GPL.md`, etc.
   - Links always work, even if file moved

5. **Backlinks:** `/LICENSE, /AI-GPL.md` (no spaces)
   - Standard CSV format
   - Easier to parse

**No Per-File scrum.pmo Note:**
- Details moved to AI-GPL.md (DRY principle)
- SPDX-FileComment points to full explanation
- Maintains simple, consistent headers

### Component Design

**Component Name:** `LicenseTool`  
**Layer Architecture:**
- **Layer 5 (CLI):** `LicenseToolCLI.ts` - Auto-discovered CLI entry point
- **Layer 2 (Implementation):** `DefaultLicenseTool.ts` - Core logic
- **Layer 3 (Interfaces):** `LicenseTool.interface.ts`, `LicenseToolModel.interface.ts`
- **Layer 4 (Utils):** File discovery, comment style mapping, header builder

**Core Methods (Public, CLI-Exposed):**
1. `check(path: string = '.'): Promise<this>`
   - @cliSyntax: `path`
   - @cliDefault: `path "."` (current directory)
   - Scans files, reports missing/incorrect headers
   - Exit code 0 = all good, 1 = issues found

2. `apply(path: string = '.', dryRun: string = 'false'): Promise<this>`
   - @cliSyntax: `path dryRun`
   - @cliDefault: `path ".", dryRun "false"`
   - Adds/updates headers in files
   - Dry-run mode: report what would be done without modifying

**Internal Methods (Private, @cliHide):**
- `discoverFilesInternal(path: string): Promise<string[]>` - Find relevant files (respect .gitignore)
- `getCommentStyleInternal(filePath: string): CommentStyle` - Map extension to comment syntax
- `calculateRelativePathInternal(fromFile: string, toFile: string): string` - Calculate relative path between files
- `buildHeaderInternal(filePath: string, commentStyle: CommentStyle): string` - Generate header with dynamic year and relative paths
- `hasValidHeaderInternal(content: string, expectedHeader: string): boolean` - Check if header present and current
- `insertHeaderInternal(content: string, header: string): string` - Prepend header to file
- `updateHeaderInternal(content: string, oldHeader: string, newHeader: string): string` - Replace outdated header
- `shouldSkipFileInternal(filePath: string): boolean` - Exclude node_modules, dist, binaries, etc.

**🚨 Web4 Naming Convention:**
- ✅ NO underscores in method names (not `_calculateRelativePath`)
- ✅ Use `Internal` suffix for private helpers (e.g., `calculateRelativePathInternal`)
- ✅ All methods camelCase
- ✅ Annotate with `@cliHide` for private methods
