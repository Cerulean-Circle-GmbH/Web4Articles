## 📊 Meta-Learning

**Key Discovery: File Write Timing in Tool Chain**
- `search_replace` tool may not flush writes immediately
- Auto-promotion (`web4tscomponent upgrade`) copies files during operation
- If copy happens before write flush → broken files propagate
- **Mitigation**: Verify file contents with terminal commands before triggering auto-promotion

**Pattern for Future:**
1. Make edits with file tools
2. **Verify with terminal** (`cat`, `head`, `bash -n`)
3. Run tests/promotion
4. If propagation occurs, clean rebuild from source
