### Outcome (Required trainAI Improvements)

#### New Topic 1: `how-to-interpret-instructions`

**Title:** 🎯 How to Interpret Instructions: Literal vs Implied Actions

**Description:** Master the art of parsing user instructions to understand exactly what's requested vs what's assumed

**Required Reading:**
1. `scrum.pmo/roles/SaveRestartAgent/cmm3.compliance.checklist.md`
   - Reason: 6d - No assumptions about user intent
   - Depth: 2

2. `scrum.pmo/project.journal/2025-10-20-UTC-1008-session/2025-10-21-UTC-1007.meta-learning.pdca.md`
   - Reason: Real example of instruction misinterpretation
   - Depth: 3

**Key Lessons:**
- ✅ "Show me X" means: Execute X, Display result, STOP
- ✅ "Fix X" means: Analyze, Propose, Implement (after confirmation)
- ✅ "X and Y" means: Do X, then do Y
- ✅ "X" does NOT imply Y, even if Y seems logical
- ⚠️ Punctuation matters: "pdca" vs "pdca!" vs "PDCA"
- 🛑 Feedback points: Where control returns to user
- ❌ Never add implied actions
- ❌ Never assume "next logical step"

**Examples:**
```
"run tests" → Execute npm test, show output, STOP
NOT: run + analyze + fix + commit

"show me file.md" → Display file, STOP  
NOT: show + analyze + suggest changes

"pdca!" → Create PDCA file
NOT: write PDCA-formatted response

"read X" → Read X, provide dual link, STOP
NOT: read + summarize + analyze
```

**Verification Checklist:**
- [ ] Can parse "show me X" correctly (execute + display + stop)
- [ ] Understands difference between command and suggestion
- [ ] Recognizes punctuation significance (!, CAPS, etc)
- [ ] Can identify feedback points in instructions
- [ ] Knows when to ask vs assume

#### New Topic 2: `how-to-collaborate`

**Title:** 🤝 How to Collaborate: User-in-the-Loop CMM4 Pattern

**Description:** Understand CMM4 collaboration where user controls the loop and agent enables execution

**Required Reading:**
1. `scrum.pmo/project.journal/2025-09-22-UTC-1908-session/howto.cmm.md`
   - Reason: CMM4 as feedback loop mastery
   - Depth: 3

2. `scrum.pmo/project.journal/2025-10-20-UTC-1008-session/2025-10-21-UTC-1007.meta-learning.pdca.md`
   - Reason: Real example of collaboration violation
   - Depth: 3

3. `scrum.pmo/roles/_shared/PDCA/PDCA.howto.decide.md`
   - Reason: Decision-making framework for user alignment
   - Depth: 2

**Key Lessons:**
- 🔄 CMM4 Loop: User decides → Agent executes → FEEDBACK POINT → User reflects → User decides
- ✅ User controls WHAT to do
- ✅ Agent controls HOW to do it
- ✅ Feedback points = where control returns to user
- 🛑 STOP at feedback points, don't assume next step
- ⚠️ "Helpful" = enabling user, NOT solving without asking
- ❌ Never close feedback loop prematurely
- ❌ Never assume user wants problem solved

**The Collaboration Model:**
```
┌─────────────┐
│   USER      │
│  (Decision) │
└──────┬──────┘
       │ Instruction
       ↓
┌─────────────┐
│   AGENT     │
│  (Execute)  │
└──────┬──────┘
       │ Result
       ↓
┌─────────────┐
│  FEEDBACK   │ ← 🛑 STOP HERE
│   POINT     │
└──────┬──────┘
       │ Reflection
       ↓
┌─────────────┐
│   USER      │
│  (Decision) │
└─────────────┘
```

**Anti-Patterns:**
```
❌ Wrong: User → Agent → (everything done) → User sees result
✅ Right: User → Agent → Result → STOP → User → Next instruction
```

**Verification Checklist:**
- [ ] Understands CMM4 collaboration loop
- [ ] Can identify feedback points
- [ ] Knows when to STOP vs continue
- [ ] Recognizes "helpful" vs "presumptuous"
- [ ] Waits for user decision at feedback points

## 4. Act

### Learnings

#### Why These Gaps Exist

**Root cause:**
- trainAI was built for technical processes
- Assumed collaboration would be intuitive
- Didn't anticipate "helpful" anti-pattern
- Focused on WHAT to do, not WHEN to stop

**The oversight:**
- Taught PDCA creation ✅
- Taught component usage ✅
- Taught link format ✅
- Didn't teach collaboration ❌
- Didn't teach feedback points ❌
- Didn't teach instruction parsing ❌

**Meta-learning:**
Technical knowledge ≠ Behavioral knowledge

Agents need:
- Technical: How to create PDCA
- Behavioral: When to stop and wait
- Social: How to collaborate with user

trainAI had 1st, missing 2nd and 3rd.

#### The Training Philosophy

**Current philosophy:**
"Teach the technical skills"

**Should be:**
"Teach the technical skills AND the social protocol"

**Because:**
- Technical skills without social protocol = over-eager agent
- Over-eager agent = violates collaboration
- Violated collaboration = CMM2 (subjective, assumed intent)

**The gap:**
We can teach:
- What to do ✅
- How to do it ✅

We forgot to teach:
- When to do it ❌
- When to stop ❌
- When to ask ❌

#### Training Priority

**Previous implicit priority:**
1. Technical accuracy
2. Process compliance
3. Tool usage

**Should be:**
1. Collaboration protocol (when to act vs wait)
2. Instruction interpretation (what's actually requested)
3. Technical accuracy
4. Process compliance
5. Tool usage

**Rationale:**
If agent doesn't know WHEN to act, perfect technical execution is wasted on wrong actions.
