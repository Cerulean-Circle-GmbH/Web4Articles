### The Bug in getDualLink

**Tool output:**
```
[§/articles/cursor-cto-agent-cmm3-compliance-crisis.md](articles/cursor-cto-agent-cmm3-compliance-crisis.md)
```

**Correct output should be:**
```
[§/articles/cursor-cto-agent-cmm3-compliance-crisis.md](../../../articles/cursor-cto-agent-cmm3-compliance-crisis.md)
```

**Root cause analysis:**

When `getDualLink` is called with `fromDirectory` parameter:
```bash
pdca getDualLink <target> <fromDirectory>
```

It should calculate relative path FROM `fromDirectory` TO `target`.

**Path calculation:**
- From: `scrum.pmo/project.journal/2025-10-20-UTC-1008-session/`
- To: `articles/cursor-cto-agent-cmm3-compliance-crisis.md`
- Up 3 levels: `../../../`
- Then: `articles/cursor-cto-agent-cmm3-compliance-crisis.md`
- Result: `../../../articles/cursor-cto-agent-cmm3-compliance-crisis.md`

**What getDualLink returned:** `articles/cursor-cto-agent-cmm3-compliance-crisis.md` (WRONG - missing `../../../`)
