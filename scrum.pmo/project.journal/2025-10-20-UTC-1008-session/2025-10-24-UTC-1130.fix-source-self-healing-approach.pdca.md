## 🔄 DO

### Root Cause: hasValidHeaderInternal Doesn't Recognize Existing Headers

**The Bug Chain:**

1. File has `/**` block + `#` hash comments (double header)
2. `hasValidHeaderInternal()` checks if file has valid header
3. It looks for `SPDX-License-Identifier` string
4. **It finds it** (in the `/**` block)
5. Thinks file is "valid" → skips it!
6. **File never gets fixed!**

**OR:**

1. File has `/**` block only (no shebang, no hash header)
2. `hasValidHeaderInternal()` sees `SPDX-License-Identifier`
3. Thinks file is "valid"
4. Skips update
5. **File stays broken!**

### Solution Strategy

**Option 1: Make hasValidHeaderInternal Smarter**

```typescript
async hasValidHeaderInternal(filePath: string, content: string): Promise<boolean> {
  const commentStyle = await this.getCommentStyleInternal(filePath);
  
  // For bash scripts (should be hash), check for hash header
  if (commentStyle === 'hash') {
    // Must have # header, not /** header
    if (content.startsWith('/**')) {
      return false; // Wrong format!
    }
    return content.includes('# SPDX-License-Identifier');
  }
  
  // ... existing logic for other styles ...
}
```

**BUT WAIT:** This won't work because `getCommentStyleInternal()` checks the CURRENT file state, which has `/**` on line 1, not shebang!

**Option 4: Enhanced getCommentStyleInternal**

```typescript
async getCommentStyleInternal(filePath: string): Promise<'block' | 'hash' | 'html'> {
  const path = await import('path');
  const ext = path.extname(filePath).toLowerCase();
  
  // Extension-based (fast path)
  if (['.ts', '.js', ...].includes(ext)) return 'block';
  if (['.py', '.sh', ...].includes(ext)) return 'hash';
  if (['.md', '.html', ...].includes(ext)) return 'html';
  
  // Content-based for extensionless files
  if (!ext) {
    const fs = await import('fs/promises');
    const content = await fs.readFile(filePath, 'utf-8');
    
    // Check ANYWHERE in first 20 lines for shebang
    const lines = content.split('\n').slice(0, 20);
    if (lines.some(line => line.trim().startsWith('#!'))) {
      return 'hash'; // It's a bash script!
    }
  }
  
  return 'block';
}
```
