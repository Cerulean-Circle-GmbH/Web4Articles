#### **New Topic 2: `how-to-agent-safety`**
**Title:** 🚨 Agent Safety: Commands That Hang & Interactive Prompt Avoidance  
**Description:** CRITICAL safety protocols for background agents

**Required Reading:**
1. `scrum.pmo/roles/_shared/PDCA/bad.interactive.sh.commands.md`
2. README.md Step 5

**Key Lessons:**
1. 🔴 NEVER use `git pull origin branch` → Use `git pull --no-edit`
2. 🔴 NEVER chain commands with `&&` → Use separate calls
3. 🔴 NEVER use `npm install` → Use `npm install --yes` or `npm ci`
4. 🔴 NEVER `git add` large directories → Exclude node_modules
5. ✅ Background agents CANNOT handle interactive prompts
6. ✅ Use non-interactive flags for ALL operations
7. ✅ Use `timeout 30s` wrapper for risky operations

**Verification Checklist:**
- [ ] Can identify interactive commands before using them
- [ ] Knows to add `--yes`, `--no-edit`, `-y` flags
- [ ] Understands why background agents can't handle prompts
- [ ] Can use timeout wrappers for safety

2. ✅ Create project.status.md in session directory
3. ✅ Dev branch format: `dev/YYYY-MM-DD-UTC-HHMM`
