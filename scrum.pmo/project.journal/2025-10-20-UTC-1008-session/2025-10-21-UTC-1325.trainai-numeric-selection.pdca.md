**Meta**: Future enhancement - allow users to call topics by number (e.g., `pdca trainAI 3`)

## 🎯 Plan

### Trigger (Verbatim)
> "can i call 'pdca trainAI 3' now?"
> [after testing] "pdca, we will do this later"

### Context
After adding numbering to the trainAI topic list, the natural next step is to allow numeric references. Currently:
- ✅ Topics are displayed with numbers (1-11)
- ❌ Must still use full topic name: `pdca trainAI how-to-cmm`
- 🎯 Desired: Use number instead: `pdca trainAI 3`

### Objective
Enhance `trainAI` method to accept both:
1. Full topic names (existing): `how-to-cmm`
2. Numeric references (new): `3`

### Success Criteria
- `pdca trainAI 3` loads `how-to-cmm` topic
- Invalid numbers (0, 12, etc.) show error
- Full topic names still work
- CLI completion still works
- All changes documented and committed

## 🔨 Do

### Implementation Plan

**Step 1: Add numeric lookup logic**
```typescript
// In trainAI method, before looking up training topic:
const topicKeys = Object.keys(trainingTopics);

// Check if topic is a number
if (/^\d+$/.test(topic)) {
  const index = parseInt(topic) - 1; // Convert to 0-based index
  if (index >= 0 && index < topicKeys.length) {
    topic = topicKeys[index]; // Convert number to topic name
  } else {
    console.error(`❌ Invalid topic number: ${parseInt(topic) + 1}`);
    console.log(`   Valid range: 1-${topicKeys.length}`);
    // Show topic list...
    return this;
  }
}

// Continue with existing lookup
const training = trainingTopics[topic];
```

**Step 2: Update error messages**
- When showing "Unknown training topic", mention numeric option
- Example: "Use topic name (e.g., 'how-to-cmm') or number (e.g., '3')"

**Step 3: Test cases**
- TC1: `pdca trainAI 3` → loads how-to-cmm
- TC2: `pdca trainAI 1` → loads how-to-start
- TC3: `pdca trainAI 11` → loads how-to-chat-response
- TC4: `pdca trainAI 0` → shows error (out of range)
- TC5: `pdca trainAI 12` → shows error (out of range)
- TC6: `pdca trainAI 999` → shows error (out of range)
- TC7: `pdca trainAI how-to-cmm` → still works (backward compatibility)
- TC8: `pdca trainAI invalid` → still shows error + list

**Step 4: Update CLI completion**
- Consider: Should CLI completion suggest numbers too?
- Current: Only suggests topic names
- Future: Could suggest both "3" and "how-to-cmm"
