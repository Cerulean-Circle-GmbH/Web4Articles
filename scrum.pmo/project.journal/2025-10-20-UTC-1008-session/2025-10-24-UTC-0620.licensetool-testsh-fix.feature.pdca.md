## 📋 PLAN

### Problem Summary (from Parent PDCA)

**Issue:** LicenseTool test.sh calls `./web4tscomponent test` instead of `./licensetool test`

**Impact:**
- Test workflow fails with symlink navigation error
- Violates Web4 component independence pattern
- Prevents auto-promotion to test/dev versions

**Root Cause:**
- LicenseTool test.sh was copied from Web4TSComponent template
- Web4TSComponent is self-referential (tests itself via `./web4tscomponent test`)
- Other components should call their own CLI (e.g., PDCA calls `./pdca test`)
