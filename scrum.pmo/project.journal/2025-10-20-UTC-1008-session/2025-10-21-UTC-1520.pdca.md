### What trainAI Says

**Dual link format (Key Lesson #1):**
```
[GitHub](https://github.com/org/repo/blob/branch/path) | [§/path](path)
```

**Key components:**
1. GitHub link: Full URL with org, repo, blob, branch, path
2. § notation: **Project-root-relative** display text
3. Local link: **Relative path** from current file to target

**Example from trainAI:**
```
[GitHub](https://github.com/Cerulean-Circle-GmbH/Web4Articles/blob/dev/branch/file.md) | [§/scrum.pmo/file.md](../../file.md)
```
