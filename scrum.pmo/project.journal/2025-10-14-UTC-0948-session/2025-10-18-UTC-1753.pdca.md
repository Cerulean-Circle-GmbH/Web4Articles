### **Problem Analysis**

#### **Issue 2: Wrong Enum Values for `version` Parameter**

**Evidence from grep:**

**Method 1: `create(component, version, options)`** - Line 875
```typescript
* @cliSyntax component version options
* @cliDefault version 0.1.0.0
* @cliDefault options all
async create(component: string, version: string = '0.1.0.0', options: string = 'all')
```
- **Parameter name:** `version`
- **Default:** '0.1.0.0'
- **@cliValues:** NONE
- **Expected behavior:** No enum restriction, accepts any semantic version

**Method 2: `on(component, version)`** - Line 1105
```typescript
* @cliSyntax component version
* @cliDefault version latest
async on(component: string, version: string = 'latest')
```
- **Parameter name:** `version`
- **Default:** 'latest'
- **@cliValues:** NONE
- **Expected behavior:** Accepts semantic versions OR symlink names (latest/dev/prod/test)

**Method 3: `setCICDVersion(targetVersion, version)`** - Line 4634
```typescript
* @cliValues targetVersion dev latest prod test
* @cliExample web4tscomponent setCICDVersion prod 1.0.0.0
async setCICDVersion(
  targetVersion: string,
  version: string = 'current'
)
```
- **Parameter name 1:** `targetVersion` (first parameter)
- **Parameter name 2:** `version` (second parameter, default: 'current')
- **@cliValues:** `targetVersion dev latest prod test` (applies to `targetVersion`, NOT `version`)
- **Expected behavior:** 
  - `targetVersion` should have values: dev, latest, prod, test
  - `version` should accept any semantic version OR 'current'

**Root Cause:**
`TSCompletion.extractCliValues(className, '', 'version')` searches ALL methods for @cliValues with parameter 'version'.
It finds `setCICDVersion` method which has `@cliValues targetVersion dev latest prod test`.
The bug is in TSCompletion line 672-674: When @cliValues format is "paramName value1 value2..." and the method HAS a parameter named 'version', it incorrectly returns ALL tokens including 'targetVersion'.

**Why the bug happens:**
1. Search for @cliValues for parameter 'version'
2. Find: `@cliValues targetVersion dev latest prod test`
3. First token 'targetVersion' !== 'version' → go to fallback (line 665-676)
4. Check if method has parameter 'version' → YES (second parameter)
5. Return ALL parts: ['targetVersion', 'dev', 'latest', 'prod', 'test'] ❌

**Correct behavior:**
- The @cliValues is for 'targetVersion' (first token matches parameter name)
- This @cliValues should NOT be returned when searching for parameter 'version'
- The method DOES have a 'version' parameter, but the @cliValues is NOT for it
