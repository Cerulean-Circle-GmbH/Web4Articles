## **📋 PLAN**

**Objective:** Restore tab completion by adding missing `@cliCompletion filter completionNameParameterCompletion` tag

**Root Cause:**

In commit 35651e0c, I changed the method signature:
```typescript
// BEFORE:
@cliCompletion completionName completionNameParameterCompletion
async completion(what: string, completionName: string, ...args: string[]): Promise<this>

// AFTER (BROKEN):
@cliCompletion what whatParameterCompletion
// MISSING: @cliCompletion for filter parameter!
async completion(what: string, filter?: string): Promise<this>
```

**Impact:**
- Direct call: ✅ Works (method code correctly calls completionNameParameterCompletion)
- Tab completion: ❌ Broken (shell doesn't know to call completionNameParameterCompletion for filter)

**Fix Strategy:**
1. Add `@cliCompletion filter completionNameParameterCompletion`
1. Verify direct call still works
1. Document regression for future prevention

**Critical Learning:** When renaming parameters, always verify ALL TSDoc tags are updated, not just `@param`!

## **🎯 ACT**

### **Regression Analysis**

**What Went Wrong:**
1. Changed parameter name: `completionName` → `filter`
1. Updated `@param completionName` → `@param filter` ✅
1. **FORGOT** to update `@cliCompletion completionName` → `@cliCompletion filter` ❌

**Why It Happened:**
- Focused on method implementation and direct call behavior
- Verified direct call works (which uses method code, not TSDoc tags)
- Did NOT verify tab completion (which relies on TSDoc `@cliCompletion` tags)

**Critical Pattern Violation:**
> When refactoring a CLI method signature, ALWAYS verify both:
> 1. Direct call (tests method code)
> 1. Tab completion (tests TSDoc tags + shell integration)

### **Prevention Strategy**

**Checklist for CLI Method Signature Changes:**
- [ ] Update `@param` tags
- [ ] Update `@cliSyntax` tag
- [ ] Update `@cliCompletion` tags (ALL parameters with completion callbacks)
- [ ] Update `@cliExample` tags
- [ ] Test direct call
- [ ] **Test tab completion in bash shell**

**CMM4 Learning:**
> Comprehensive testing includes BOTH code paths (direct invocation) AND metadata paths (shell tab completion). A passing direct call does NOT guarantee working tab completion.
