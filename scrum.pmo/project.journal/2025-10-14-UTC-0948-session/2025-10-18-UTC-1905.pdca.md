**1. Added @cliValues Annotation**

Changed line 719 in `DefaultWeb4TSComponent.ts`:
```typescript
* @cliSyntax targetDir

* @cliValues targetDir § test/data
```

**Reason:** Without `@cliValues`, no enum values are shown, causing "Discovery Command" fallback display.

**2. Fixed Parameter Description**

Changed line 707 in `DefaultWeb4TSComponent.ts`:
```typescript
// OLD: @param targetDir Target directory (default: current working directory or test/data in test mode)
// NEW:
* @param targetDir Absolute path to project root (§ = discovered root, test/data = test isolation)
```

**Reason:** User feedback: "it needs to be the absolute directory of project root discovered dynamically" - the old description incorrectly said "current working directory".

**3. Added Completion Callback Method**

Added lines 1873-1879 in `DefaultCLI.ts`:
```typescript
/**
 * Completion for targetDir parameter
 * Returns: § (discovered project root) and test/data (test isolation)
 * @cliHide
 */
async targetDirParameterCompletion(currentArgs: string[]): Promise<string[]> {
  return this.enumParameterCompletion('targetDir');
}
```

**Reason:** The `!` prefix appears when `hasParameterCompletion()` returns false (lines 1069-1073 in DefaultCLI.ts). Adding this method makes the completion available.
