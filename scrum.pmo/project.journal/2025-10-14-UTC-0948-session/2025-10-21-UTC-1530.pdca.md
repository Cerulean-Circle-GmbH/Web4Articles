## **🎯 ACT**

**How to Fix (Documented, Not Yet Implemented):**

**Location:** `source.env` around lines 311-327

**Current Code:**
```bash
if [ ${#tokens[@]} -eq 1 ]; then
    # Single match detection
    local first_line=$(echo "$out" | head -1)
    if [[ "$first_line" =~ ^[[:space:]]*[0-9]+:[[:space:]]*(.+) ]]; then
        local method_with_params="${BASH_REMATCH[1]}"
        local clean_method=$(echo "$method_with_params" | sed 's/\x1b\[[0-9;]*m//g')
        clean_method=$(echo "$clean_method" | awk '{print $1}')
        # Add trailing space for next parameter
        COMPREPLY=("$clean_method ")
        return 0
    fi
fi
```

**The Fix:**

The code checks for numbered format (`1: method`) but when TSDoc display is shown (no numbers), it falls through to the multi-line processing which doesn't handle single-match auto-completion correctly.

**Add BEFORE the numbered line check:**

```bash
if [ ${#tokens[@]} -eq 1 ]; then
    # Single match detected
    local first_line=$(echo "$out" | head -1)
    
    # ✅ FIX: Check for TSDoc format (method signature without number prefix)
    # Pattern: "methodName <param> <?optional>" or "methodName !<required>"
    if [[ "$first_line" =~ ^[[:space:]]*([a-zA-Z_][a-zA-Z0-9_]*)[[:space:]]*(<!|<\?) ]]; then
        # Extract method name (first word)
        local method_name="${BASH_REMATCH[1]}"
        # Add trailing space for next parameter
        COMPREPLY=("$method_name ")
        return 0
    fi
    
    # Original numbered line check
    if [[ "$first_line" =~ ^[[:space:]]*[0-9]+:[[:space:]]*(.+) ]]; then
        local method_with_params="${BASH_REMATCH[1]}"
        local clean_method=$(echo "$method_with_params" | sed 's/\x1b\[[0-9;]*m//g')
        clean_method=$(echo "$clean_method" | awk '{print $1}')
        COMPREPLY=("$clean_method ")
        return 0
    fi
fi
```

**What This Does:**
1. When single match is detected (${#tokens[@]} -eq 1)
2. Check if first line is TSDoc format: `completion <what> <?filter>`
3. Extract method name using regex: `^[[:space:]]*([a-zA-Z_][a-zA-Z0-9_]*)[[:space:]]*(<!|<\?)`
4. Set COMPREPLY with method name + space
5. Return 0 to signal completion

**This will fix both cases:**
- Direct: `web4tscomponent compl<TAB>` → `web4tscomponent completion []`
- Nested: `web4tscomponent completion method compl<TAB>` → `web4tscomponent completion method completion []`
