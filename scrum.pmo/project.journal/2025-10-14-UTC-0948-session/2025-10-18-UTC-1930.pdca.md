## **📋 PLAN**

**Objective:** Make `web4tscomponent <TAB>` trigger hierarchical method display

**Requirements Traceability:** User requirement: "i wanted what web4tscomponent completion method does"

**Current Behavior Analysis:**

**When user types: `web4tscomponent <TAB>`**
1. Bash calls `_web4_tscompletion`
2. TSCompletion called with: `["DefaultCLI,DefaultWeb4TSComponent"]`
3. TSCompletion returns: space-separated method names
4. Bash shows: flat list of 234 possibilities

**When user types: `web4tscomponent completion method <TAB>`**
1. Bash calls `_web4_tscompletion`
2. TSCompletion called with: `["DefaultCLI,DefaultWeb4TSComponent", "completion", "method"]`
3. TSCompletion returns: `__CALLBACK__:filterParameterCompletion`
4. Callback executes: `web4tscomponent completeParameter filterParameterCompletion completion method`
5. Returns: hierarchical numbered list with parameters
6. Bash shows: **colored hierarchical display**

**Implementation Strategy:**

**Option 1: Automatic Injection (RECOMMENDED)**
- When args are empty (just command name), inject `completion method`
- This makes TSCompletion trigger the hierarchical callback
- User gets numbered display automatically

**Code Location:** `source.env` line ~123-128, modify the `completeArgs` construction

**Before:**
```bash
local className="Web4TSComponentCLI,Default${component}"
local completeArgs=("$className" "${args[@]}")
```

**After:**
```bash
local className="Web4TSComponentCLI,Default${component}"
# Auto-inject 'completion method' when no method specified (hierarchical display)
if [ ${#args[@]} -eq 0 ] || [ "${args[0]}" = "" ]; then
    local completeArgs=("$className" "completion" "method")
else
    local completeArgs=("$className" "${args[@]}")
fi
```

## **🎯 ACT**

**Success Achieved:** Hierarchical method display on single TAB with filter support

**Initial Issue (FIXED):**
- `web4tscomponent <TAB>` showed flat list (234 possibilities)
- **Solution:** Direct callback to `completionNameParameterCompletion`

**Second Issue (FIXED):**
- First attempt showed `method parameter` instead of method list
- **Root Cause:** TSCompletion was looking for `what` parameter values
- **Solution:** Bypass TSCompletion, call callback directly

**Third Issue (FIXED):**
- `web4tscomponent com<TAB>` fell back to flat bash completion
- **Root Cause:** Logic only triggered hierarchical display when args empty
- **Solution:** Extend logic to handle single partial method name as filter
- **Implementation:** Pass first arg as filter parameter to callback

**ROOT CAUSE FOUND (ACTUAL BUG):**
- The regression was NOT in the bash completion script!
- **Real Bug:** `DefaultCLI.ts` lines 1460-1461, 1584-1585
- **Code:** `filtered = prefixFiltered.length > 0 ? prefixFiltered : filtered;`
- **Problem:** When filter matches nothing, falls back to showing ALL methods
- **Fix:** Remove fallback: `filtered = filtered.filter(name => name.startsWith(filterPrefix));`

**Fourth Issue (FIXED - Attempt 1 FAILED):**
- Single match showed TSDoc but didn't auto-complete the method name
- `web4tscomponent compl<TAB>` stayed as `compl` instead of completing to `completion `
- **First Attempt:** Used regex `([0-9]+):\)[[:space:]]*([^[:space:]]+)` to extract method names
- **Regression:** Regex was too strict, failed on ANSI-colored output, no tokens extracted
- **Result:** When tokens.length = 0, code fell through showing all 208 methods unfiltered
- **BUT:** This revealed the REAL bug in DefaultCLI.ts filter logic!

**Fourth Issue (FIXED - Attempt 2 SUCCESS):**
- **Root Cause:** Two different output formats for single match!
  1. **Numbered format:** `1: methodName <params>` (when showing list)
  2. **TSDoc format:** `methodName <params>\n────\n📖 Documentation:...` (single match with docs)
- **Problem:** Bash script only handled numbered format, missed TSDoc format
- **Solution:** 
  1. Use simpler regex `([0-9]+):` to extract token numbers (works with ANSI codes)
  2. **NEW:** If `tokens.length == 0` (no numbers), extract method from first line (TSDoc format)
  3. For single numbered match, extract method name from full line using second regex pass
  4. Strip ANSI codes with `sed`, extract first word with `awk`
  5. If no tokens and no valid first word, set `COMPREPLY=()` to prevent fallback

**Code Logic (lines 175-187, 245-253):**
```bash
# Check if we have numbered entries
while IFS= read -r line; do
    if [[ "$line" =~ ^[[:space:]]*([0-9]+): ]]; then
        tokens+=("${BASH_REMATCH[1]}")
    fi
done <<< "$out"

# No numbers found → Single match with TSDoc format
if [ ${#tokens[@]} -eq 0 ]; then
    local first_line=$(echo "$out" | head -1)
    local clean_method=$(echo "$first_line" | sed 's/\x1b\[[0-9;]*m//g' | awk '{print $1}')
    if [ -n "$clean_method" ]; then
        COMPREPLY=("$clean_method ")  # Auto-complete!
        return 0
    fi
fi
```
