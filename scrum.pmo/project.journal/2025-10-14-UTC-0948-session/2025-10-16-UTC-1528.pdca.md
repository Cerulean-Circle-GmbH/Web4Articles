## **🔧 DO**

### **Root Cause Analysis**

**Problem:** Methods without CLI annotations show NO parameters in completion output

**Investigation:**
```typescript
// DefaultCLI.ts:470-508
private extractParameterInfoFromTSCompletion(methodName: string): any[] {
  if (typeof TSCompletion.getEnhancedMethodParameters === 'function') {
    const paramInfo = TSCompletion.getEnhancedMethodParameters(this.componentClass.name, methodName);
    
    return paramInfo.map(...);  // ❌ BUG: If paramInfo is [], returns [] immediately!
  }
  return this.extractParameterInfoFallback(methodName);  // Never reached!
}
```

**Root Cause:** When `TSCompletion.getEnhancedMethodParameters` returns empty array `[]` (for private methods, methods without CLI annotations, etc.), the code immediately returns `[]` without trying the fallback!

**Solution:** Check if `paramInfo.length === 0` and use fallback in that case:

```typescript
if (typeof TSCompletion.getEnhancedMethodParameters === 'function') {
  const paramInfo = TSCompletion.getEnhancedMethodParameters(this.componentClass.name, methodName);
  
  // ✅ FIX: If TSCompletion found no parameters but method exists, use fallback
  if (paramInfo.length === 0) {
    return this.extractParameterInfoFallback(methodName);
  }
  
  return paramInfo.map(...);
}
```

**Fallback Mechanism:** `extractParameterInfoFallback` uses runtime reflection:
```typescript
const method = this.componentClass.prototype[methodName];
const paramCount = method.length;  // JavaScript Function.length = parameter count
// Generate intelligent names: componentName, version, options, etc.
```
