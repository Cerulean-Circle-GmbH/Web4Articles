**Critical Insight:** P24 was about preventing directory fallback, NOT about what content to show!

**Phase 3: Decision - Update Test**

**Rationale:**
1. Core bug fix verified: No directory fallback ✅
2. Test 5j2 checking for callback names is testing *different* behavior
3. Current behavior (parameter names) appears intentional
4. Test should verify regression prevention: "NOT .git/"

**Action Taken:**

```typescript

// NEW (matches actual behavior):

expect(stripped).toContain('<completionName>');
expect(stripped).toContain('<?component:');
```
