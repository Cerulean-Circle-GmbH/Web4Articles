## Plan

**Goal:** TypeScript generates colored prompt echo, bash just displays it

**User Feedback (2025-10-21 UTC 11:50):**
> "your web4 command > web4tscomponent completion method compl
> 
> SHOUD NOT END ON NEW LINE.
> web4 should be cyan, your and command white
> 
> web4tscomponent completion method compl
> in the usal coloring as used always"

**Root Cause:**
- Prompt echo coloring was in bash (dumb layer)
- TypeScript should handle all formatting (smart layer)
- Wrong color scheme: had cyan for entire "your web4 command >" 
- Extra newline preventing bash from appending completion on same line

**Solution Design:**
1. Bash exports `WEB4_CLI_NAME` environment variable
2. TypeScript reads `WEB4_CLI_NAME` for correct CLI name
3. TypeScript generates ANSI-colored prompt in DISPLAY output
4. Bash removes its prompt echo logic (just displays TypeScript output)
5. Correct colors: `your` (white), `web4` (cyan), `command >` (white), command (no color)
6. No trailing newline - bash appends completion on same line

## Do

### 1. Bash: Export CLI Name
**File:** `source.env`

Added before TypeScript calls:
```bash
# Export CLI name for TypeScript to use in prompt echo
export WEB4_CLI_NAME="$cli"
result=$(timeout 30s "$cli" completion method "$cur" 2>>"$logfile" || true)
unset WEB4_CLI_NAME
```

### 2. TypeScript: Read CLI Name from Environment
**File:** `DefaultCLI.ts` lines 1361-1364

```typescript
// Build command-line context for prompt echo
// Bash exports WEB4_CLI_NAME for us to use in prompt
const cliName = process.env.WEB4_CLI_NAME || 'cli';
const commandContext = [cliName, ...contextArgs];
```

### 3. TypeScript: Generate Colored Prompt
**File:** `DefaultCLI.ts` lines 1316-1326

```typescript
// Add colored prompt echo if context provided
if (commandContext && commandContext.length > 0) {
  const cyan = '\x1b[36m';
  const white = '\x1b[37m';
  const reset = '\x1b[0m';
  // Format: "your web4 command >" with "web4" in cyan, rest in white
  // Then the actual command without newline so bash can append completion
  const prompt = `${white}your ${cyan}web4${white} command >${reset} ${commandContext.join(' ')}`;
  lines.push(`DISPLAY: `);
  lines.push(`DISPLAY: ${prompt}`);
}
```

### 4. Bash: Remove Duplicate Prompt Echo
**File:** `source.env` lines 93-96

Removed the bash prompt echo logic:
```bash
# OLD (removed):
if [ -n "$display" ]; then
    printf "\n%s\n" "$display"
    printf "\nyour web4 command > %s %s" "$cli" "${COMP_WORDS[@]:1}"
    printf "\n"
fi

# NEW (simplified):
display=$(echo "$result" | grep "^DISPLAY: " | cut -d' ' -f2-)
[ -n "$display" ] && printf "\n%s\n" "$display"
```
