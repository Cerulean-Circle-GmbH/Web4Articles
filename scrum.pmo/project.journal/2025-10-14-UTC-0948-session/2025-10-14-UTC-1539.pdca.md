**Root Cause Analysis:**
My CMM1 hacking violation in 1527 PDCA spread incorrect pattern to 3 other test files

**Pattern Rule Established:**
- **Test files**: Use `__dirname` (file-relative paths from test file location)
- **Runtime code**: May use `process.cwd()` (execution-relative) when needed

**Why `__dirname` for tests:**
- Explicit about file location (not dependent on execution context)
- Consistent regardless of where vitest runs from
- More maintainable and predictable
