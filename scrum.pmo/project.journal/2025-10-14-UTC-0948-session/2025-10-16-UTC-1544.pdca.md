## **📋 PLAN**

**Objective:** Display parameter names like `<action>` in yellow, not callback names

**Current Behavior:**
```bash
$ web4tscomponent completion parameter
1: actionParameterCompletion          # ❌ Callback name
2: completionNameParameterCompletion  # ❌ Callback name
3: componentParameterCompletion       # ❌ Callback name
```

**Desired Behavior:**
```bash
$ web4tscomponent completion parameter
1: <action>              # ✅ Parameter name in yellow
2: <completionName>      # ✅ Parameter name in yellow
3: <component>           # ✅ Parameter name in yellow
```

**Implementation Plan:**
1. Strip `ParameterCompletion` suffix from callback names
1. Determine if parameter is required or optional (for `<>` vs `<?>` notation)
1. Wrap in Web4 notation angle brackets
1. Apply BRIGHT_YELLOW color (matching CLI help parameter display)

**Transformation Logic:**
```typescript
// Before: actionParameterCompletion
// After:  <action>

name.replace(/ParameterCompletion$/, '')  // Strip suffix
// Then wrap in angle brackets with yellow color
```

---

## **🔧 DO**

### **Implementation**

**Single-Line Transformation:**

```typescript
// In completionNameParameterCompletion (what === 'parameter' branch)

// BEFORE:
return filtered.map((name, index) => `${BRIGHT_CYAN}${index + 1}:${RESET} ${name}`);
// Output: "1: actionParameterCompletion"

// AFTER:
return filtered.map((name, index) => {
  const paramName = name.replace(/ParameterCompletion$/, '');  // Strip suffix
  return `${BRIGHT_CYAN}${index + 1}:${RESET} ${BRIGHT_YELLOW}<${paramName}>${RESET}`;  // Web4 notation + yellow
});
// Output: "1: <action>" (in yellow)
```

**Changes:**
1. **Strip suffix:** `name.replace(/ParameterCompletion$/, '')` removes "ParameterCompletion"
1. **Wrap in brackets:** `<${paramName}>` applies Web4 notation
1. **Apply yellow color:** `${BRIGHT_YELLOW}...${RESET}` matches CLI help parameter display

**Files Changed:**
- `components/Web4TSComponent/0.3.13.1/src/ts/layer2/DefaultCLI.ts` (lines 1330-1348)
