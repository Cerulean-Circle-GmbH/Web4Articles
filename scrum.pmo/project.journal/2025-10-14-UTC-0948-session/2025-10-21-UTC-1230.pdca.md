1. Method signature with parameters
2. Visual separator line
3. "📖 Documentation:" header
4. Full TSDoc description

- **Wrong 1:** Return array of semantic units `[signature, separator, header, doc]` - resulted in each element on separate line

**User had to explicitly guide** to the correct solution.

### Goal

Fix multi-line TSDoc display by ensuring:
1. TypeScript returns ONE string with embedded `\n` characters
2. `formatCompletionOutput` **splits on `\n`** before adding `DISPLAY:` prefix
3. Bash `printf` renders the multi-line output correctly
