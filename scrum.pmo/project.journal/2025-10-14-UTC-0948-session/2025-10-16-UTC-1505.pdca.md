## **📋 PLAN**

**Objective:** Show ALL methods (including @cliHide) with full signatures using methodSignatures + extractParameterInfoFromTSCompletion

**Current Issue:**

`analyzeComponentMethods()` filters out:
- Methods with `@cliHide` annotation (line 251)
- Methods starting with `_` (line 247)

This is correct for help output, but the `completion` method is a DISCOVERY tool - it should show hidden methods!

**Previous Behavior (good for discovery, bad for signatures):**
```typescript
const allMethods = Array.from(this.methodSignatures.keys());
// Shows ALL methods but methodSignatures only has {name, paramCount, isAsync}
```

**Current Behavior (good for signatures, bad for discovery):**
```typescript
const methods = this.analyzeComponentMethods();
// Has full parameter info but filters out @cliHide methods
```

**Solution:**
```typescript
// Get ALL methods from methodSignatures.keys()
const allMethodNames = Array.from(this.methodSignatures.keys());

// For each method, extract parameters using extractParameterInfoFromTSCompletion
for (const methodName of allMethodNames) {
  const parameters = this.extractParameterInfoFromTSCompletion(methodName);
  // Generate signature using generateParameterSyntax
}
```

**Key Methods:**
- `methodSignatures.keys()` → ALL method names (including hidden)
- `extractParameterInfoFromTSCompletion(methodName)` → Get parameters for ANY method
- `generateParameterSyntax(param, methodName)` → Format with Web4 notation

### **Implementation**

**File:** `components/Web4TSComponent/0.3.13.1/src/ts/layer2/DefaultCLI.ts` (lines 1307-1340)

**BEFORE (filtered methods):**
```typescript
// Use analyzeComponentMethods for full signature generation
const methods = this.analyzeComponentMethods(); // Filters out @cliHide methods

```

**AFTER (ALL methods):**
```typescript
// Use methodSignatures for ALL methods (including @cliHide)
// Discovery tool should show hidden methods for debugging/development
const allMethodNames = Array.from(this.methodSignatures.keys());
let filtered = allMethodNames
  .filter(name => !name.endsWith('ParameterCompletion'))
  .filter(name => name !== 'completeParameter')
  .filter(name => name !== 'execute')
  .filter(name => name !== 'start')
  .sort();

// For each method, extract parameters
return filtered.map((methodName, index) => {
  const parameters = this.extractParameterInfoFromTSCompletion(methodName);
  
  if (parameters && parameters.length > 0) {
    const paramList = parameters.map((p: any) => {
      return this.generateParameterSyntax(p, methodName);
    }).join(' ');
    return `${BRIGHT_CYAN}${index + 1}:${RESET} ${methodName} ${BRIGHT_YELLOW}${paramList}${RESET}`;
  }
  return `${BRIGHT_CYAN}${index + 1}:${RESET} ${methodName}`;
});
```

**Key Changes:**
1. Switched from `analyzeComponentMethods()` to `methodSignatures.keys()` for ALL methods
2. Call `extractParameterInfoFromTSCompletion(methodName)` for each method
3. Still use `generateParameterSyntax` for Web4 notation
4. Preserved color coding (bright cyan numbers, bright yellow parameters)

**Why This Works:**
- `methodSignatures` contains ALL methods (not filtered by @cliHide)
- `extractParameterInfoFromTSCompletion()` is the same method used by `analyzeComponentMethods`
- `generateParameterSyntax()` applies Web4 notation and checks for completion callbacks
