## **📋 PLAN**

**Objective:** Fix O(n×m) performance issue with caching

**Root Cause Analysis:**

**Current Implementation (DRY Violation):**
```typescript
// For EACH of 18 parameters:
return filtered.map((callbackName, index) => {
  // Scan ALL 200+ methods
  for (const methodName of methodNames) {
    const params = this.extractParameterInfoFromTSCompletion(methodName);  // ❌ REPEATED 18×200 = 3,600 times!
    const param = params.find(p => p.name === paramName);
  }
});
```

**Performance Issue:**
- 18 parameters × 200 methods = 3,600 parameter extractions
- Each extraction parses TypeScript AST
- Result: >5 seconds (timeout)

**DRY Principle Violated:**
> "Don't Repeat Yourself" - We're extracting parameters from the same methods over and over

**Solution:**
```typescript
// Extract parameters from ALL methods ONCE
const allMethodParams = new Map();
for (const methodName of methodNames) {
  allMethodParams.set(methodName, this.extractParameterInfoFromTSCompletion(methodName));
}

// Then for EACH parameter, just look up cached data
return filtered.map((callbackName, index) => {
  for (const methodName of methodNames) {
    const params = allMethodParams.get(methodName);  // ✅ Cached lookup
    const param = params.find(p => p.name === paramName);
  }
});
```

**Expected Improvement:**
- From: 3,600 extractions (>5s)
- To: 200 extractions (<100ms)
- 36× faster!

## **🔧 DO**

### **Performance Fix Implementation**

**Root Cause:** Repeated extraction - O(parameters × methods) = 18 × 200+ = 3,600+ extractions

**Solution:** Cache extractions - O(methods) = 200 extractions

**BEFORE (DRY Violation):**
```typescript
// For EACH of 18 parameters:
return filtered.map((callbackName, index) => {
  for (const methodName of methodNames) {
    const params = this.extractParameterInfoFromTSCompletion(methodName);  // ❌ 3,600 times!
  }
});
```

**AFTER (DRY Compliant):**
```typescript
// Extract from ALL methods ONCE
const allMethodParams = new Map<string, any[]>();
const cliMethodsSet = new Set<string>();

for (const methodName of allMethodNames) {
  const params = this.extractParameterInfoFromTSCompletion(methodName);  // ✅ 200 times
  allMethodParams.set(methodName, params);
  if (params.length > 0) cliMethodsSet.add(methodName);
}

// For EACH parameter, use cached data
return filtered.map((callbackName, index) => {
  for (const methodName of methodNames) {
    const params = allMethodParams.get(methodName)!;  // ✅ Cached lookup
  }
});
```
