### **Step 3: Refined Component.interface.ts Design (✅ COMPLETE)**

**BEFORE (PDCA 1540 - WRONG):**
```typescript
export interface Component<TModel extends Model = Model> {
  init(scenario: Scenario<TModel>): this;
  toScenario(name?: string): Promise<Scenario<TModel>>;
  process(...args: any[]): Promise<this> | this;  // ❌ PLACEBO!
}
```

**AFTER (CORRECTED):**
```typescript
/**
 * Component.interface.ts - Base interface for ALL Web4 components
 * Every Web4 component must implement these fundamental methods
 * 
 * Purpose: Provides common contract for:
 * - Lifecycle (init, toScenario)
 * - Development (test, build, clean)
 * - Introspection (tree)
 */

import { Scenario } from './Scenario.interface.js';
import { Model } from './Model.interface.js';

/**
 * Base interface for all Web4 components
 * Ensures every component has fundamental lifecycle and development methods
 */
export interface Component<TModel extends Model = Model> {
  // ========================================
  // LIFECYCLE METHODS (Web4 pattern)
  // ========================================
  
  /**
   * Initialize component with scenario
   * @param scenario Scenario containing component configuration
   * @returns this for method chaining
   */
  init(scenario: Scenario<TModel>): this;
  
  /**
   * Convert component state to scenario for persistence
   * @param name Optional scenario name
   * @returns Scenario representation of current state
   */
  toScenario(name?: string): Promise<Scenario<TModel>>;
  
  // ========================================
  // DEVELOPMENT METHODS (Delegated to Web4TSComponent)
  // ========================================
  
  /**
   * Run component tests (full suite or selective)
   * Delegates to Web4TSComponent for hierarchical testing
   * 
   * @param scope Test scope: 'all' | 'file' | 'describe' | 'itCase'
   * @param references Hierarchical test references (e.g., '1', '2a', '3b2')
   * @returns this for method chaining
   * 
   * @example
   * await component.test();              // Run all tests
   * await component.test('file', '1');   // Run test file #1
   * await component.test('itCase', '2a1'); // Run specific test case
   */
  test(scope?: string, ...references: string[]): Promise<this>;
  
  /**
   * Build component (TypeScript compilation)
   * Delegates to Web4TSComponent
   * 
   * @returns this for method chaining
   */
  build(): Promise<this>;
  
  /**
   * Clean component build artifacts
   * Delegates to Web4TSComponent
   * 
   * @returns this for method chaining
   */
  clean(): Promise<this>;
  
  // ========================================
  // INTROSPECTION METHODS (Optional but useful)
  // ========================================
  
  /**
   * Show component directory tree structure
   * Delegates to Web4TSComponent
   * 
   * @param depth Maximum depth to show (default: 4)
   * @param showHidden Whether to show hidden files (default: false)
   * @returns this for method chaining
   */
  tree?(depth?: string, showHidden?: string): Promise<this>;
}

/**
 * Extended interface for components with Web4TSComponent delegation
 * All generated components get a web4ts reference for advanced features
 */
export interface ComponentWithWeb4TS<TModel extends Model = Model> 
  extends Component<TModel> {
  /**
   * Web4TSComponent instance for delegation (DRY principle)
   * Provides access to all Component methods via delegation
   * @internal Used by implementation to delegate test, build, clean, tree
   */
  readonly web4ts: any; // Will be properly typed as Web4TSComponent once circular dep resolved
}
```

**Key Changes:**
1. ❌ **Removed:** `process()` method (placebo eliminated)
1. ✅ **Added:** `test()` method (with full signature and documentation)
1. ✅ **Added:** `build()` method
1. ✅ **Added:** `clean()` method
1. ✅ **Added:** `tree()` method (optional - note the `?`)
1. ✅ **Clear sections:** Lifecycle, Development, Introspection

**Wait - this is DUPLICATION! Let me refine...**

**BETTER APPROACH - DRY Delegation Helper:**
```typescript
export class Default{{COMPONENT_NAME}} implements {{COMPONENT_NAME}} {
  private web4ts = new DefaultWeb4TSComponent();
  
  /**
   * Delegate method call to web4ts with automatic context loading
   * @cliHide
   */
  private async delegateToWeb4TS(methodName: string, ...args: any[]): Promise<this> {
    await this.web4ts.on('{{COMPONENT_NAME}}', '{{VERSION}}');
    await this.web4ts[methodName](...args);
    return this;
  }
  
  // Development methods (ONE-LINE delegation!)
  async test(scope: string = 'all', ...references: string[]): Promise<this> {
    return this.delegateToWeb4TS('test', scope, ...references);
  }
  
  async build(): Promise<this> {
    return this.delegateToWeb4TS('build');
  }
  
  async clean(): Promise<this> {
    return this.delegateToWeb4TS('clean');
  }
  
  async tree(depth: string = '4', showHidden: string = 'false'): Promise<this> {
    return this.delegateToWeb4TS('tree', depth, showHidden);
  }
}
```

## **🎯 ACT**

### **QA Decisions**

1. **Q:** Should process() be eliminated?
   **A:** YES. Never called, no real implementation, pure placebo. Safe to remove.

1. **Q:** Should test(), build(), clean() be in Component interface?
   **A:** YES. Every component needs these. All can delegate to ONE implementation (Web4TSComponent).

1. **Q:** Should tree() be in Component interface?
   **A:** YES, but optional (`tree?:`) - useful but not critical.

1. **Q:** How to implement delegation in templates?
   **A:** Add DRY helper `delegateToWeb4TS(methodName, ...args)` for reuse. One-line delegation methods.

1. **Q:** What about existing components with process()?
   **A:** REMOVE from interface. If any component overrides it for custom logic, they can keep as private method. No breaking change since never called via interface.

### **Lessons Learned**

1. **Placebo Methods Accumulate:** `process()` sat unused for years - regular audits needed
1. **Interfaces Should Match Reality:** test/build/clean exist but weren't in interface
1. **Delegation is Powerful:** ONE implementation serves ALL components via web4ts
1. **TRON Catches Architectural Debt:** Human review spotted what automated systems missed
1. **Fix Before Implementing:** Correcting PDCA 1540 now saves rework later
