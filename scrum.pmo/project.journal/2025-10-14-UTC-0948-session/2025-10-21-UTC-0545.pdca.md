### **Migration Strategy**

**Phase 1: Define Output Format Protocol**

TypeScript should return structured hints:

```typescript
interface CompletionResult {
  type: 'single' | 'multiple' | 'values';
  completion?: string;        // For single match auto-complete
  values?: string[];          // For bash compgen
  display?: string;           // For hierarchical display (with colors)
}

// Return as JSON with marker:
// __FORMAT__:{"type":"single","completion":"completion","display":"...""}
```

**Phase 2: Simplify Bash (Target: 80 lines)**

```bash
_web4_tscompletion() {
    local cli="$WEB4_PROJECT_ROOT/scripts/$2"
    local cur="${COMP_WORDS[COMP_CWORD]}"
    local args=("${COMP_WORDS[@]:1}")
    
    # Call TypeScript with all arguments
    local out=$(timeout 30s $cli __complete__ "${args[@]}" 2>/dev/null || true)
    
    # Check for structured format
    if [[ "$out" == __FORMAT__:* ]]; then
        local json="${out#__FORMAT__:}"
        local display=$(echo "$json" | jq -r '.display // empty')
        local completion=$(echo "$json" | jq -r '.completion // empty')
        local values=$(echo "$json" | jq -r '.values[]? // empty')
        
        # Show display if provided
        [ -n "$display" ] && printf "\n%s\n" "$display"
        
        # Set COMPREPLY
        if [ -n "$completion" ]; then
            COMPREPLY=("$completion ")
        elif [ -n "$values" ]; then
            COMPREPLY=( $(compgen -W "$values" -- "$cur") )
        else
            COMPREPLY=()
        fi
    else
        # Legacy fallback: treat as space-separated values
        COMPREPLY=( $(compgen -W "$out" -- "$cur") )
    fi
}
```

**Phase 3: TypeScript Handles Everything**

New method in DefaultCLI:

```typescript
async __complete__(args: string[]): Promise<void> {
  // All the complex logic from bash moved here:
  // - ANSI stripping
  // - Output parsing
  // - Single-match detection
  // - Format as structured JSON
  
  const result = await this.generateCompletion(args);
  
  // Output structured format
  console.log(`__FORMAT__:${JSON.stringify(result)}`);
}
```
