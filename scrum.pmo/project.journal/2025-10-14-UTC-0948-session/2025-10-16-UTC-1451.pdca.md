## **📋 PLAN**

**Objective:** Leverage DefaultCLI's auto-discovery to generate full method signatures in completion output

**Current Behavior:**
```bash
$ web4tscomponent completion method creat
1: create
2: createBasePackageJson
...
```

**Desired Behavior:**
```bash
$ web4tscomponent completion method creat
1: create <component> <?version:'0.1.0.0'> <?options:'all'>
2: createBasePackageJson <?targetDir>
...
```

**Implementation Strategy:**

1. Use `analyzeComponentMethods()` instead of `methodSignatures.keys()` for methods
1. For each method, access `method.parameters` array
1. For each parameter, call `this.generateParameterSyntax(param, methodName)`
1. Join parameters with spaces to build full signature
1. Keep parameter completions unchanged (just callback names)

**Key Methods to Leverage:**
- `analyzeComponentMethods()` - Returns `MethodInfo[]` with populated `parameters` field
- `generateParameterSyntax(param, methodName)` - Generates Web4 notation: `<required>`, `<?optional:'default'>`, `!<?noCompletion>`

## **🔧 DO**

### **Implementation**

**File:** `components/Web4TSComponent/0.3.13.1/src/ts/layer2/DefaultCLI.ts` (lines 1270-1334)

**BEFORE (showing only method names):**
```typescript
const allMethods = Array.from(this.methodSignatures.keys());
let filtered = allMethods.filter(...).sort();
return filtered.map((name, index) => `${BRIGHT_CYAN}${index + 1}:${RESET} ${name}`);
```

**AFTER (showing full signatures):**
```typescript
if (what === 'method') {
  // Use analyzeComponentMethods for full signature generation
  const methods = this.analyzeComponentMethods();
  let filtered = methods.filter(...);
  
  // Generate full CLI signatures using auto-discovery
  return filtered.map((method, index) => {
    if (method.parameters && method.parameters.length > 0) {
      // Build parameter list using auto-discovery
      const paramList = method.parameters.map((p: any) => {
        return this.generateParameterSyntax(p, method.name);
      }).join(' ');
      return `${BRIGHT_CYAN}${index + 1}:${RESET} ${method.name} ${paramList}`;
    }
    return `${BRIGHT_CYAN}${index + 1}:${RESET} ${method.name}`;
  });
}
```

**Key Changes:**
1. Switched from `methodSignatures.keys()` to `analyzeComponentMethods()` for method data
1. Access `method.parameters` array (guaranteed populated by `extractParameterInfoFromTSCompletion`)
1. Call `generateParameterSyntax` for each parameter to apply Web4 notation
1. Join parameters with spaces to build full signature
1. Parameter completions remain unchanged (just callback names)
