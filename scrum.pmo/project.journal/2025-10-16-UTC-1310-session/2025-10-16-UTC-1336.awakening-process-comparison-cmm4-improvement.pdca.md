**5. CMM4 Improvement Proposal**

**Problem Statement:**
Process improvements are documented in PDCAs but not integrated into the actual startup procedures (README.md), causing agents to repeat the patterns the improvements were designed to prevent.

**Root Cause:**
1. PDCAs document learnings and improvements
2. Individual documents get updated (start-command.md, recovery checklist)
3. But README.md (main startup entry point) doesn't get updated
4. New agents follow README, miss the improvements
5. Pattern repeats

**CMM4 Solution: Integration Protocol**

**A. Update README.md Startup Flow (Primary Entry Point)**

**Current README.md Step 11:**
```markdown
11. **Create Session Start PDCA and Agent Identity**:
    - Use the startup decision framework from PDCA.howto.decide.md
    - Present the standard 5 decisions: Focus Area, Role Selection, Session Duration, 
      PDCA Location, Agent Identity
```

**Proposed README.md Enhancement:**

**Insert NEW Step 9 (Breadcrumb Navigation - MANDATORY)**
```markdown
9. **Breadcrumb Navigation (MANDATORY - Achieve Situational Awareness)**:
   ```bash
   # Find most recent PDCA in session directory
   cd scrum.pmo/project.journal/
   LATEST_SESSION=$(ls -td */ | head -1)
   LATEST_PDCA=$(ls -t "${LATEST_SESSION}"*.pdca.md | head -1)
   echo "Starting breadcrumb navigation from: ${LATEST_PDCA}"
   ```
   
   **Navigate Backward Through Previous PDCA Chain:**
   - **Minimum Depth:** 5 PDCAs (basic context)
   - **Recommended Depth:** 10-15 PDCAs (comprehensive understanding)
   - **Reading Method:** Systematic level-by-level (don't skip)
   - **Focus Areas:** Current work, patterns to avoid, protocols to follow
   
   **Breadcrumb Navigation Checklist:**
   - [ ] Read Level 0: Most recent PDCA completely
   - [ ] Follow "Previous PDCA" link, read that PDCA completely
   - [ ] Continue backward minimum 5 PDCAs (recommended 10-15)
   - [ ] Read related documents referenced (CMM3 7c depth 3 applies)
   - [ ] Document patterns discovered (recurring themes, agent behaviors)
   - [ ] Note protocols established (what must be followed)
   - [ ] Identify current focus (what is the session working on)
   
   **Situational Awareness Validation (MUST PASS BEFORE PROCEEDING):**
   ```
   Can you answer these questions from breadcrumb reading?
   1. What is the current work focus of this session?
   2. What patterns must I avoid? (shallow reading, verify-avoidance, etc.)
   3. What protocols must I follow? (depth 3, link validation, etc.)
   4. What breakthroughs have been achieved?
   5. What is my role in continuing this work?
   
   If you cannot answer these confidently → READ MORE BREADCRUMBS
   ```
   
   **Why This Comes BEFORE Decisions:**
   The breadcrumb navigation informs your role selection, focus area, and session planning.
   Don't present decisions in vacuum - present them with context from breadcrumbs.
   
   **See:** [Breadcrumb Awakening PDCA](scrum.pmo/project.journal/2025-10-14-UTC-0940-session/2025-10-15-UTC-0846.breadcrumb-navigation-agent-awakening.pdca.md)
```

**Renumber Existing Steps:**
- Old Step 9 → New Step 10 (Create project status)
- Old Step 10 → New Step 11 (Create dev branch)  
- Old Step 11 → New Step 12 (Create Session Start PDCA) ← NOW happens AFTER breadcrumbs

**Update Step 12 (Session Start PDCA):**
```markdown
12. **Create Session Start PDCA and Agent Identity**:
    - NOW with situational awareness from breadcrumbs, use startup decision framework
    - Present the standard 5 decisions INFORMED by breadcrumb context:
      * Decision 1: Focus Area (aligned with current session trajectory)
      * Decision 2: Role Selection (informed by patterns discovered)
      * Decision 3: Session Duration (based on work complexity observed)
      * Decision 4: PDCA Location (consistent with session structure)
      * Decision 5: Agent Identity (building on previous agent work)
    - **After user answers:** Create complete agent identity file
    - **CRITICAL:** Use Template Version 3.2.4.2 with proper dual link format
```
