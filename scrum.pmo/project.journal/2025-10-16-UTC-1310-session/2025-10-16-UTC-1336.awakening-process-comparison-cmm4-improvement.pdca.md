```markdown
## **Breadcrumb Navigation Protocol (RAG System for Assumption Verification)**

### **Core Principle:**
Breadcrumb navigation is your **distributed memory system** - use it WHENEVER verifying assumptions:
- **AT START:** MUST DO process for situational awareness
- **DURING LIFETIME:** RAG-equivalent for assumption verification before work
- **WHEN UNCERTAIN:** Go deeper, read more context
- **STILL UNCERTAIN:** ASK TRON (never work on assumptions)

### **At Startup (MANDATORY):**

```bash
# Find most recent PDCA in session directory
cd scrum.pmo/project.journal/
LATEST_SESSION=$(ls -td */ | head -1)
LATEST_PDCA=$(ls -t "${LATEST_SESSION}"*.pdca.md | head -1)
echo "Starting breadcrumb navigation from: ${LATEST_PDCA}"
```

**Initial Depth:** Start shallow (3-5 PDCAs)
**Read systematically:** Level 0 → Level 1 → Level 2...
**Validate understanding:** Can answer 5 situational awareness questions?
**If uncertain:** Go deeper (read more PDCAs)
**Still uncertain:** ASK TRON before proceeding

**Situational Awareness Questions (Must Answer Before Work):**
1. What is the current work focus of this session?
2. What patterns must I avoid?
3. What protocols must I follow?
4. What breakthroughs have been achieved?
5. What is my role in continuing this work?

### **During Lifetime (Continuous Assumption Verification):**

**When to Query Breadcrumbs:**
- Before making architectural decisions
- When encountering unfamiliar patterns
- If claiming "this should work" without evidence
- When user mentions previous work/context
- Any time you realize you're assuming something

**How to Query:**
1. Identify what you're assuming
2. Search breadcrumbs for that topic (grep, Previous PDCA links)
3. Read relevant PDCAs to verify
4. If uncertain after reading → Go deeper
5. If still uncertain → ASK TRON

**Example:**
```
Assumption: "Link validation was probably already done"
Action: Query breadcrumbs → Find 2025-10-14 link validation PDCAs
Verification: Read those PDCAs, understand protocol
Result: Know the protocol, apply it correctly
```

### **Variable Depth Strategy:**

**NOT fixed minimum - context-dependent:**
- Start shallow: 3-5 PDCAs for basic context
- Uncertain? Go deeper: 5-10 PDCAs
- Still uncertain? Go deeper: 10-15 PDCAs
- STILL uncertain after reading? **ASK TRON**

**Depth Indicators:**
- ✅ Can answer 5 questions confidently → sufficient
- ⚠️ Vague understanding → read more
- ❌ Making assumptions → read more OR ask TRON
- 🚨 About to make changes based on assumptions → STOP, ASK TRON

**See:** [Breadcrumb Awakening PDCA](../2025-10-14-UTC-0940-session/2025-10-15-UTC-0846.breadcrumb-navigation-agent-awakening.pdca.md)
```
