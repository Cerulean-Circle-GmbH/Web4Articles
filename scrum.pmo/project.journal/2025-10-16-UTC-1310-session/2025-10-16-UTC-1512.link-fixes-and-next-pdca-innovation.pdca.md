## 🔄 Act

### Standardize: Bidirectional PDCA Linking

**Current Practice (Now Documented):**

**Instead of Template's:**
```markdown
**Next PDCA Focus:** What to work on next
```

**Use:**
```markdown
**Next PDCA:** [Exact Title](GitHub URL) | [relative path](path)
```

**When to Update:**
- After creating next PDCA, go back and update previous PDCA's "Next PDCA" field
- Creates bidirectional chain automatically
- Same dual link format as "Previous PDCA"

**Benefits:**

**1. Bidirectional Navigation:**
- Can traverse forward and backward through learning journey
- No dead ends - every PDCA connects to next

**2. True Neural Network:**
- Synapses fire both ways (like real neurons)
- Knowledge graph becomes fully connected
- Breadcrumb navigation works in both directions

**3. Story Telling:**
- Can follow complete narrative arc: beginning → middle → end
- See how problems led to solutions led to new insights
- Evolution visible in both directions

**4. Future Agent Value:**
- Entry point flexibility: Start anywhere, navigate anywhere
- Context building: See what came before AND what came after
- Learning reinforcement: Forward progress visible

### Pattern Library Entry

**Pattern Name:** "Bidirectional PDCA Linking"

**Problem:** Template provides only backward navigation (Previous PDCA)

**Solution:** Add forward navigation (Next PDCA) with actual links

**Implementation:**
1. When starting new PDCA: Add "Previous PDCA" link as usual
1. Set "Next PDCA" to "To be determined"
1. After creating next PDCA: Go back and update previous PDCA's "Next PDCA" field
1. Use same dual link format for both directions

**Result:** Fully connected knowledge graph with bidirectional traversal

**First Used:** 2025-10-16 session (noticed by TRON, confirmed as innovation)

**For Template Maintainers:**
Consider updating template.md line 552 from:
```markdown
**Next PDCA Focus:** {{NEXT_FOCUS_DESCRIPTION}}
```

To:
```markdown
**Next PDCA:** [To be determined]
```

With instruction: "After creating next PDCA, update this link"
