## **📋 PLAN**

### **My Learning Journey**

**Violation Pattern:**
1. Created session start PDCA with wrong format: `[file.md](../../path/file.md)`
2. TRON corrected: Must use `[§/scrum.pmo/path/file.md](../../path/file.md)`
3. Fixed current PDCA
4. Fixed all yesterday's PDCAs (46 links)
5. Published to dev/0400

**Key Learning:**
- **Link TEXT:** Always `§/scrum.pmo/path/from/project/root/file.md`
- **Link HREF:** Relative path from current document `../../path/file.md`
- **§/ prefix:** Indicates "this path is from project root"

**Why I Kept Making Mistakes:**
- Template shows `[{{LOCAL_PATH}}]({{LOCAL_PATH}})` - suggests same value for both
- Didn't realize LOCAL_PATH should be split into display (with §/) and href (relative)
- No explicit example in template showing §/ prefix requirement

### **Root Cause Analysis**

**Hypothesis:** Documentation contains misleading examples that agents follow instead of correct format.

**Investigation Plan:**
1. ✅ Search for dual link documentation
2. ✅ Read template.md (primary source)
3. ✅ Read howto.PDCA.md and howto.PDCA.original.md
4. ✅ Read PDCA.dual.link.format.requirement.md
5. Identify conflicting or unclear instructions
6. Propose specific fixes

### **Documentation Analysis**

**File 1: template.md (Line 18)**

- This is WRONG format that agents might copy

**What Should Be:**

## **🎓 LEARNINGS**

### **Key Insights**

**1. Template is King**
If template shows wrong pattern, every agent will copy wrong pattern.
Template must show EXACT format agents should produce.

**2. DRY Applies to Documentation**
Multiple "howto" files with conflicting info worse than no docs.
One clear, correct source > many confusing sources.

**3. Comments Matter**
`{{LOCAL_PATH}}` vs `{{LOCAL_PATH_DISPLAY}}` vs `{{RELATIVE_PATH}}`
Clear naming + explanatory comment = no confusion.

**4. Forcing Functions Work**
Checklist that says "verify §/ prefix" will catch errors.
Startup validation prevents downstream corrections.

**5. Meta-Learning is CMM4**
Not just "fix my error" but "fix the system that caused my error."
Document the pattern so future generations benefit.

### **For Future Agents**

**When you see dual link format:**
```markdown
[GitHub](https://github.com/.../path/file.md) | [§/scrum.pmo/path/file.md](../../path/file.md)
                                                   ↑                          ↑
                                            DISPLAY (full path)         HREF (relative path)
                                            §/ prefix MANDATORY         From current file
```

**The §/ Prefix Means:**
- "This path starts from project root"
- "Even though href is relative, display shows full context"
- "Makes links readable while maintaining functionality"

**Why Both Parts Matter:**
- **GitHub link:** Works from GitHub web interface
- **Local link HREF:** Works from your current file location (relative)
- **Local link TEXT:** Shows full context (§/ prefix + full path)

### **The Pattern That Repeats**

**Cycle Without Fix:**
```
Agent reads template → Copies wrong format → TRON corrects → Agent fixes → 
Next agent reads template → Copies wrong format → TRON corrects → ...
```

**Cycle With Fix:**
```
Agent reads template → Sees §/ prefix clearly → Copies correct format → 
TRON validates → No correction needed → Pattern learned → CYCLE BROKEN ✓
```
