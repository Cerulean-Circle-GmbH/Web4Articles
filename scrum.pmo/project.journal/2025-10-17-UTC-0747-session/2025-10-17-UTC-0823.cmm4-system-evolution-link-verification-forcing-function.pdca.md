## **📋 PLAN**

**Context:** Multiple agents (including this one) repeatedly made off-by-one errors calculating relative paths in dual links, causing broken links that wasted TRON's review time.

**Root Cause:** Agents assumed paths were correct without testing, and lacked clear documentation on how to count directory levels.

**CMM4 Goal:** Evolve the system so future agents automatically learn correct path calculation during startup and have a verification protocol to prevent committing broken links.

**Actions:**
1. Add comprehensive "Dual Link Format & Path Verification" section to `recovery/start-command.md`
2. Update template.md with inline comments explaining path calculation logic
3. Document verification protocol (test with `ls` before committing)
4. Reference this learning in the startup process
5. Commit and merge to dev/0400 baseline

Created standard verification workflow:
```bash

cd scrum.pmo/project.journal/YOUR-SESSION/

ls -la ../../roles/_shared/PDCA/template.md # Should work

# If ls fails → path is WRONG → fix before committing
```
