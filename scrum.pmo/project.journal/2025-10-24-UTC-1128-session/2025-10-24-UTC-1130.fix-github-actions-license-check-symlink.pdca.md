## PLAN

### Problem Statement (TRON)

**Trigger:** GitHub Actions "License Header Check" workflow failing with:
```
Error: Process completed with exit code 1
cd components/LicenseTool/latest: No such file or directory
```

**Response:** Workflow tries to build LicenseTool using `latest` symlink, but **Git doesn't check out symlinks properly in CI**.

**Outcome:** CI pipeline broken, can't verify license headers on commits.

**Next:** Fix workflow to use actual version directory instead of symlink.

### Root Cause Analysis

1. **Symptom:** `cd components/LicenseTool/latest` fails in GitHub Actions
2. **Why:** GitHub Actions checkout doesn't properly resolve symlinks
3. **Root Cause:** Workflow hardcodes `latest` symlink instead of using actual version
4. **Pattern:** This is a **CI/CD Gap** identified in `how-to-merge` trainAI topic

### Objective

Fix the GitHub Actions workflow to:
1. Detect the actual `prod` version of LicenseTool (not symlink)
2. Build that specific version
3. Make workflow resilient to version changes

### Solution Options

**Option 1: Use `prod` symlink and resolve it**
- Pros: Always uses stable production version
- Cons: Still relies on symlinks (may not work in CI)

**Option 2: Hardcode specific version**
- Pros: Simple, guaranteed to work
- Cons: Requires manual update on every LicenseTool upgrade

**Option 3: Dynamically detect prod version** ✅ **CHOSEN**
- Pros: Resilient to version changes, follows Web4 semantic versioning
- Cons: Slightly more complex
- **Why Chosen:** CMM3 compliant (reproducible, doesn't require manual intervention)

### Implementation Plan

#### Step 1: Analyze current workflow

Current failing step:
```yaml
- name: Build LicenseTool Component
  run: |
    cd components/LicenseTool/latest
    ./src/sh/build.sh verbose
```

#### Step 2: Fix workflow to detect prod version dynamically

**New approach:**
```yaml
- name: Build LicenseTool Component
  run: |
    # Resolve prod symlink to actual version (works even if symlinks don't)
    PROD_VERSION=$(ls -l components/LicenseTool/prod 2>/dev/null | awk '{print $NF}' || echo "0.1.1.0")
    
    # Fallback: Use highest semantic version if prod doesn't exist
    if [ ! -d "components/LicenseTool/$PROD_VERSION" ]; then
      PROD_VERSION=$(ls -d components/LicenseTool/[0-9]*.[0-9]*.[0-9]*.[0-9]* | sort -V | tail -1 | xargs basename)
    fi
    
    echo "Using LicenseTool version: $PROD_VERSION"
    cd components/LicenseTool/$PROD_VERSION
    ./src/sh/build.sh verbose
```
