**3. Broken Link Analysis**

**Problem Identified:**
When branch A has PDCA with links to branch B content, and branch B isn't migrated, links break.

**Example Pattern:**
```markdown
[Previous PDCA](https://github.com/.../blob/dev/2025-09-15-UTC-1234/scrum.pmo/...)
```
If dev/2025-09-15-UTC-1234 isn't migrated to release/dev, link breaks after branch deletion.

**Impact:**
- Breadcrumb navigation breaks
- Historical research becomes impossible
- Future agents can't learn from previous work
- PDCA process UPDATE sections lose their learning chain

**Solution Strategy:**
1. **Migration Order:** Migrate branches in chronological order so links remain valid
1. **Link Audit:** Before migrating, identify all cross-branch links
1. **Rewrite Links:** Update links to point to release/dev after migration
1. **Verification:** Test link chains after migration
