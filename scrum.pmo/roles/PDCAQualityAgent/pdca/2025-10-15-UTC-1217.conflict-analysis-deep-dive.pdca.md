## **PDCA PROCESS UPDATE**

### **New Pattern: Conflict Analysis Methodology**

**Pattern Name:** "Automated Detection + Manual Assessment"

**When to Use:**
- Multiple conflicts to analyze (> 5)
- Need consistent analysis across all items
- Value assessment required
- Decision support needed

**How to Apply:**
1. **Automate Detection:** Script to gather objective data
1. **Manual Assessment:** Apply value framework to each item
1. **Categorize:** Group by value/priority/type
1. **Navigate:** Provide multi-level structure for different detail needs
1. **Decide:** Priority action plan with recommendations

**This Pattern Used In:**
- Branch conflict analysis (this PDCA)
- Could be used for: link checking, PDCA quality review, component analysis

### **New Pattern: Multi-Level Documentation**

**Pattern Name:** "Summary → Detail → Rabbit Hole"

**Structure:**
- **Level 0:** Executive summary (key findings, high-level stats)
- **Level 1:** Categorized summaries (group by priority/type)
- **Level 2:** Individual item summaries (quick verdict + context)
- **Level 3:** Detailed analysis (full context + git commands + strategies)

**Navigation:**
- Anchor links from summary to detail
- Back-links from detail to summary
- "Rabbit Hole Navigation" subsections for deep dives
- Summary table for at-a-glance comparison

**Benefits:**
- Supports quick decisions (stay at Level 1-2)
- Supports deep analysis (go to Level 3)
- Reader chooses depth
- Context provided at each level
