## **DO**

### **Step 1: Create Automated Generation Script**

Created `/tmp/generate-loose-ends-with-links.sh`:

```bash
#!/bin/bash
# Generate comprehensive loose ends table with GitHub links

# Get all remote branches
ALL_BRANCHES=$(git branch -r | grep -v "HEAD" | sed 's/^[[:space:]]*//' | sort)

COUNTER=1

for BRANCH in $ALL_BRANCHES; do
    # Skip release/dev (our baseline)
    if [[ "$BRANCH" == "origin/release/dev" ]]; then
        continue
    fi
    
    # Check merge status to release/dev
    if git merge-base --is-ancestor "$BRANCH" origin/release/dev 2>/dev/null; then
        IN_RELEASE="✅"
    else
        IN_RELEASE="❌"
    fi
    
    # Check merge status to dev/0400
    if git merge-base --is-ancestor "$BRANCH" origin/dev/0400 2>/dev/null; then
        IN_DEV0400="✅"
    else
        IN_DEV0400="❌"
    fi
    
    # Only show if not in either (loose ends)
    if [[ "$IN_RELEASE" == "❌" ]] && [[ "$IN_DEV0400" == "❌" ]]; then
        # Get branch info
        COMMIT_HASH=$(git log -1 --format="%H" "$BRANCH" 2>/dev/null)
        SHORT_HASH=$(git log -1 --format="%h" "$BRANCH" 2>/dev/null)
        COMMIT_MSG=$(git log -1 --format="%s" "$BRANCH" 2>/dev/null | sed 's/|/-/g')
        COMMIT_DATE=$(git log -1 --format="%ci" "$BRANCH" 2>/dev/null | cut -d' ' -f1)
        
        # Extract branch name without origin/
        BRANCH_NAME=${BRANCH#origin/}
        
        # Create GitHub URL
        GITHUB_URL="https://github.com/Cerulean-Circle-GmbH/Web4Articles/tree/${BRANCH_NAME}"
        
        # Output one line per branch
        echo "**${COUNTER}.** [\`${BRANCH_NAME}\`](${GITHUB_URL}) | Commit: \`${SHORT_HASH}\` | Date: ${COMMIT_DATE} | \"${COMMIT_MSG}\""
        echo ""
        
        ((COUNTER++))
    fi
done
```

**Script Features:**
- Automatic GitHub URL generation
- Filters loose ends (not in release/dev OR dev/0400)
- Sorts branches alphabetically
- Numbers each entry
- Includes metadata (SHA, date, message)
- One branch per line format
