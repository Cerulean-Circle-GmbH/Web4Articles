## **🔧 DO**

### **Implementation Details**

#### **Why ProjectRootMocker Failed**

**The Broken Pattern:**
```typescript
// ❌ BROKEN: Procedural, global state
class ProjectRootMocker {
  mock() {
    process.chdir(mockPath);          // Global side effect!
    process.env.PROJECT_ROOT = mockPath;  // ENV pollution!
  }
}

beforeEach(() => {
  mockProjectRoot = new ProjectRootMocker(testDataDir);
  web4ts = new DefaultWeb4TSComponent();  // Constructor reads path BEFORE mock!
});
```

**Why It Failed:**
1. `DefaultWeb4TSComponent` constructor calls `findProjectRoot()` immediately
2. Constructor uses `import.meta.url`, not `process.cwd()`
3. Mock hasn't set anything yet when constructor runs
4. Component's `model.targetDirectory` set to production path
5. All operations happen in production

#### **The OOP Solution**

**How setTargetDirectory() Works:**
```typescript
// ✅ CORRECT: OOP, model state
class DefaultWeb4TSComponent {
  constructor() {
    this.model = {
      targetDirectory: this.findProjectRoot(),  // Default: production
      component: 'Web4TSComponent',
      version: this.readVersionFromDirectory(),
    };
  }
  
  setTargetDirectory(directory: string): void {
    this.model.targetDirectory = directory;  // Pure state change!
  }
  
  private isTestEnvironment(): boolean {
    return this.model.targetDirectory.includes('/test/data');
  }
}

beforeEach(() => {
  web4ts = new DefaultWeb4TSComponent();
  web4ts.setTargetDirectory(testDataDir);  // Override to test path!
});
```

**Why It Works:**
1. Constructor initializes with production defaults (normal)
2. `setTargetDirectory()` explicitly overrides model state
3. All methods use `this.model.targetDirectory`
4. Pure function - no side effects, no globals
5. Clear intent - obvious what test is doing
6. Reliable - model state guaranteed

#### **Standard Test Pattern**

**Official Web4 Test Isolation Pattern:**
```typescript
describe('Test Suite', () => {
  const testDataDir = path.join(__dirname, 'data');
  let component: DefaultWeb4TSComponent;

  beforeEach(async () => {
    // Clean test/data CONTENT only
    if (existsSync(testDataDir)) {
      const entries = await fs.readdir(testDataDir);
      for (const entry of entries) {
        await fs.rm(path.join(testDataDir, entry), { 
          recursive: true, 
          force: true 
        });
      }
    } else {
      await fs.mkdir(testDataDir, { recursive: true });
    }
    
    // Set up test isolation - ONE LINE!
    component = new DefaultWeb4TSComponent();
    component.setTargetDirectory(testDataDir);
  });

  // NO afterEach - leave results visible

  it('test case', async () => {
    // Operations automatically go to test/data
    await component.create('TestComponent', '1.0.0.0', 'all');
    
    // Verify in test/data
    const testPath = path.join(testDataDir, 'components', 'TestComponent', '1.0.0.0');
    expect(existsSync(testPath)).toBe(true);
  });
});
```
